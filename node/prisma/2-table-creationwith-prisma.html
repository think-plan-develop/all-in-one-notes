1. Schema Location

All models live in one file

With Prisma, all your database models are normally defined in prisma/schema.prisma, even if you have 100 models.

prisma/ └── schema.prisma
💡 Install the Prisma VS Code extension for syntax highlighting, autocomplete, and schema validation.
2. Example Models

Role + User (relation)

prisma/schema.prisma
model Role {
  id    String @id @default(uuid())
  name  String @unique
  users User[]
}

model User {
  id            String   @id @default(uuid())
  email         String   @unique
  password_hash String
  role_id       String
  role          Role     @relation(fields: [role_id], references: [id])
  created_at    DateTime @default(now())
  updated_at    DateTime @updatedAt
}
3. Validate Schema

Check the schema first

terminal
npx prisma validate
✅ Output: The schema at prisma/schema.prisma is valid 🚀
⚠️ npx prisma migrate dev --name init will fail here if the database is not set up yet.
4. Database Setup

Configure prisma.config.ts

prisma.config.ts
import "dotenv/config";
import { defineConfig, env } from "prisma/config";

export default defineConfig({
  schema: "prisma/schema.prisma",
  migrations: { path: "prisma/migrations" },
  datasource: { url: env("DATABASE_URL") },
});

Configure schema.prisma

prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../src/generated/prisma"
}

datasource db {
  provider = "postgresql"
}
5. Test the Database Connection

Now run

terminal
npx prisma migrate dev --name init
📌 This creates the tables in PostgreSQL and generates the Prisma Client.
6. What Prisma Creates

Project structure

project-2-auth/ │ ├── prisma/ │ ├── schema.prisma │ └── migrations/ │ └── 20260822xxxxxx_init/ │ └── migration.sql │ ├── src/ │ └── generated/ │ └── prisma/ │ └── ... │ ├── .env ├── prisma.config.ts └── package.json
PathWhat it is
schema.prismaSource of truth for the database structure
migrations/Prisma stores the database changes here
migration.sqlThe SQL Prisma generated from your models
src/generated/prisma/Generated Prisma Client code. Don't manually edit this.

7. Runtime — db.ts

For the running application, add db.ts

src/config/db.ts
import { PrismaClient } from "../generated/prisma/client.js";
import { PrismaPg } from "@prisma/adapter-pg";
import { env } from "./env.js";

const adapter = new PrismaPg({
  connectionString: env.DATABASE_URL,
});

export const prisma = new PrismaClient({ adapter });
8. Structure vs Data

Quick difference

ConceptWhat it does
MigrationCreates / changes the database structure
SeedInserts initial / default records
