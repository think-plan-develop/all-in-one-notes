3. Package Roles

Prisma + Postgres Stack

PackageRole
@prisma/client The Prisma Client — type-safe query builder your app imports (e.g. prisma.user.findMany()). Runtime library for talking to the database.
@prisma/adapter-pg Driver adapter so Prisma Client uses pg directly (driver adapters mode — better for serverless/edge).
pg Actual PostgreSQL driver for Node.js — opens TCP and speaks the Postgres wire protocol.
4. Prisma CLI

Commands

prisma (with -D) is the CLI for schema/migrations/codegen. Separate from @prisma/client (runtime).

CommandPurpose
npx prisma initScaffolds prisma/schema.prisma + .env
npx prisma generateGenerates @prisma/client from schema
npx prisma migrate devCreate + apply migration (dev)
npx prisma migrate deployApply migrations (production)
npx prisma studioBrowser GUI for DB data
npx prisma db pushPush schema without migration file
npx prisma formatFormat schema.prisma

Key Distinction

prisma (CLI)

Dev-only · terminal · schema/migrations/codegen
Install with -D

@prisma/client

Runtime · imported in app code · needed in production
Regular dependency

📌 prisma → -D · @prisma/client → regular dependency
5. npx prisma init

What It Creates

your-project/ ├── prisma/ │ └── schema.prisma └── .env

schema.prisma starter:

schema.prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
  • generator client → generates JS/TS client on prisma generate
  • datasource db → DB type + connection string from .env

Example model later:

schema.prisma
model User {
  id    Int     @id @default(autoincrement())
  email String  @unique
  name  String?
}

.env placeholder:

.env
DATABASE_URL="postgresql://johndoe:randompassword@localhost:5432/mydb?schema=public"
💡 Replace with your real Postgres credentials.

Useful Flags

FlagPurpose
--datasource-provider postgresqlSet DB provider explicitly
--output ./generated/clientCustom client output path

What It Does NOT Do

  • Does not connect to the database
  • Does not create tables
  • Does not generate the client (use prisma generate or migrate dev)

Next Steps After init

  1. Edit .env with real DATABASE_URL
  2. Define models in schema.prisma
  3. Run npx prisma migrate dev --name init → creates tables + generates client
