path Module

Definition

The path module is a built-in Node.js module used to work with file and directory paths in a platform-independent way.

Interview Definition: The path module provides utilities for creating, resolving, and manipulating file system paths without hardcoding path separators (/ or \).
import.js
const path = require("path");

Why use it?

Different operating systems use different path separators — hardcoding either one breaks the other platform.

OSExample Path
WindowsC:\Users\Shivam\project\file.txt
Linux / macOS/home/shivam/project/file.txt
Avoid: hardcoded strings like "uploads/images/profile.jpg" or "uploads\\images\\profile.jpg" — they may break across operating systems.

Methods

path.join()

Joins multiple path segments into a single normalized path.

join.js
const path = require("path");

const filePath = path.join("users", "images", "profile.jpg");
console.log(filePath);
// Windows: users\images\profile.jpg
// Linux/macOS: users/images/profile.jpg
Use case: building file paths safely.

path.resolve()

Converts a relative path into an absolute path.

resolve.js
const path = require("path");

const absolutePath = path.resolve("uploads", "image.png");
console.log(absolutePath);
// C:\Projects\NodeApp\uploads\image.png
Use case: when APIs require an absolute path.

path.extname()

Returns the file extension.

extname.js
console.log(path.extname("photo.jpg"));    // .jpg
console.log(path.extname("document.pdf")); // .pdf
console.log(path.extname("index.html"));  // .html
Use case: validate uploaded file types.

path.basename()

Returns the file name from a path — and can optionally strip the extension.

basename.js
console.log(path.basename("/users/images/profile.jpg"));
// profile.jpg

console.log(path.basename("profile.jpg", ".jpg"));
// profile
Use case: extract the file name from a full path.

Quick Summary

MethodPurposeExample Output
path.join()Join path segmentsuploads/images/file.jpg
path.resolve()Create an absolute pathC:\Project\uploads\file.jpg
path.extname()Get file extension.jpg

Interview Answer: The path module safely works with file and directory paths across operating systems. join() combines segments, resolve() generates an absolute path, extname() returns the extension, and basename() extracts the file name — avoiding hardcoded strings and ensuring cross-platform compatibility.
os Module

Definition

The os module is a built-in Node.js module that provides information about the operating system — CPU, memory, platform, hostname, and more.

import.js
import os from "os";

Core Methods

MethodOne-Line Explanation
os.platform()Returns the operating system platform.
os.arch()Returns the CPU architecture.
os.cpus()Returns details about all CPU cores.
os.totalmem()Returns the total installed RAM.
os.freemem()Returns the currently available RAM.
os.hostname()Returns the computer's hostname.
os.uptime()Returns the system uptime in seconds.

Examples

os-examples.js
import os from "os";

console.log(os.platform());   // "win32", "linux", "darwin"
console.log(os.arch());       // "x64", "arm64"
console.log(os.cpus());       // array of CPU core details
console.log(os.totalmem());   // total RAM in bytes
console.log(os.freemem());    // available RAM in bytes
console.log(os.hostname());   // e.g. "shivam-laptop"
console.log(os.uptime());     // seconds since last reboot
⚠️ Note: hostname() is a method, not a property — you must call it with (). Logging os.hostname without parentheses prints the function itself, not the value.

crypto Module — Practical Usage

Overview

Knowing raw crypto matters, but real projects usually reach for specific tools per use case. Here's what's actually used where.

Use Case → What's Generally Used

Use CaseWhat is Generally Used?
Password hashingbcrypt or Argon2 ✅
JWT signingjsonwebtoken (internally uses crypto)
Password reset tokencrypto.randomBytes() ✅
UUID generationcrypto.randomUUID() (or uuid package in older projects)
Encrypt sensitive datacrypto.createCipheriv()
Verify webhook signaturescrypto.createHmac()
HTTPS/TLSNode.js https module (uses crypto internally)

Quick Examples

crypto-examples.js
import crypto from "crypto";

// Password reset token
const token = crypto.randomBytes(32).toString("hex");

// UUID generation (built-in, no package needed)
const id = crypto.randomUUID();
console.log(id); // e.g. "3f9a1c2e-4b8d-4a1e-9c3f-2e1a9b7d6c5f"

// Encrypt sensitive data
const key = crypto.randomBytes(32);
const iv = crypto.randomBytes(16);
const cipher = crypto.createCipheriv("aes-256-cbc", key, iv);
let encrypted = cipher.update("secret data", "utf8", "hex");
encrypted += cipher.final("hex");

// Verify webhook signature
const hmac = crypto.createHmac("sha256", "webhookSecret").update(payloadBody).digest("hex");

Interview Tip

Raw crypto is the foundation — good for random tokens, HMAC verification, and encryption.

Remember: passwords always go through bcrypt/Argon2 (never raw hashing), and auth tokens go through jsonwebtoken — both wrap crypto internally with safer, purpose-built APIs. Knowing when to use the raw module vs. the specialized package is exactly what interviewers are probing for.

Usage Patterns

1. Reading a File

No need for __dirname.

2. Getting __filename

get-filename.js
import { fileURLToPath } from "url";

const __filename = fileURLToPath(import.meta.url);

console.log(__filename);
Output
/Users/shivam/project/index.js

3. Getting __dirname

get-dirname.js
import path from "path";
import { fileURLToPath } from "url";

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

console.log(__dirname);
Output
/Users/shivam/project

4. Dynamic Import

dynamic-import.js
const math = await import(
  new URL("./math.js", import.meta.url)
);

console.log(math.add(2, 3));
Useful when loading modules dynamically.
Interview Questions
💡 Interview Q&A
Why use the path module instead of string concatenation?
Because path separators differ across operating systems (\ on Windows vs / on Linux/macOS). path.join() and path.resolve() handle this automatically so the same code works everywhere.
Difference between path.join() and path.resolve()?
join() simply concatenates and normalizes segments into a relative or partial path. resolve() does the same but always returns a fully qualified absolute path, resolving from right to left until an absolute path is formed.
How do you get a file's extension or name in Node.js?
Use path.extname(filePath) to get the extension (e.g. .jpg), and path.basename(filePath) to get the file name. Passing a second argument to basename() strips that extension from the result.
How would you check available system memory in Node.js?
Use os.totalmem() for total installed RAM and os.freemem() for currently available RAM, both returned in bytes — useful for basic monitoring or resource-aware logic.
Why does console.log(os.hostname) print a function?
Because hostname is a method, not a property — omitting the parentheses logs the function reference itself instead of invoking it. It must be called as os.hostname().
Should you hash passwords with crypto directly?
No. Raw crypto hashing (like SHA-256) is too fast and lacks built-in salting, making it vulnerable to brute-force attacks. Use bcrypt or Argon2 instead — they're purpose-built for password hashing with slow, salted algorithms.
How do you generate a secure random token in Node.js?
Use crypto.randomBytes(32).toString("hex") — this is the standard approach for password-reset tokens and other secure random identifiers.
What is import.meta.url?
import.meta.url is an ES Module feature that provides the URL of the current module. It is commonly used to resolve file paths, read files relative to the current module, recreate __dirname and __filename, and perform dynamic imports. It replaces many use cases where CommonJS applications relied on __dirname.
Why doesn't __dirname work in ES Modules?
__dirname and __filename are CommonJS-specific globals and are not defined inside ES Modules. Instead, ESM exposes import.meta.url, from which the equivalent path information can be derived using fileURLToPath() and path.dirname().
How do you get __dirname in an ES Module?
First derive __filename with fileURLToPath(import.meta.url), then pass that into path.dirname() to get the containing folder — recreating the CommonJS __dirname global.
How do you perform a dynamic import relative to the current module?
Use await import(new URL("./module.js", import.meta.url)) — this resolves the target module's path relative to the current file before dynamically loading it, which is useful for conditionally loading modules at runtime.
