The Concept — What is a Stream?

Definition

A stream is an object that processes data chunk by chunk instead of loading the entire data into memory, making it memory-efficient and ideal for large files and real-time data processing.

Why Use Streams Instead of fs.readFile()?

  • fs.readFile() loads the entire file into memory.
  • Streams process data in chunks.
  • Streams use less memory.
  • Streams start processing immediately without waiting for the complete file.

The Four Types of Streams

  • Readable — data flows out (e.g. reading a file)
  • Writable — data flows in (e.g. writing a file)
  • Duplex — both readable and writable (e.g. a TCP socket)
  • Transform — a duplex stream that modifies data as it passes through (e.g. compression)
Readable Stream — fs.createReadStream()

Creating a Readable Stream

fs.createReadStream() creates and returns a Readable Stream that reads a file chunk by chunk instead of loading the entire file into memory.

read-stream.js
const fs = require("fs");

const readStream = fs.createReadStream("input.txt");

The "data" Event

Triggered whenever a new chunk of data is available.

on-data.js
readStream.on("data", (chunk) => {
    console.log(chunk.toString());
});

Example output:

Chunk 1 Chunk 2 Chunk 3 ...

The "end" Event

Triggered after the entire file has been read.

on-end.js
readStream.on("end", () => {
    console.log("File reading completed.");
});

Use end when you want to perform an action after all data has been read.

💡 Examples: Log "Reading completed" · Close a database connection · Send a final response.
Writable Stream — fs.createWriteStream()

Creating a Writable Stream

fs.createWriteStream() creates and returns a Writable Stream that writes data to a file in chunks.

write-stream.js
const fs = require("fs");

const writeStream = fs.createWriteStream("output.txt");

.write()

Writes data into the file.

write-call.js
writeStream.write("Hello ");
writeStream.write("Node.js");
💡 Output: Hello Node.js

Does .write() Replace or Append?

createWriteStream() uses the w flag by default.

default-flag.js
const writeStream = fs.createWriteStream("output.txt");
  • If the file does not exist, it is created.
  • If the file already exists, its existing content is replaced (overwritten).

Example — existing file contains Hello World:

overwrite-example.js
writeStream.write("Node.js");
⚠️ Output: Node.js — the old content (Hello World) is removed.

How to Append Instead of Replace

Use the a flag.

append-flag.js
const writeStream = fs.createWriteStream("output.txt", {
    flags: "a"
});

Example — existing file contains Hello:

append-example.js
writeStream.write(" Node.js");
✅ Output: Hello Node.js — the new content is appended instead of replacing the existing content.
🔗 How pipe() Works Internally
🔗

Connecting the Two Streams

pipe-example.js
const fs = require("fs");

const readStream = fs.createReadStream("input.txt");
const writeStream = fs.createWriteStream("output.txt");

readStream.pipe(writeStream);

What Does pipe() Do Automatically?

Instead of writing this:

manual.js
readStream.on("data", (chunk) => {
    writeStream.write(chunk);
});

readStream.on("end", () => {
    writeStream.end();
});

You can simply write:

pipe.js
readStream.pipe(writeStream);

pipe() automatically:

  • Reads each chunk.
  • Writes each chunk.
  • Handles backpressure.
  • Ends the writable stream when reading is complete.
  • Reduces boilerplate code.

Stream Interview Questions
💡 Interview Q&A
What is a Stream in Node.js?
A stream is an object that processes data chunk by chunk instead of loading the entire data into memory, making it memory-efficient and ideal for large files and real-time data processing.
Why use Streams instead of fs.readFile()?
fs.readFile() loads the entire file into memory. Streams process data in chunks, use less memory, and start processing immediately without waiting for the complete file.
What are the four types of Streams?
Readable, Writable, Duplex, and Transform.
What is fs.createReadStream()?
fs.createReadStream() is an fs module function that creates and returns a Readable stream to read a file chunk by chunk.
What is fs.createWriteStream()?
fs.createWriteStream() is an fs module function that creates and returns a Writable stream to write data to a file chunk by chunk.
What is the difference between createReadStream() and ReadStream?
createReadStream() is a factory function that creates and returns a Readable stream. ReadStream is the underlying class (constructor). In practice, always use the factory function:
preferred.js
fs.createReadStream("file.txt");
instead of:
avoid.js
new fs.ReadStream("file.txt");
What is pipe() in Node.js?
pipe() is a method of a Readable stream that automatically transfers data from a Readable stream to a Writable (or compatible Transform/Duplex) stream. It also handles backpressure automatically.
Is pipe() a stream?
No. pipe() is a method used to connect streams. It is not a type of stream.
What is Backpressure?
Backpressure occurs when the Readable stream produces data faster than the Writable stream can consume it. pipe() automatically pauses and resumes the Readable stream to prevent excessive memory usage.
