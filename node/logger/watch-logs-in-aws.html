1. Open Logs Insights

Each request has one traceId

pino log
{
  "traceId": "7fba02e3-9b64-4de3-942d-b1881f0aab85"
}

The same traceId appears in all logs for that request.

AWS Console → CloudWatch → Logs Insights Log group: /ecs/pino-logger-task Select the time range
2. Search one exact traceId
2

Only that request

Logs Insights
fields @timestamp, level, traceId, req.method, req.url, res.statusCode, responseTime, msg
| filter traceId = "7fba02e3-9b64-4de3-942d-b1881f0aab85"
| sort @timestamp asc

Replace the UUID with the real ID.

3. Example flow

One ID = entire request

10:00:01 traceId=abc-123 GET /users Request received 10:00:01 traceId=abc-123 GET /users Database query started 10:00:01 traceId=abc-123 GET /users Database query completed 10:00:01 traceId=abc-123 GET /users request completed
4. Partial trace ID
4

When you don't have the full UUID

Logs Insights
fields @timestamp, level, traceId, req.method, req.url, msg
| filter traceId like /abc-123/
| sort @timestamp asc

Project rule

Don't pick task streams by hand

Don't keep choosing ecs/Main/62c31cb… · ecs/Main/4f5f86… · ecs/Main/edc0cb…. Those are ECS task log streams and change when tasks restart.
