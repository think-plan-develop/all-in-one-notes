1–3 · AWS CLI · IAM · CloudWatch
1

AWS CLI

Amazon Web Services Command Line Interface — manage AWS from the terminal.

powershell
aws --version
aws configure
aws sts get-caller-identity

aws configure asks: Access Key ID · Secret Access Key · Default region · Default output (e.g. us-east-1, json).

  • Access Key ID — identifies the IAM user/key.
  • Secret Access Key — treat like a password.
  • Never put either key in GitHub or inside a Docker image.
  • Don't use the AWS root user's access keys.
2

IAM

Identity and Access Management: who can access AWS, what they can access, what actions they can perform.

For CLI, create an IAM user with required permissions — not the root account. Enable MFA on root. Root should not have active access keys for normal development.

3

9

ECS + Fargate

Elastic Container Service runs Docker on AWS. Launch type: Fargate — serverless container compute. You don't manage EC2, OS, or Docker host. You specify CPU, memory, container, networking.

Task Execution Role

ecsTaskExecutionRole + AmazonECSTaskExecutionRolePolicy — pull from ECR, send logs to CloudWatch.

📌 Execution role is used by ECS/Fargate — different from permissions the app itself may need.
13

ECS Service

Keeps the app running. Desired tasks = 1 → ECS tries to keep one task running.

Task crashes
↓
Service notices
↓
New task starts

That's why stopping a task causes ECS to create a replacement.

14

ECS Task

Running instance of the task definition. Gets its own networking: private IP 172.31.69.89 · public IP 54.163.55.191

15

Dockerfile / app

  logger.info('Server started on port 3000');

Host 3000 → container 3000. EXPOSE 3000 does not open AWS's firewall. Security Groups control access.

17–19

VPC · Subnet · Internet Gateway

VPC vpc-05238bb298bc72d50 ├── Subnet subnet-0013467d15bb75f8e 172.31.64.0/20 │ └── ECS Task ├── Route Table 0.0.0.0/0 → igw-003f0379f3c48dd69 ├── Internet Gateway └── Security Group

Default subnet, auto-assign public IPv4 = Yes → task gets a public IP. Route 0.0.0.0/0 → IGW → internet.

20

Security Group

Virtual firewall. Example: sg-02312c73d3f5bcb0a

Testing inbound: Custom TCP · Port 3000 · Source 0.0.0.0/0 = anyone on the internet.

Better for dev: restrict to your public IP YOUR_PUBLIC_IP/32 (single address). ISP can change your IP — then the SG stops working until you update it.

21

Private IP vs Public IP

Private

172.31.69.89 — inside the VPC.

Public

54.163.55.191 — from the internet. Test: http://54.163.55.191:3000

22

Network ACL

NACL = subnet-level filter. Example: acl-0b7d7760ae1348c82

Inbound/outbound rule 100: All traffic · 0.0.0.0/0 · ALLOW. Then * DENY. Numbered rules first — 100 matches, traffic allowed.

30

Exit code 137

Exit 137 = SIGKILL (9). If you manually stopped the task, 137 is expected — not an app crash.

Service desired = 1 → ECS creates a replacement. Replacement can get a new public IP. Always check the current RUNNING task's public IP.
