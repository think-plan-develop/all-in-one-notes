🚀 Node.js + TypeScript + MongoDB Setup

Complete Backend Project Architecture Guide (Beginner → Production Level)

STEP 1

Create Project

mkdir node-mongo-app cd node-mongo-app npm init -y
Creates package.json which stores:
  • Project Information
  • Dependencies
  • Scripts
  • Version Information
STEP 2

Install Runtime Dependencies

npm install express mongoose dotenv cors helmet morgan

Express

API Framework used to create routes, middleware and web servers.

Mongoose

ODM Layer between Node.js and MongoDB.

Dotenv

Loads environment variables from .env file.

CORS

Allows frontend applications to access backend APIs.

Helmet

Adds secure HTTP headers.

Morgan

Logs incoming requests.
STEP 3

Install Development Dependencies

npm install -D typescript ts-node-dev @types/node @types/express @types/cors @types/morgan

TypeScript

Converts TS into JavaScript.

ts-node-dev

Automatically restarts server on changes.

@types/*

Provides TypeScript definitions.
STEP 4

Initialize TypeScript

npx tsc --init
Creates tsconfig.json which controls:
  • Compilation
  • Strict Type Checking
  • Module System
  • Output Directory
STEP 5

Project Structure

src │ ├── config │ └── db.ts │ ├── models │ └── user.model.ts │ ├── services │ └── user.service.ts │ ├── controllers │ └── user.controller.ts │ ├── routes │ └── user.routes.ts │ ├── app.ts │ └── server.ts

STEP 7

Database Connection

Node.js ↓ Mongoose ↓ MongoDB
import mongoose from "mongoose"; export const connectDB = async () => { await mongoose.connect( process.env.MONGO_URI as string ); console.log("MongoDB Connected"); };
STEP 8

Model Layer

User Collection ↓ Schema Definition ↓ Validation Rules ↓ MongoDB Documents
const userSchema = new mongoose.Schema({ name: String, email: String }); export const User = mongoose.model( "User", userSchema );
STEP 9

Service Layer

Controller ↓ Service ↓ Database
export const getUsers = async () => { return User.find(); };
Service Layer contains:
  • Business Logic
  • Database Queries
  • Reusable Functions
  • Complex Operations
STEP 10

Controller Layer

Request ↓ Controller ↓ Service ↓ Response
export const fetchUsers = async ( req, res ) => { const users = await getUsers(); res.json(users); };
STEP 11

Route Layer

GET /users ↓ Route ↓ Controller
router.get("/", fetchUsers);
