### Mistakes to Remember — Mongoose User Schema 1. **`required`, not `require`** ```ts required: true ``` ❌ `require: true` 2. **Use `maxlength` for string length** ```ts maxlength: 35 ``` ❌ `maxLength: 35` 3. **Add `unique: true` for unique email** ```ts email: { type: String, required: true, unique: true } ``` 4. **Schema and Model are different** ```text Schema → defines document structure Model → interacts with MongoDB ``` 5. **Create Schema using `mongoose.Schema()`** ```ts const userSchema = new mongoose.Schema({...}); ``` 6. **Create Model using `mongoose.model()`** ```ts const User = mongoose.model("User", userSchema); ``` ❌ Don't use: ```ts new mongoose.Model(...) ``` 7. **Use a meaningful Model name** ```ts const User = mongoose.model("User", userSchema); ``` Not: ```ts const userSchema = ... ``` for the model variable. 8. **`timestamps: true` is a Schema option** ```ts { timestamps: true } ``` It automatically creates: ```text createdAt updatedAt ``` 9. **For email fields, commonly use `trim` and `lowercase`** ```ts email: { type: String, required: true, unique: true, trim: true, lowercase: true } ``` 10. **Password should never be stored as plain text** ```text Plain password ↓ bcrypt.hash() ↓ Hashed password ↓ MongoDB ``` ### Easy pattern to remember ```text mongoose.Schema() ↓ Schema definition ↓ mongoose.model() ↓ Model ↓ MongoDB operations ``` **Your biggest mistakes were:** `require` → `required`, `new mongoose.Model()` → `mongoose.model()`, and forgetting `unique: true` for email.
