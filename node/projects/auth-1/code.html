MODEL usersModal.ts
Mongoose model — depends only on argon2 for the pre-save hash hook. Fields: email, password, name, timestamps + unique index on email.
import { model, Schema, InferSchemaType } from "mongoose";
import argon2 from "argon2";

const userSchema = new Schema({
  name: {
    type: String,
    maxlength: 35,
    required: true,
  },
  password: {
    type: String,
    required: true,
  },
  email: {
    required: true,
    type: String,
    unique: true,
    trim: true,
    lowercase: true,
    validate: {
      validator(value: string) {
        return /^[^\s@]+@techmahindra\.com$/.test(value);
      },
      message: "Please enter techmahindra domain email",
    },
  },
}, { timestamps: true });

userSchema.pre("save", async function (next) {
  if (!this.isModified("password")) {
    return;
  }
  this.password = await argon2.hash(this.password);
});

export type User = InferSchemaType<typeof userSchema>;

const userModel = model<User>("User", userSchema);

export default userModel;

SERVICE authService.ts
Business logic layer — depends on: usersModal.ts, authSchema.ts, AppError.ts. Used by authController.ts.
import userModel from "./usersModal.js";
import { registerInput, loginInput } from "./authSchema.js";
import argon2 from "argon2";
import jwt from "jsonwebtoken";
import { AppError } from "./AppError.js";

export const registerUser = async (userData: registerInput) => {
  const existingUser = await userModel.findOne({ email: userData.email });

  if (existingUser) {
    throw new AppError("User already exists", 409);
  }

  const hashedPassword = await argon2.hash(userData.password);

  const savedUser = await userModel.create({
    ...userData,
    password: hashedPassword,
  });

  if (!savedUser) {
    throw new AppError("Failed to create user", 500);
  }

  return savedUser;
};

export const loginUser = async (loginData: loginInput) => {
  const existingUser = await userModel
    .findOne({ email: loginData.email })
    .select("+password");

  if (!existingUser) {
    throw new AppError("User doesn't exist", 404);
  }

  const isValidPassword = await argon2.verify(
    existingUser.password,
    loginData.password
  );

  if (!isValidPassword) {
    throw new AppError("Invalid credentials", 401);
  }

  const SECRET = process.env.JWT_SECRET;
  if (!SECRET) {
    throw new AppError("Server configuration error", 500);
  }

  const token = jwt.sign(
    { email: existingUser.email, name: existingUser.name, userId: existingUser._id },
    SECRET,
    { expiresIn: "15m" }
  );

  return token;
};

export const getProfileDetails = async (userId: string) => {
  const user = await userModel.find({ _id: userId }, { password: 0 }).lean();
  if (!user) throw new Error("user not found");
  return user;
};
Key fixes applied:
• Password hashed with argon2.hash() before create
• Standardized on AppError with correct status codes (409, 401, 500)
• expiresIn: "15m" (not "15min")
• .select("+password") for login verify
• Parameter renamed to loginData (no shadowing)
MIDDLEWARE authMiddleware.ts
Authorization middleware — depends on express.d.ts's Request.user augmentation. Used by authRoute.ts.
import { Request, Response, NextFunction } from "express";
import jwt from "jsonwebtoken";

interface JwtPayload {
  userId: string;
}

export const authMiddleware = (
  req: Request,
  res: Response,
  next: NextFunction
) => {
  const token = req.cookies.token;

  if (!token) {
    return res.status(401).json({
      message: "Authentication required",
    });
  }

  try {
    const decoded = jwt.verify(
      token,
      process.env.JWT_SECRET!
    ) as JwtPayload;

    if (!decoded.userId) throw new Error("invalid token");

    req.user = {
      userId: decoded.userId,
    };

    next();
  } catch {
    return res.status(401).json({
      message: "Invalid or expired token",
    });
  }
};
CONTROLLER authController.ts
Controller layer — depends on authSchema.ts and authService.ts. Used by authRoute.ts.
import { Request, Response, NextFunction } from "express";
import { loginSchema, registerSchema } from "./authSchema.js";
import { getProfileDetails, loginUser, registerUser } from "./authService.js";

export const registerController = async (
  req: Request,
  res: Response,
  next: NextFunction
) => {
  try {
    const requestData = registerSchema.parse(req.body);
    await registerUser(requestData);
    res.status(201).json({ message: "User created successfully" });
  } catch (err) {
    next(err);
  }
};

export const loginController = async (
  req: Request,
  res: Response,
  next: NextFunction
) => {
  try {
    const loginData = loginSchema.parse(req.body);
    const token = await loginUser(loginData);

    res.cookie("token", token, {
      httpOnly: true,
      secure: true,
      sameSite: "strict",
    });

    res.status(200).json({ message: "User logged in successfully" });
  } catch (err) {
    next(err);
  }
};

export const getUserController = async (
  req: Request,
  res: Response,
  next: NextFunction
) => {
  try {
    const userId: string = req.user.userId;
    if (!userId) throw new Error("userid is missing");
    const userData = await getProfileDetails(userId);
    res.status(200).json({ data: userData, message: "User logged in successfully" });
  } catch (err) {
    next(err);
  }
};

export const logoutController = (
  req: Request,
  res: Response
) => {
  res.clearCookie("token");
  res.status(200).json({ message: "Logout successful" });
};
Key fixes: Controllers use next(err) uniformly · validated data passed to service · 201 on create · cookie set with httpOnly, secure, sameSite: "strict"

ERROR errorHandlers.ts
Centralized error handler — depends on AppError.ts and ZodError. Registered last in server.ts, after all routes.
import type { Request, Response, NextFunction } from "express";
import { ZodError } from "zod";
import { AppError } from "./AppError.js";

export const errorHandler = (
  err: unknown,
  req: Request,
  res: Response,
  next: NextFunction
) => {
  // 1. Custom application error
  if (err instanceof AppError) {
    return res.status(err.statusCode).json({
      success: false,
      message: err.message,
    });
  }

  // 2. Zod validation error
  if (err instanceof ZodError) {
    return res.status(400).json({
      success: false,
      message: "Validation failed",
      errors: err.issues.map((issue) => ({
        field: issue.path.join("."),
        message: issue.message,
      })),
    });
  }

  // 3. Unknown/unexpected error
  return res.status(500).json({
    success: false,
    message: "Internal server error",
  });
};

SERVER server.ts
Entry point — imports app.ts, connection.ts, errorHandlers.ts. Connects to DB, registers the error handler, starts listening.
import dotenv from "dotenv";
import app from "./app.js";
import connectDB from "./connection.js";
import { errorHandler } from "./errorHandlers.js";

dotenv.config();

const port = process.env.PORT;

connectDB();

app.use(errorHandler);

app.listen(port, () => {
  console.log("server is listing on port", port);
});
⚠️ Remember: errorHandler must be registered last (after all routes). Controllers pass errors via next(err) so this handler can format them correctly.
