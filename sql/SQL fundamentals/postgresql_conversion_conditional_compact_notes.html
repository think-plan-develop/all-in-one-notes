Conversion functions

Conversion changes a value from one data type to another — for example, text to a number, a number to text, or text to a date.

Text → number'100'::INTEGER
Number → text100::TEXT
Text → date'2026-10-29'::DATE
2

CAST() and PostgreSQL ::

CAST()

Converts an expression into a specified data type.

cast_syntax.sql
CAST(expression AS data_type)

Example:

cast_example.sql
SELECT CAST('100' AS INTEGER) AS amount;

Output:

amount
100

More examples

cast_examples.sql
-- Text to integer
SELECT CAST('250' AS INTEGER);

-- Integer to text
SELECT CAST(100 AS TEXT);

-- Text to decimal
SELECT CAST('99.50' AS NUMERIC(10, 2));

-- Text to date
SELECT CAST('2026-10-29' AS DATE);

PostgreSQL shorthand: ::

PostgreSQL supports :: as a shorter alternative to CAST().

postgres_cast_shorthand.sql
SELECT '100'::INTEGER AS amount;
SELECT 99.50::TEXT AS amount;
SELECT '2026-10-29'::DATE AS order_date;
Real-project example: If an API sends a price as text, convert it before doing numeric calculations.
convert_price.sql
SELECT
    product_name,
    price_text::NUMERIC AS price
FROM products;
Important: The source value must be convertible. For example, 'abc'::INTEGER raises a conversion error.

Conditional expressions — CASE WHEN

Conditional expressions return different values depending on a condition, similar to if / else logic in JavaScript.

Syntax

case_syntax.sql
CASE
    WHEN condition1 THEN result1
    WHEN condition2 THEN result2
    ELSE default_result
END

Example: classify orders by amount

order_category.sql
SELECT
    order_id,
    amount,
    CASE
        WHEN amount >= 10000 THEN 'High'
        WHEN amount >= 5000 THEN 'Medium'
        ELSE 'Low'
    END AS order_category
FROM orders;

If the amount is 12000, the result is High. If it is 7000, the result is Medium. If it is 2000, the result is Low.

Remember: Conditions are checked in order. The first matching branch wins, so put more specific or higher-threshold conditions first.

Conditional aggregation

Combine CASE with aggregate functions to count or sum only rows that meet a condition.

conditional_aggregation.sql
SELECT
    COUNT(*) AS total_orders,
    COUNT(CASE WHEN status = 'completed' THEN 1 END)
        AS completed_orders,
    SUM(CASE WHEN status = 'completed' THEN amount ELSE 0 END)
        AS completed_revenue
FROM orders;
total_ordersCounts all orders.
completed_ordersCounts orders whose status is completed.
completed_revenueSums the amount for completed orders.

COALESCE() — handling NULL values

COALESCE() returns the first non-NULL value from its arguments.

coalesce_example.sql
SELECT COALESCE(NULL, NULL, 'Unknown') AS result;

Output:

result
Unknown

Real-world example: default a missing phone number

default_phone.sql
SELECT
    customer_id,
    COALESCE(phone, 'Not Provided') AS phone
FROM customers;

If phone is NULL, the query displays Not Provided.

Use a default in calculations

default_discount.sql
SELECT
    product_name,
    price - COALESCE(discount, 0) AS final_price
FROM products;

If discount is NULL, it is treated as zero in this expression.

Key distinction: CAST() changes a value's data type; CASE WHEN chooses a result based on logic; COALESCE() selects the first non-NULL value.
