This topic explains how to handle missing values (NULL) and how to write conditions inside SQL queries. Four concepts to learn: NULL / IS NULL / IS NOT NULL, COALESCE(), CASE WHEN, and NULLIF().

1. NULL, IS NULL & IS NOT NULL

a. Understanding NULL

NULL represents a missing, unknown, or unavailable value in a database. It is different from:

ValueMeaning
NULLMissing or unknown value
0Actual numeric zero
''Empty string
'NULL'Text containing the word NULL

Example

Suppose the employees table contains:

employee_idemployee_namemanager_id
1RahulNULL
2Amit1
3Priya1
4NehaNULL

Here, NULL in manager_id means the employee has no recorded manager.

Important: NULL comparison

You cannot check NULL using normal comparison operators.

wrong.sql
-- Incorrect
SELECT *
FROM employees
WHERE manager_id = NULL;
right.sql
-- Correct
SELECT *
FROM employees
WHERE manager_id IS NULL;

To find employees whose manager is available:

is-not-null.sql
SELECT *
FROM employees
WHERE manager_id IS NOT NULL;

Why not use = NULL?

SQL uses three-valued logic: TRUE, FALSE, and UNKNOWN. When you compare a value with NULL, the result is generally UNKNOWN, not TRUE or FALSE.

null-equals-null.sql
SELECT NULL = NULL;

Result: NULL (unknown). Therefore, use IS NULL and IS NOT NULL.

b. IS NULL

IS NULL checks whether a column contains a missing value.

Example 1: Find employees without a manager

q.sql
SELECT *
FROM employees
WHERE manager_id IS NULL;

Example 2: Find customers without an email address

q.sql
SELECT *
FROM customers
WHERE email IS NULL;

Example 3: Find orders without a sales representative

q.sql
SELECT *
FROM orders
WHERE sales_rep_id IS NULL;

c. IS NOT NULL

IS NOT NULL checks whether a column contains a value.

Example 1: Find employees who have a manager

q.sql
SELECT *
FROM employees
WHERE manager_id IS NOT NULL;

Example 2: Find customers who have an email address

q.sql
SELECT *
FROM customers
WHERE email IS NOT NULL;

Example 3: Find orders assigned to a sales representative

q.sql
SELECT *
FROM orders
WHERE sales_rep_id IS NOT NULL;

IS NULL vs IS NOT NULL

OperatorPurpose
IS NULLFind missing values
IS NOT NULLFind available values
2. COALESCE()

COALESCE() returns the first non-NULL value from the provided arguments. It checks values from left to right.

syntax.sql
COALESCE(value1, value2, value3, ...)

COALESCE() — SQL Query Syntax Rules

query.sql
SELECT
    column1,
    COALESCE(column2, default_value) AS alias_name
FROM table_name;

Important syntax points:

  1. Write COALESCE() inside the SELECT statement, like a column.
  2. Use a comma , between columns and COALESCE().
  3. Inside COALESCE(), separate the column and default value using a comma.
  4. Give an alias using AS after the closing bracket ).
  5. Do not put a comma before FROM.
  6. No special WHERE condition is required.

Example: Replace a NULL salary with zero

query.sql
SELECT
    employee_name,
    salary,
    COALESCE(salary, 0) AS updated_salary
FROM employees;
Remember: COALESCE() is written like a column expression, not as a separate SQL clause.

Example 1: Replace NULL with default text

q.sql
SELECT
    employee_name,
    COALESCE(manager_id::TEXT, 'No Manager') AS manager
FROM employees;

Possible output:

employee_namemanager
RahulNo Manager
Amit1
Priya1
  • If manager_id is NULL, it returns 'No Manager'.
  • Otherwise, it returns the manager ID as text.
  • ::TEXT converts the integer into text because both COALESCE arguments must have compatible data types.

Example 2: Replace NULL salary with zero

q.sql
SELECT
    employee_name,
    COALESCE(salary, 0) AS salary
FROM employees;

If salary is NULL, the query displays 0.

Example 3: Multiple fallback values

q.sql
SELECT
    COALESCE(email, 'No Email Available') AS contact
FROM customers;

You can provide multiple fallback values:

q.sql
SELECT
    COALESCE(email, phone, 'No Contact Available') AS contact
FROM customers;
  1. Email if available.
  2. Otherwise, phone if available.
  3. Otherwise, 'No Contact Available'.
Note: the example assumes a phone column exists; check your table schema before running it.

Important points

  • COALESCE() does not update the original table.
  • It only changes the value displayed in the query result.
  • It returns the first non-NULL value.
  • All arguments must have compatible data types.
3. CASE WHEN

CASE WHEN is used to apply conditional logic in SQL. Think of it like if / else if / else in JavaScript. SQL checks conditions from top to bottom, and the first matching condition is returned.

syntax.sql
CASE
    WHEN condition1 THEN result1
    WHEN condition2 THEN result2
    ELSE default_result
END

Example 1: Categorize employees based on salary

q.sql
SELECT
    employee_name,
    salary,
    CASE
        WHEN salary >= 100000 THEN 'High Salary'
        WHEN salary >= 70000 THEN 'Medium Salary'
        ELSE 'Low Salary'
    END AS salary_category
FROM employees;

Possible output:

employee_namesalarysalary_category
Rahul120000High Salary
Amit85000Medium Salary
Priya50000Low Salary
  • Salary greater than or equal to 100000 → High Salary.
  • Otherwise, salary greater than or equal to 70000 → Medium Salary.
  • Otherwise → Low Salary.

Example 2: Categorize orders based on status

q.sql
SELECT
    order_id,
    status,
    CASE
        WHEN status = 'Delivered' THEN 'Completed'
        WHEN status = 'Cancelled' THEN 'Failed'
        WHEN status = 'Pending' THEN 'In Progress'
        ELSE 'Other'
    END AS order_category
FROM orders;

Example 3: CASE WHEN with NULL

q.sql
SELECT
    employee_name,
    CASE
        WHEN manager_id IS NULL THEN 'Top Level Employee'
        ELSE 'Has Manager'
    END AS manager_status
FROM employees;

This checks whether the employee has a manager.

Example 4: CASE WHEN with UPDATE

You can also use CASE WHEN to update values conditionally.

q.sql
UPDATE employees
SET salary =
    CASE
        WHEN department_id = 1 THEN salary + 10000
        WHEN department_id = 2 THEN salary + 5000
        ELSE salary
    END;
  • Increases salary by 10000 for department 1.
  • Increases salary by 5000 for department 2.
  • Leaves other employees' salaries unchanged.
Important: this is an actual UPDATE. It modifies the table, so use a suitable WHERE condition if you only intend to update selected employees.
4. NULLIF()

NULLIF() compares two values. If both values are equal, it returns NULL. Otherwise, it returns the first value.

syntax.sql
NULLIF(value1, value2)

Example 1: Basic example

q.sql
SELECT NULLIF(10, 10);   -- NULL
SELECT NULLIF(10, 20);   -- 10

Example 2: Avoid division by zero

Suppose you want to calculate revenue per unit.

q.sql
SELECT
    product_name,
    price / NULLIF(stock_quantity, 0) AS revenue_per_unit
FROM products;

If stock_quantity is zero, NULLIF() returns NULL instead of zero, avoiding a division-by-zero error.

5. COALESCE vs CASE WHEN vs NULLIF

These functions may look similar, but they solve different problems.

FunctionPurposeExample

Recommended learning order

  1. Understand NULL and three-valued logic.
  2. Learn IS NULL and IS NOT NULL.
  3. Learn COALESCE() to handle missing values.
  4. Learn CASE WHEN for conditional logic.
  5. Learn NULLIF() for special cases such as division by zero.
Recommendation: focus most on IS NULL, COALESCE() and CASE WHEN. These are particularly useful when writing real-world SQL queries and backend APIs.
