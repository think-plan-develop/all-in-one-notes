Window Functions in SQL

A window function calculates across a set of related rows while keeping every individual row in the result. Use it for ranking, running totals, previous/next values, and comparisons.

Understand with an example

Suppose we have an Employees table:

To rank every employee by salary, highest first:

salary_rank.sql
SELECT
    name,
    department,
    salary,
    RANK() OVER (ORDER BY salary DESC) AS salary_rank
FROM Employees;

Result:

Notice: Amit and Karan both have rank 1, and the next rank is 3. The rows are ranked without combining them or losing employee details.

Window function syntax

window_syntax.sql
function_name() OVER (
    PARTITION BY column_name
    ORDER BY column_name
)
FunctionWhat to calculate: SUM(), RANK(), LAG()
PARTITION BYSplit rows into groups for calculation. It does not collapse rows.
ORDER BYSet the order rows are ranked or processed within the window.
3

Most important window functions

A. ROW_NUMBER() — unique row number

Assigns a unique sequential number to each row.

row_number.sql
SELECT
    name,
    salary,
    ROW_NUMBER() OVER (ORDER BY salary DESC) AS rn
FROM Employees;

Even if salaries tie, row numbers are different. For predictable tie ordering, add a unique column to ORDER BY.

Use cases: pagination, finding the latest record, and removing duplicates.

B. RANK() — ranking with gaps

rank.sql
SELECT
    name,
    salary,
    RANK() OVER (ORDER BY salary DESC) AS rnk
FROM Employees;

For salaries 70000, 70000, 60000, ranks are 1, 1, 3.

C. DENSE_RANK() — ranking without gaps

dense_rank.sql
SELECT
    name,
    salary,
    DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk
FROM Employees;

For salaries 70000, 70000, 60000, ranks are 1, 1, 2.

D. SUM() — running total

Assume a Transactions table with amount and transaction_date.

running_total.sql
SELECT
    transaction_date,
    amount,
    SUM(amount) OVER (
        ORDER BY transaction_date
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS running_total
FROM Transactions;

Amounts 100, 200, 300 produce running totals 100, 300, 600.

E. LAG() and LEAD() — previous and next rows

LAG() gets a value from a previous row; LEAD() gets a value from a following row.

lag_lead.sql
SELECT
    transaction_date,
    amount,
    LAG(amount) OVER (ORDER BY transaction_date) AS previous_amount,
    LEAD(amount) OVER (ORDER BY transaction_date) AS next_amount
FROM Transactions;

Useful for comparing this month's sales with last month's, or spotting changes between consecutive records.

What does PARTITION BY do?

To rank employees within each department instead of across the whole company:

department_rank.sql
SELECT
    name,
    department,
    salary,
    DENSE_RANK() OVER (
        PARTITION BY department
        ORDER BY salary DESC
    ) AS dept_rank
FROM Employees;

Result:

namedepartmentsalarydept_rank
AmitIT70,0001
KaranIT70,0001
RahulIT50,0002
NehaHR60,0001
PriyaHR40,0002
The ranking restarts at 1 for each department.

Window function vs. GROUP BY

This is one of the most important differences to understand.

Using GROUP BY

Returns one row per department.

Using a window function

Keeps every employee row and adds the department average.

group_by.sql
SELECT department, AVG(salary) AS avg_salary
FROM Employees
GROUP BY department;
departmentavg_salary
IT63,333.33
HR50,000
department_average.sql
SELECT
    name,
    department,
    salary,
    AVG(salary) OVER (PARTITION BY department) AS dept_avg_salary
FROM Employees;

Remember: GROUP BY combines rows into groups; window functions calculate across related rows while preserving individual rows.

Window functions generally cannot be used directly in the WHERE clause at the same query level. Use a CTE or subquery to filter their results.

Example: find one highest-paid employee per department. Salary ties are broken by emp_id.

top_employee_per_department.sql
WITH ranked_employees AS (
    SELECT
        name,
        department,
        salary,
        ROW_NUMBER() OVER (
            PARTITION BY department
            ORDER BY salary DESC, emp_id
        ) AS rn
    FROM Employees
)
SELECT name, department, salary
FROM ranked_employees
WHERE rn = 1;
