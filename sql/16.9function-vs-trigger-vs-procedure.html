2. Function — Detailed Syntax

A function is a reusable block of SQL logic that returns a value, table, or void.

syntax.sql
CREATE OR REPLACE FUNCTION function_name(
    parameter_name datatype
)
RETURNS return_datatype
LANGUAGE plpgsql
AS $$
BEGIN

    -- SQL statements

    RETURN value;

END;
$$;

Important syntax components

KeywordPurpose
CREATE FUNCTIONCreates a function
OR REPLACEReplaces an existing definition
RETURNSDefines the return type
LANGUAGE plpgsqlSpecifies the language
DECLAREDefines local variables (optional)
BEGIN / ENDContains function logic
RETURNReturns the result

Example: function with IN parameter

get_employee_salary.sql
CREATE OR REPLACE FUNCTION get_employee_salary(
    emp_id INT
)
RETURNS NUMERIC
LANGUAGE plpgsql
AS $$
DECLARE
    emp_salary NUMERIC;
BEGIN

    SELECT salary
    INTO emp_salary
    FROM employees
    WHERE employee_id = emp_id;

    RETURN emp_salary;

END;
$$;

-- Call
SELECT get_employee_salary(1);

Common function return types

Return typeUsage
RETURNS INTReturn an integer
RETURNS TEXTReturn text
RETURNS BOOLEANReturn true/false
RETURNS NUMERICReturn decimal value
RETURNS TABLE(...)Return multiple rows and columns
RETURNS VOIDReturn no meaningful value

Example: RETURNS TABLE

get_employees.sql
CREATE OR REPLACE FUNCTION get_employees()
RETURNS TABLE (
    emp_id INT,
    emp_name VARCHAR,
    emp_salary NUMERIC
)
LANGUAGE plpgsql
AS $$
BEGIN

    RETURN QUERY
    SELECT employee_id, employee_name, salary
    FROM employees;

END;
$$;

-- Call
SELECT * FROM get_employees();
3. Trigger — Detailed Syntax

A trigger automatically executes a trigger function when a specific event occurs on a table or view.

Important: PostgreSQL triggers require a separate function. You cannot directly write the trigger’s business logic inside CREATE TRIGGER.

Step 1: create trigger function

trigger_function.sql
CREATE OR REPLACE FUNCTION trigger_function_name()
RETURNS TRIGGER
LANGUAGE plpgsql
AS $$
BEGIN

    -- Trigger logic

    RETURN NEW;

END;
$$;

Step 2: create trigger

trigger.sql
CREATE TRIGGER trigger_name
BEFORE INSERT OR UPDATE OR DELETE
ON table_name
FOR EACH ROW
EXECUTE FUNCTION trigger_function_name();

Important syntax differences

KeywordPurpose
RETURNS TRIGGERMandatory return type for trigger functions
NEWContains new record
OLDContains existing record
BEFOREExecutes before the operation
AFTERExecutes after the operation
FOR EACH ROWExecutes for every affected row
FOR EACH STATEMENTExecutes once per SQL statement
WHENOptional condition for trigger execution
EXECUTE FUNCTIONConnects trigger to its function

Example: automatically update timestamp

Step 1 — trigger function

update_timestamp.sql
CREATE OR REPLACE FUNCTION update_timestamp()
RETURNS TRIGGER
LANGUAGE plpgsql
AS $$
BEGIN

    NEW.updated_at = CURRENT_TIMESTAMP;

    RETURN NEW;

END;
$$;

Step 2 — create trigger

trigger.sql
CREATE TRIGGER employee_update_trigger
BEFORE UPDATE
ON employees
FOR EACH ROW
EXECUTE FUNCTION update_timestamp();

Step 3 — update employee

update.sql
UPDATE employees
SET salary = 85000
WHERE employee_id = 1;

PostgreSQL automatically executes the trigger and updates updated_at.

OLD vs NEW

OperationOLDNEW
INSERTNot availableNew record
UPDATEPrevious recordUpdated record
DELETEDeleted recordNot available

Trigger timing

TypeWhen to use

INSTEAD OFHandling operations on views
4. Stored Procedure — Detailed Syntax

A stored procedure is a reusable block of SQL statements designed to perform database operations.

syntax.sql
CREATE OR REPLACE PROCEDURE procedure_name(
    IN parameter_name datatype
)
LANGUAGE plpgsql
AS $$
BEGIN

    -- SQL operations

END;
$$;

Unlike functions, procedures do not require a RETURNS clause.

Example: update employee salary

update_salary.sql
CREATE OR REPLACE PROCEDURE update_salary(
    IN emp_id INT,
    IN new_salary NUMERIC
)
LANGUAGE plpgsql
AS $$
BEGIN

    UPDATE employees
    SET salary = new_salary
    WHERE employee_id = emp_id;

END;
$$;

-- Call
CALL update_salary(1, 90000);

Procedure parameters

ParameterPurpose
INReceives input
OUTReturns output
INOUTReceives and returns modified value
Main advantage: procedures can perform transaction control using COMMIT and ROLLBACK in supported execution contexts.
5. Function vs Trigger — Syntax Differences

This is particularly important because both use CREATE FUNCTION, but they serve different purposes.

SyntaxFunctionTrigger Function
DeclarationCREATE FUNCTIONCREATE FUNCTION
Return typeRETURNS INT, TEXT, TABLE, etc.RETURNS TRIGGER
ParametersNormal parametersNo normal parameters
Data accessExplicit SQL queriesNEW and OLD
ExecutionCalled using SELECTCalled by a trigger
Return statementRETURN valueRETURN NEW or RETURN OLD
Trigger required?NoYes

Remember this distinction

Normal function — called using SELECT:

normal.sql
CREATE FUNCTION get_salary(emp_id INT)
RETURNS NUMERIC

Trigger function — executed through CREATE TRIGGER:

trigger-fn.sql
CREATE FUNCTION update_salary()
RETURNS TRIGGER

7. Useful Management Commands
commands.sql
-- Delete function
DROP FUNCTION get_employee_salary(INT);

-- Delete procedure
DROP PROCEDURE update_salary(INT, NUMERIC);

-- Delete trigger
DROP TRIGGER employee_update_trigger ON employees;

-- Disable trigger
ALTER TABLE employees
DISABLE TRIGGER employee_update_trigger;

-- Enable trigger
ALTER TABLE employees
ENABLE TRIGGER employee_update_trigger;
8. Final Revision — Remember These Three

1. FUNCTION — input → logic → return result

function.sql
SELECT get_employee_salary(1);

Used for calculations, fetching records and reusable logic.

2. TRIGGER — database event → automatic execution

trigger.sql
UPDATE employees
SET salary = 90000
WHERE employee_id = 1;

Used for audit logs, validation and automatic updates.

3. STORED PROCEDURE — call → multiple operations

procedure.sql
CALL update_salary(1, 90000);

Used for transactions, order processing and business workflows.

Interview tip: the most important difference is that a function returns a result, a trigger function responds automatically to database events, and a stored procedure performs explicitly requested operations.
