React Installation Using Vite npm & npx

Step-by-step guide to creating a React app with Vite using both npm and npx

Step-by-Step npm vs npx Common Examples
⚡
Vite: A fast build tool used to scaffold modern React projects.
📦
npm: Node Package Manager — installs and manages project dependencies.
▶️
npx: Node Package Execute — runs packages directly without permanent install.
🌐
localhost:5173: Default local server address where the Vite app runs.
Step-by-Step Installation
🛠️ Using npm (Recommended)
terminal
# 1. Verify Node.js
node -v
npm -v

# 2. Create project
npm create vite@latest
# → choose Project Name → React → JavaScript/TypeScript

# 3. Go to project folder
cd my-app

# 4. Install packages
npm install

# 5. Start development server
npm run dev

# 6. Open in browser
# http://localhost:5173
⚡ Using npx
terminal
# 1. Verify Node.js
node -v
npm -v

# 2. Create project (template specified directly)
npx create-vite@latest my-app --template react

# 3. Go to project folder
cd my-app

# 4. Install packages
npm install

# 5. Start development server
npm run dev

# 6. Open in browser
# http://localhost:5173

📦 npm
  • Installs & manages packages
  • Saves packages in node_modules
  • Updates package.json
  • Best for project dependencies
▶️ npx
  • Executes packages directly
  • No permanent installation
  • Doesn't update package.json
  • Best for one-time CLI commands
💡 Memory Trick: npm = Install 📦  |  npx = Execute ▶️
