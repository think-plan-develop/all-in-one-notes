1. Semantic vs Non-Semantic HTML

Semantic HTML uses elements that clearly describe their meaning, such as <header>, <nav>, <main>, <article>, and <footer>. It improves readability, SEO, and accessibility.

Non-semantic HTML uses generic elements that don't describe their purpose, mainly <div> and <span>.

2. Difference between <div> and <span> ⭐

<div> and <span> are non-semantic container elements, but their default display behavior is different.

  • <div> → block-level element; normally starts on a new line.
  • <span> → inline element; normally stays in the same line.
  • Both are commonly used with CSS and JavaScript.
html
<div>This is a div</div>

<p>Hello <span>world</span></p>

Here, <div> creates a separate block, while <span> is used to style or group part of the text.

  • <div> is a block-level container, whereas <span> is an inline container. Both are non-semantic elements mainly used for grouping and styling content.
3. Difference between id and class ⭐

id

Both id and class are attributes used to identify/select HTML elements. An id is generally intended to uniquely identify one element on a page.

html
<div id="header">Header</div>

CSS:

css
#header {
  color: red;
}

JavaScript:

js
document.getElementById("header");

class

A class can be assigned to multiple elements.

html
<p class="text">Hello</p>
<p class="text">World</p>

CSS:

css
.text {
  color: blue;
}

You can also give one element multiple classes:

html
<div class="card active large"></div>
  • id is generally used to uniquely identify an element, while class is reusable and can be applied to multiple elements. Classes are commonly used for CSS styling and reusable UI behavior.
⚠️ An id should be unique within the document, whereas the same class can appear many times.
4. Block-level vs Inline Elements ⭐

Block-level elements

A block-level element normally:

  • Starts on a new line
  • Takes the available width by default
  • Can contain other elements depending on the HTML rules

Examples:

html
<div></div>
<p></p>
<section></section>
<h1></h1>
<header></header>
html
<div>First</div>
<div>Second</div>

Output conceptually:

First Second

Each <div> starts on a new line.

Inline elements

Inline elements normally:

  • Stay on the same line
  • Take only the width required by their content
  • Are commonly used inside text

Examples:

html
<span></span>
<a></a>
<strong></strong>
<em></em>
html
<p>Hello <span>Shivam</span> how are you?</p>

The <span> remains within the same line.

  • Block-level elements normally start on a new line and occupy the available width, while inline elements remain in the same line and take only the required width.

CSS can change this behavior:

css
div {
  display: inline;
}

span {
  display: block;
}
  • Block/inline is default behavior, and CSS display can change it.
5–14. Forms, Inputs & Accessibility
5

Purpose of the alt attribute

alt provides alternative text for an image when it cannot be displayed and helps screen readers describe the image.

html
<img src="profile.jpg" alt="User profile photo">
6

Why use <label> with forms?

<label> describes a form field and improves accessibility. Clicking the label can also focus the associated input.

html
<label for="email">Email</label>
<input id="email" type="email">
7

disabled vs readonly vs required

  • disabled → user cannot interact with it and its value isn't submitted.
  • readonly → user cannot edit it, but its value can be submitted.
  • required → user must provide a value before submitting.
html
<input disabled>
<input readonly value="ABC">
<input required>
8

GET vs POST in HTML forms

GET

Sends form data in the URL. Commonly used for retrieving/filtering data.

POST

Sends data in the request body. Commonly used for submitting or creating data.

9

HTML5 input types

Common HTML5 input types include:

email number date time url tel range color search file
html
<input type="email">
<input type="date">
<input type="number">
10

<button> vs <input type="submit">

<button> is more flexible because it can contain text or other HTML content and can have different types.

html
<button type="submit">Submit</button>

<input type="submit"> is specifically a submit control.

html
<input type="submit" value="Submit">
11

Semantic layout elements

<header>, <nav>, <main>, <section>, <article>, and <footer> are semantic HTML elements that describe different parts of a webpage.

html
<header>Page header</header>
<nav>Navigation</nav>
<main>Main content</main>
<section>Section</section>
<article>Article</article>
<footer>Footer</footer>

They make the document structure easier to understand for developers, search engines, and assistive technologies.

12

Accessibility in HTML

Accessibility means creating websites that can be used by people with different abilities, including users who rely on screen readers, keyboards, or other assistive technologies.

13

Purpose of aria-* attributes

aria-* attributes provide additional accessibility information when normal HTML semantics aren't sufficient.

html
<button aria-label="Close menu">X</button>
14

Why is name important in form inputs?

The name attribute identifies the field when form data is submitted.

html
<input name="email" type="email">

The submitted data can contain:

email=user@example.com
⚠️ Without name, the input's value generally isn't included in normal form submission.
15. HTML vs JSX ⭐ React-specific

HTML is the standard markup language for webpages, while JSX is a JavaScript syntax extension commonly used with React.

jsx
<div className="container">
  {user.name}
</div>

JSX allows JavaScript expressions inside markup and uses React-specific syntax such as className instead of class.

16. What is box-sizing: border-box ⭐⭐⭐

Default: content-box

This is an important CSS box-model interview question.

By default, CSS uses:

css
box-sizing: content-box;

With content-box, the specified width applies only to the content. For example:

css
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}

Actual width becomes:

Content = 200px Padding = 20 + 20 = 40px Border = 5 + 5 = 10px Total = 200 + 40 + 10 = 250px
200px content
(box grows to 250px total)
⚠️ With content-box (the default), padding and border are added on top of the declared width.

With border-box

css
.box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}

Now the 200px includes content + padding + border.

Total width = 200px Padding + Border are included inside the 200px

So the content area becomes smaller:

Total width = 200px Padding = 40px Border = 10px Content = 150px

content-box (default)

200px content + 40px padding + 10px border = 250px total

border-box

200px total — padding + border eat into it, leaving 150px content

Common real-world usage

Developers commonly apply:

css
* {
  box-sizing: border-box;
}

This makes width and height calculations more predictable because padding and borders are included in the declared dimensions.

  • box-sizing: border-box makes the declared width and height include the element's padding and border, making CSS layout calculations easier and more predictable.
