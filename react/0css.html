1. The CSS Box Model ⭐⭐⭐⭐⭐

Every HTML element is treated as a rectangular box consisting of four parts:

Content
Content
Padding
Border
Margin
  1. Content → actual text/image
  2. Padding → space between content and border
  3. Border → boundary around the element
  4. Margin → space outside the element
css
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
  margin: 10px;
}

With default content-box:

Content = 200px Padding = 40px Border = 10px Total width = 250px
  • The CSS box model consists of content, padding, border, and margin. The total size of an element depends on these four parts.
2. margin vs padding ⭐⭐⭐⭐⭐

The easiest way to remember: Padding = inside space, Margin = outside space.

css
.card {
  padding: 20px;
  margin: 20px;
}
Margin ┌───────────────┐ │ Border │ │ ┌───────────┐ │ │ │ Padding │ │ │ │ ┌───────┐ │ │ │ │ │Content│ │ │ │ │ └───────┘ │ │ │ └───────────┘ │ └───────────────┘

Padding

Creates space inside the element.

css
button {
  padding: 10px 20px;
}

The text gets more space inside the button.

Margin

Creates space outside the element.

css
button {
  margin: 20px;
}

It creates distance between the button and surrounding elements.

📌 Padding is part of the element's box, while margin creates space outside the box.
  • Padding creates space inside an element, between the content and border, while margin creates space outside the element, between it and other elements.
3. What does box-sizing: border-box do ⭐⭐⭐⭐⭐

By default: box-sizing: content-box; — the declared width applies only to the content.

css
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid;
}
/* Actual width: 200 + 40 + 10 = 250px */

With border-box, the 200px includes content + padding + border:

css
.box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid;
}
/* Total width = 200px */

content-box (default)

Total = 200 + 40 + 10 = 250px

border-box

Total stays 200px — padding/border eat into it

This is why many projects use:

css
* {
  box-sizing: border-box;
}
  • border-box makes the declared width and height include the content, padding, and border, making element sizing more predictable.
4. block vs inline vs inline-block ⭐⭐⭐⭐⭐

display: block

  • Starts on a new line
  • Usually takes the full available width
  • Width and height can be applied
css
.box {
  display: block;
  width: 200px;
  height: 100px;
}

Examples: <div>, <p>, <section>

display: inline

  • Stays in the same line
  • Takes only required width
  • width/height generally don't work as expected for normal inline boxes

Examples: <span>, <a>, <strong>

display: inline-block

Combination of both — stays on the same line like inline, allows width/height like block.

css
.box {
  display: inline-block;
  width: 200px;
  height: 100px;
}
DisplayNew line?Width/Height
blockYesYes
inlineNoGenerally no
inline-blockNoYes
  • block starts on a new line and accepts width/height, inline stays in the same line and generally doesn't accept width/height normally, while inline-block stays inline but allows width and height.

6. CSS Specificity ⭐⭐⭐⭐⭐

Specificity determines which CSS rule wins when multiple rules target the same element.

Inline styles ↓ ID ↓ Class / attribute / pseudo-class ↓ Element / pseudo-element
css
p { color: blue; }
.text { color: green; }
#title { color: red; }
html
<p id="title" class="text">Hello</p>

The color will be red because the ID selector has higher specificity.

  • CSS specificity is the priority system used by the browser to determine which conflicting CSS rule should be applied.
7. How does the CSS Cascade work?

The cascade is the process CSS uses to decide which rule should apply when multiple rules match an element. Important factors, in order:

  1. Origin and importance
  2. Cascade layers
  3. Specificity
  4. Source order

For rules with the same priority and specificity, the rule appearing later generally wins.

css
p { color: red; }
p { color: blue; }
/* result: blue — the second rule comes later */
  • The CSS cascade determines which styles win when multiple rules apply, considering factors such as importance, cascade layers, specificity, and source order.
8. relative vs absolute vs fixed vs sticky ⭐⭐⭐⭐⭐

position: relative

The element remains in the normal document flow and can be moved relative to its original position. It also establishes a positioning context for absolutely positioned descendants.

css
.box {
  position: relative;
  top: 20px;
}

position: absolute

Removed from normal document flow and positioned relative to its nearest positioned ancestor.

css
.parent { position: relative; }

.child {
  position: absolute;
  top: 0;
  right: 0;
}

If there is no suitable positioned ancestor, it is positioned relative to the initial containing block.

position: fixed

Positioned relative to the viewport and generally stays in the same place while scrolling.

css
.header {
  position: fixed;
  top: 0;
}

Common use:

  • Fixed navbar
  • Floating button
  • Chat button

position: sticky

Behaves like a normal element until a scroll threshold is reached, then sticks within its scrolling container.

css
.header {
  position: sticky;
  top: 0;
}

Common use: sticky headers, sticky table headings.

PositionNormal flowReference
relative✅Its original position
absolute❌Positioned ancestor
fixed❌Viewport
sticky✅ initiallyScroll/container boundaries
9. z-index and why it sometimes doesn't work

z-index controls the stacking order of overlapping elements. Generally, a higher stacking level appears above a lower one.

css
.modal {
  position: fixed;
  z-index: 1000;
}

Common reasons z-index appears not to work:

  • Element isn't positioned as expected.
  • A parent creates a separate stacking context.
  • Another ancestor has a higher stacking context.
  • z-index is being compared within different stacking contexts.
css
.parent {
  position: relative;
  z-index: 1;
}

.child {
  position: absolute;
  z-index: 9999;
}

The child's 9999 doesn't automatically put it above an element in another stacking context whose parent is above .parent.

  • z-index controls stacking order, but it works within stacking contexts. A very high z-index cannot necessarily escape its parent's stacking context.
10. What is Flexbox ⭐⭐⭐⭐⭐

Flexbox is a CSS layout system designed primarily for arranging elements in one dimension — either a row or a column.

css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}

It makes it easy to:

  • Align items
  • Distribute space
  • Create rows/columns
  • Build responsive layouts
11. justify-content vs align-items ⭐⭐⭐⭐⭐

This depends on the flex direction. For default flex-direction: row, the main axis is horizontal.

justify-content

Controls alignment along the main axis. Centers items horizontally when direction is row.

align-items

Controls alignment along the cross axis. Centers items vertically when direction is row.

  • justify-content → main axis
  • align-items → cross axis

If flex-direction: column, the axes swap orientation:

Main axis → vertical Cross axis → horizontal
12. Main axis and cross axis in Flexbox

Flexbox has two axes. The main axis is determined by flex-direction; the cross axis is perpendicular to it.

row → main axis horizontal
→ → → main
↓ cross
column → main axis vertical
↓ main
→ cross
  • The main axis is determined by flex-direction, while the cross axis is perpendicular to it. justify-content works on the main axis and align-items on the cross axis.
13. Flexbox vs Grid ⭐⭐⭐⭐

Flexbox — one-dimensional

Row OR Column. Good for navbars, buttons, small component layouts, aligning items.

Grid — two-dimensional

Rows + Columns. Good for dashboards, page layouts, product grids, complex layouts.

  • Flexbox is mainly for one-dimensional layouts, while CSS Grid is designed for two-dimensional row-and-column layouts.
14. What does flex: 1 mean?

flex: 1 is shorthand for flex: 1 1 0%; — the item can grow and shrink and starts with a flex basis of 0%, so available space is distributed among flex items according to their flex factors.

css
.container { display: flex; }
.box { flex: 1; }
┌────────┬────────┬────────┐ │ Box 1 │ Box 2 │ Box 3 │ └────────┴────────┴────────┘

They will generally share the available space equally.

15. What are Media Queries?

Media queries allow CSS to apply different styles based on conditions such as viewport width.

css
.container { display: flex; }

@media (max-width: 768px) {
  .container {
    flex-direction: column;
  }
}

When the viewport is 768px or smaller, the layout changes to a column. Commonly used for responsive design.

17. px vs % vs em vs rem ⭐⭐⭐⭐

px

A fixed CSS pixel unit. Useful when you need a specific size.

%

Usually relative to the relevant containing/reference dimension.

em

Relative to the parent's computed font size for font sizing; can compound through nested elements.

rem

Relative to the root (html) element's font size.

If root font size is 16px: 2rem = 32px

  • px is a fixed CSS unit, % is relative to a containing/reference dimension, em is relative to font sizing in the element's context, and rem is relative to the root element's font size.
18. Pseudo-class vs pseudo-element ⭐⭐⭐⭐

Pseudo-class — represents a state

css
button:hover { background: black; }
input:focus { border: 1px solid blue; }
:hover:focus:active:checked:nth-child()

Pseudo-element — targets a part

css
p::first-letter { font-size: 30px; }
p::before { content: "★"; }
::before::after::first-letter::first-line
  • Pseudo-class = state · Pseudo-element = part
19. :nth-child() vs :nth-of-type() ⭐⭐⭐⭐

This is a common tricky question.

html
<div>
  <p>One</p>
  <span>Two</span>
  <p>Three</p>
</div>

:nth-child()

Looks at position among all sibling elements.
p:nth-child(2) selects nothing here — the 2nd child is <span>.

:nth-of-type()

Looks at position among siblings of the same element type.
p:nth-of-type(2) selects <p>Three</p>.

  • :nth-child() → position among ALL siblings
  • :nth-of-type() → position among SAME element type
20. Centering an element horizontally & vertically ⭐⭐⭐⭐⭐

Flexbox (most common)

css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}
html
<div class="container">
  <div class="box">Hello</div>
</div>

For the default flex-direction: row: justify-content: center → horizontal, align-items: center → vertical.

Grid

css
.container {
  display: grid;
  place-items: center;
}

place-items: center centers the item in both axes.

  • The easiest modern way is Flexbox using justify-content: center and align-items: center. CSS Grid can also center an element using place-items: center.
