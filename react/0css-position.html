✅ Remember:
  • Choose one row; replace 0 with 16px for space from the edge.
  • 50% places the child's starting edge halfway across the parent; translate(-50%) shifts it back by half its own size.
  • Use position: fixed instead of absolute to position relative to the viewport in typical layouts.
📍 2. CSS Positioning
The Five Position Values
PositionNormal Layout Space?Positioned Relative ToCommon Use
static✅ YesNormal document flowDefault positioning
relative✅ YesIts original positionSmall offsets; reference for absolute children
absolute❌ NoNearest ancestor whose position is not static*Badges, icons, overlays
fixed❌ NoUsually the viewport*Floating buttons, fixed headers
sticky✅ YesNearest ancestor with a scrolling mechanismSticky headers, sidebar navigation

* Properties such as transform can also create a containing block and affect absolute or fixed positioning.

positioning.css
.element {
  position: absolute;

  top: 10px;
  right: 20px;
  bottom: auto;
  left: auto;

  z-index: 10;
}
⚠️ Remember: top, right, bottom, and left do not reposition a static element.
↔️ 3. relative — Move from the Original Position
relative.css
.box {
  position: relative;
  top: 10px;  /* Moves down */
  left: 20px; /* Moves right */
}

The original space stays reserved. Other elements do not move to fill it.

✅ Most common use: establishing a reference for an absolutely positioned child.
📌 4. absolute — Position Inside a Parent
Card.html
<div class="card">
  <span class="badge">New</span>
  <h3>Product</h3>
</div>
badge.css
.card {
  position: relative;
  padding: 24px;
  border: 1px solid #ccc;
}

.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
✅ Remember: parent → relative; child → absolute. Without a qualifying ancestor, the child uses the initial containing block.

🖼️ Cover the entire parent

overlay.css
.overlay {
  position: absolute;
  inset: 0; /* top, right, bottom, left: 0 */
  background: rgb(0 0 0 / 40%);
}

⊙ Center an absolute element

center.css
.child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
📝 Why the transform: top/left move its top-left corner to the parent's center. translate shifts it back by half its own size.
📌 5. fixed — Stay in Place While the Page Scrolls
help-button.css
.help-button {
  position: fixed;
  right: 20px;
  bottom: 20px;
  z-index: 100;
}

🧷 Fixed header

fixed-header.css
.header {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  height: 64px;
  z-index: 100;
}

main {
  padding-top: 64px; /* Prevents content hiding behind header */
}
⚠️ Fixed elements do not reserve layout space — that's why main needs matching padding-top.
📎 6. sticky — Scroll Normally, Then Stick
sticky.css
.header {
  position: sticky;
  top: 0;
  z-index: 100;
  background: white;
}

A sticky element stays in normal flow, sticks at its threshold, and remains constrained by its containing block.

📝 If sticky doesn't work, check:
  • Have you provided a threshold such as top: 0?
  • Does it have enough room to move inside its parent?
  • Does an ancestor have overflow: auto, scroll, or hidden, changing which ancestor controls sticking?
🗂️ 7. z-index — Control Overlapping
z-index.css
.header {
  position: sticky;
  top: 0;
  z-index: 100;
}

.modal-overlay {
  position: fixed;
  inset: 0;
  z-index: 1000;
}
✅ Higher z-index appears above lower values within the same stacking context.
⚠️ A child with z-index: 99999 cannot necessarily appear above another parent's stacking context.

📋 Common stacking-context creators

  • Positioned elements with a non-auto z-index.
  • position: fixed or sticky.
  • transform other than none.
  • opacity below 1.
💡 z-index also works on flex and grid items without requiring positioning.
📱 8. Screen Resolution vs CSS Viewport
Responsive CSS uses viewport dimensions in CSS pixels — not the physical pixel resolution of the screen. A phone may have a physical width of 1170px but a viewport width around 390 CSS pixels at a device pixel ratio of 3.
index.html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
MeasurementMeaning
Physical resolutionActual display pixels, such as 1920 × 1080
CSS viewportAvailable browser layout area in CSS pixels
Device pixel ratioRatio of physical pixels to CSS pixels
Media-query widthTests viewport width
📝 Note: browser zoom and window size can affect the available CSS viewport.
📏 9. Practical Responsive Breakpoints
These are example layout ranges, not guaranteed device categories. Choose breakpoints where your content needs to change.
Viewport WidthTypical Layout
Below 480pxCompact phone layout
480px–767pxWider phone / small viewport
768px–1023pxTablet-sized layout
1024px–1279pxSmall desktop layout
1280px–1535pxWide desktop layout
1536px and aboveExtra-wide layout

📱 Mobile-first CSS

mobile-first.css
/* Base: all widths, starting with mobile */
.container {
  width: 100%;
  padding-inline: 16px;
}

.grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* 768px and wider */
@media (min-width: 768px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* 1024px and wider */
@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

/* 1280px and wider */
@media (min-width: 1280px) {
  .container {
    max-width: 1200px;
    margin-inline: auto;
  }
}
✅ Rules from smaller breakpoints still apply unless a later rule overrides them.
🔍 10. Media-Query Syntax
RequirementCSS
768px and wider@media (min-width: 768px)
767px and narrower@media (max-width: 767px)
From 768px up to, but excluding, 1024px@media (768px <= width < 1024px)
Landscape viewport@media (orientation: landscape)
Viewport height up to 600px@media (max-height: 600px)
responsive-button.css
/* Move a floating button closer to the edges on small screens */
.help-button {
  position: fixed;
  right: 24px;
  bottom: 24px;
}

@media (max-width: 480px) {
  .help-button {
    right: 12px;
    bottom: 12px;
  }
}
