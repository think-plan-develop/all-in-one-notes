🟩 Nginx — Web Server, Reverse Proxy & API Gateway

1What is Nginx — and what jobs can it do?
Nginx (pronounced “engine-ex”) is a web server that receives requests from browsers and either serves files or forwards requests to a backend application.

For your React + Node.js application, it can do these jobs:

🗂️

Web server

Serves your React build files: HTML, CSS, JavaScript and images

🔀

Reverse proxy ⭐

Receives API requests and forwards them to your Node.js server

⚖️

Load balancer

Distributes requests across multiple backend instances

🔒

HTTPS handling

Uses SSL/TLS certificates to provide secure connections

💾

Caching

Stores reusable responses to reduce backend work

2Routing requests to your services

Where the rules liveYou configure these routing rules in Nginx.

4Can Nginx act as an API gateway? ⭐ Important
Yes — Nginx can act as a basic API gateway, depending on how you configure it.

An API gateway is the entry point for clients to access backend services. Nginx can perform that role by routing requests:

Incoming requestDestination
/api/auth/*Auth service — port 3001
/api/properties/*Property service — port 3002
/api/payments/*Payment service — port 3003

Along with routing, Nginx can handle load balancing, HTTPS, rate limiting and request-size limits.

5Reverse proxy vs API gateway

The distinction is:

🔀 Reverse proxy

describes forwarding requests to backend servers.

🚪 API gateway

describes managing access to backend APIs, often with routing, authentication and traffic policies.

RememberNginx is the software; API gateway is a role it can perform.
Beyond NginxAdvanced API management features — such as developer portals, API subscriptions and usage billing — typically require additional tools or a dedicated gateway product.
6Interview answer ⭐ Important

“Nginx is primarily a web server and reverse proxy, but we can configure it as an API gateway for routing, load balancing, TLS termination and rate limiting.”
