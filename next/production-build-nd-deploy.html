🧪
No rebuild on start: npm start serves the existing build only.

NEXT_PUBLIC_: visible to the browser and fixed at build time.

🛠️
Process manager: hosting platform or PM2 keeps the server running.
⚙️ 1. Development vs Production
Three Commands, Three Purposes
CommandPurpose
npm run devRuns the development server with automatic updates while coding
npm run buildCreates an optimized production build
npm startRuns the production server using the existing build

The usual scripts in package.json are:

{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start"
  }
}
📦 2. Create a Production Build
Compile, Optimize, Prerender
npm run build

Next.js prepares your application for production, including compiling code, optimizing bundles, and prerendering eligible pages.

The default build output goes into .next/.

⚠️ If the build fails, fix the reported errors before deploying—for example, TypeScript errors, missing imports, or failed API requests during prerendering.
🧪 3. Test Production Locally
Build First, Then Start
npm run build
npm start

Open http://localhost:3000.

npm start does not rebuild your code. After changing code, build again to test the updated production version.
🔐 4. Environment Variables
Where Values Belong
EnvironmentWhere values belong
Local development.env.local
ProductionHosting platform’s environment settings or secret manager

Example variables:

API_BASE_URL=https://api.example.com
API_SECRET_KEY=your-secret
NEXT_PUBLIC_APP_NAME=My Store
  • Keep secrets server-side.
  • NEXT_PUBLIC_ values are visible to the browser and fixed during the build.
  • Variables used during prerendering must be available when building.
  • Server features may also need environment variables when the app runs. nextjs.org ↗
🚢 5. Deployment Flow
For a Typical Node.js Deployment
Typical Node.js deployment
STEP 1Upload or clone your project
→
STEP 2Install dependencies using npm ci
→
STEP 3Configure environment variables
→
STEP 4Run npm run build
→
STEP 5Run npm start using the host’s process management

On managed hosting, these steps are usually configured through the platform.

A normal Next.js application may need a running server for request-time rendering, Route Handlers, and other server features. Deploying only static files is a separate setup with limitations.
🛠️ 6. Common Problems
What to Check When Something Breaks
ProblemWhat to check
Production build not foundRun npm run build before npm start
Build fails but development worksRead the build error; check types, imports, and prerendered data fetching
API works locally but fails after deploymentProduction API URL, environment variables, and network access
Public environment variable still has the old valueRebuild and redeploy
Images fail to loadImage URL and images.remotePatterns
Server stops after closing the terminalUse the hosting platform’s process manager or a tool such as PM2
For your practice: first run npm run build and npm start locally, then check your pages, navigation, images, and API calls.
