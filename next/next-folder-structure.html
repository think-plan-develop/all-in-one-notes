File Tree Files You'll Use Most
🗂️ Your Next.js Project Files
next-project/— your project's main folder
  • .next/types/— generated TypeScript files, do not edit
    • TScache-life.d.ts— generated types for cache lifetime settings
    • TSroot-params.d.ts— generated types for root route parameters
    • TSroutes.d.ts— generated route types
    • TSvalidator.ts— checks route files export valid types
  • app/ ⭐— pages, layouts, and routing files
    • 🖼️favicon.ico— small website icon in the browser tab
    • #globals.css ⭐— global styles, body styling, CSS resets
    • ⚛layout.tsx ⭐— root wrapper: <html>, <body>, {children}
    • ⚛page.tsx ⭐— homepage displayed at /
  • node_modules/— installed packages (React, Next.js), do not edit
  • public/ ⭐— static files; public/logo.png → /logo.png
  • ◆.gitignore— files and folders Git should ignore
  • iAGENTS.md— project instructions for AI coding assistants
  • ✦CLAUDE.md— project instructions for Claude coding tools
  • 📒eslint.config.mjs— rules for code quality and common mistakes
  • TSnext-env.d.ts— generated Next.js TS declarations, do not edit
  • TSnext.config.ts ⭐— image config, redirects, rewrites
  • {}package-lock.json— exact installed dependency versions
  • {}package.json ⭐— dependencies & commands (dev, build, start)
  • 📒postcss.config.mjs— CSS processing plugins, commonly Tailwind
  • iREADME.md— project documentation & setup instructions
  • {}tsconfig.json— TS compiler settings, import aliases like @/*
