Definitions — SSR vs CSR
Q

What is Server-Side Rendering (SSR)?

ASSR means the server fetches the data and generates the HTML before sending it to the browser. The browser receives already-rendered content, so the initial data API call is not made directly by the browser.

Q

What is Client-Side Rendering (CSR)?

ACSR means the browser loads the JavaScript first and then fetches data from the API and renders the content on the client. The API request is therefore visible in the browser's Network tab.

💡 Your original code is already a modern Next.js Server Component API call. Below, the exact same API and variable names are used to show both approaches side by side.
1. Server-side API call — your current code

The code (Server Component)

app/user/page.tsx
export default async function User() {
  const response = await fetch(
    "https://jsonplaceholder.typicode.com/users"
  );

  const products = await response.json();

  return (
    <div>
      <h1>User List</h1>

      {products &&
        products.map((ele, index) => {
          return (
            <div key={index}>
              <p>
                {ele?.id} ::&nbsp;{ele.name}
              </p>
            </div>
          );
        })}
    </div>
  );
}

2. Client-side API call — exact same API

The code (Client Component)

app/user/page.tsx
"use client";

import { useEffect, useState } from "react";

export default function User() {
  const [products, setProducts] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch("https://jsonplaceholder.typicode.com/users")
      .then((response) => response.json())
      .then((data) => {
        setProducts(data);
        setLoading(false);
      });
  }, []);

  if (loading) {
    return <h1>Loading...</h1>;
  }

  return (
    <div>
      <h1>User List</h1>

      {products &&
        products.map((ele, index) => {
          return (
            <div key={index}>
              <p>
                {ele?.id} ::&nbsp;{ele.name}
              </p>
            </div>
          );
        })}
    </div>
  );
}

Now the flow is completely different

Browser

React renders users

And now Chrome DevTools → Network will show:

✅ https://jsonplaceholder.typicode.com/users

because the browser itself made the API call.
