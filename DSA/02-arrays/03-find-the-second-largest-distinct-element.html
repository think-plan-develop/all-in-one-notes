find-the-second-largest-distinct-element.js
const arr = [10, 40, 40, 25, 30];

let largest = -Infinity;
let second = -Infinity;

for (const x of arr) {
  if (x > largest) {
    second = largest;
    largest = x;
  } else if (x < largest && x > second) {
    second = x;
  }
}

console.log(second === -Infinity ? "No second largest" : second);
💡 Hints

Stuck? Open one hint at a time

Hint 1

Track two variables: largest and second, both starting at -Infinity.

Hint 2

If a value is bigger than largest, shift largest into second. Otherwise, if it is smaller than largest but bigger than second, update second.

📌 Noted Points

Remember these

  • ⚡ Duplicates: The condition x < largest stops a repeated maximum from becoming the second largest.
  • 💡 No answer: An array like [5, 5, 5] has no second distinct value, so handle that case.
  • ⚠️ No sorting: Sorting works but costs O(n log n). This single pass is O(n) time and O(1) extra space. Check [5], [5, 5, 5], and [-8, -2, -5, -2] (answer -5).
