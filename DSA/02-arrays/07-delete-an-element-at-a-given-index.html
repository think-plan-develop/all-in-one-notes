const arr = [10, 20, 30, 40, 50];
const index = 2;

for (let i = index; i < arr.length - 1; i++) {
  arr[i] = arr[i + 1];
}
arr.length = arr.length - 1;

console.log(arr);

📌 Noted Points

Remember these

  • ⚡ Shift forwards: When deleting, move elements from left to right so nothing is overwritten too early.
  • 💡 Valid index: The index must be an integer from 0 to arr.length - 1. Empty arrays have no valid deletion index. Worst-case time: O(n); auxiliary space: O(1).
  • ⚠️ Built-in: arr.splice(index, 1) removes the element in one call.
