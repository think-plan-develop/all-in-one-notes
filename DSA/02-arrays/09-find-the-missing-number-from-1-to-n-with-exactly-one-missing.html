Find the Missing Number from 1 to n

🟢 Easy⭐ ImportantArraysMath
An unsorted array contains n - 1 distinct integers from 1 to n, inclusive, with exactly one missing. Find that number; n = arr.length + 1. Assume n * (n + 1) and all sums stay within JavaScript's safe integer range.

const arr = [1, 2, 4, 5, 6];

const n = arr.length + 1;
const expected = (n * (n + 1)) / 2;

let actual = 0;
for (const x of arr) actual += x;

console.log(expected - actual);

Stuck? Open one hint at a time

Hint 1

Here n is arr.length + 1, because one number is missing.

Hint 2

The sum of 1 to n is n * (n + 1) / 2. Subtract the actual sum of the array.

📌 Noted Points

Remember these

  • ⚡ Find n first: n is one more than the array length, not arr.length.
  • 💡 XOR trick: XOR is an alternative, but JavaScript Number bitwise operators convert values to 32-bit integers. Use that version only with suitable bounds (for example, 1 <= n <= 2^31 - 1); do not treat it as an arbitrary-size integer solution.
  • ⚠️ O(n) time: One pass and O(1) space, with no sorting needed.
