Find the Union and Intersection of Two Arrays

🟢 EasyArraysSet
Using sets, find the union (all distinct values from both numeric arrays) and intersection (distinct values present in both). For the union, scan a followed by b; for the intersection, keep first-occurrence order from a. Do not modify either input.

find-the-union-and-intersection-of-two-arrays.js
const a = [1, 2, 3, 4];
const b = [3, 4, 5, 6];

const setB = new Set(b);

const union = [...new Set([...a, ...b])];
const intersection = [...new Set(a)].filter((x) => setB.has(x));

console.log("Union =", union);
console.log("Intersection =", intersection);

📌 Noted Points

Remember these

  • ⚡ Fast lookup: Under the usual expected O(1) hash-set lookup assumption, this approach takes O(n + m) expected time and O(n + m) extra space. Constant-time lookup is an analysis assumption, not a JavaScript worst-case guarantee.
  • 💡 Duplicates: Both results contain each value once, even if the inputs repeat values.
