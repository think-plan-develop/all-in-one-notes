find-the-majority-element.js
const arr = [3, 3, 4, 2, 3, 3, 5];

let candidate = null;
let count = 0;

for (const x of arr) {
  if (count === 0) candidate = x;
  count += x === candidate ? 1 : -1;
}

let total = 0;
for (const x of arr) {
  if (x === candidate) total++;
}
console.log(total > arr.length / 2 ? candidate : "No majority element");
💡 Hints

Stuck? Open one hint at a time

Hint 1

Keep a candidate and a count. Same value: count++. Different value: count--.

Hint 2

If count is 0 before processing an element, choose that element as the new candidate. Then update count. A cancellation during this step causes reselection on the next iteration.

Hint 3

Count the candidate again to confirm it really appears more than n / 2 times.

📌 Noted Points

Remember these

  • ⚡ Verify: The first pass only finds a candidate. Always confirm it with a second count.
  • 💡 Name: Boyer-Moore voting cancels pairs of different values. A true majority survives, but the candidate must be verified when a majority is not guaranteed. Both passes together take O(n) time and O(1) extra space; count directly instead of allocating an array with filter().
  • ⚠️ Strictly more: Exactly n / 2 occurrences is not a majority.
