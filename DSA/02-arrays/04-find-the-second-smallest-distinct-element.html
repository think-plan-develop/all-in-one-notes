find-the-second-smallest-distinct-element.js
const arr = [7, 3, 3, 9, 5];

let smallest = Infinity;
let second = Infinity;

for (const x of arr) {
  if (x < smallest) {
    second = smallest;
    smallest = x;
  } else if (x > smallest && x < second) {
    second = x;
  }
}

console.log(second === Infinity ? "No second smallest" : second);
💡 Hints

Stuck? Open one hint at a time

Hint 1

Mirror the second-largest idea: keep smallest and second, both starting at Infinity.

Hint 2

Update second only when the value is bigger than smallest and smaller than second.

📌 Noted Points

Remember these

  • ⚡ Duplicates: The repeated 3 must not be counted as the second smallest.
  • 💡 Start with Infinity: Infinity is larger than every allowed finite input, so the first value can replace it. Using 0 fails when all values are positive. Time: O(n); extra space: O(1).
