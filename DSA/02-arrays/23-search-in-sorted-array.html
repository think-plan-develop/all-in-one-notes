search-rotated-sorted-array.js
const arr = [4, 5, 6, 7, 0, 1, 2];
const target = 0;

let lo = 0;
let hi = arr.length - 1;
let result = -1;

while (lo <= hi) {
  const mid = Math.floor((lo + hi) / 2);

  if (arr[mid] === target) {
    result = mid;
    break;
  }

  if (arr[lo] <= arr[mid]) {
    // left half is sorted
    if (arr[lo] <= target && target < arr[mid]) hi = mid - 1;
    else lo = mid + 1;
  } else {
    // right half is sorted
    if (arr[mid] < target && target <= arr[hi]) lo = mid + 1;
    else hi = mid - 1;
  }
}

console.log(result);
💡 Hints

Stuck? Open one hint at a time

Hint 1

Use binary search. After picking mid, at least one half (left or right) is always fully sorted.

Hint 2

If arr[lo] <= arr[mid], the left half is sorted. Check whether the target lies inside that sorted range; if not, search the other half.

Hint 3

Otherwise the right half is sorted. Apply the same range check using arr[mid] and arr[hi].

📌 Noted Points

Remember these

  • ⚡ Use <=: The check arr[lo] <= arr[mid] must include equality so that a window where lo === mid is treated as sorted.
  • 💡 Complexity: O(log n) time and O(1) extra space. This version assumes distinct values; duplicates can make both halves look unsorted and can force an O(n) worst case.
