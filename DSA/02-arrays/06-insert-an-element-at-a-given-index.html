insert-an-element-at-a-given-index.js
const arr = [10, 20, 30, 40];
const index = 2;
const value = 25;

for (let i = arr.length; i > index; i--) {
  arr[i] = arr[i - 1];
}
arr[index] = value;

console.log(arr);

📌 Noted Points

Remember these

  • ⚡ Shift backwards: Shifting from the front overwrites values you still need. Always move the last element first.
  • 💡 Valid index: The index can be from 0 to arr.length. Inserting at arr.length just appends. The solution assumes a valid integer index. Manual shifting uses O(n) worst-case time and O(1) auxiliary space, excluding array storage.
  • ⚠️ Built-in: arr.splice(index, 0, value) does the same, but practise the manual shift first.
