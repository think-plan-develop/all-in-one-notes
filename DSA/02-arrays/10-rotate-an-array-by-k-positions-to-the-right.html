Rotate an Array by K to the Right

🟢 Easy⭐ ImportantArraysRotation
Rotate an array to the right by k positions. Each rotation moves the last element to the front. Produce a new array and do not modify the input. k may be larger than the array length; an empty array produces [].
INPUT arr
1234567
k
3

Result[5, 6, 7, 1, 2, 3, 4]

rotate-array-right.js
const arr = [1, 2, 3, 4, 5, 6, 7];
const k = 3;

const n = arr.length;
let result = [];

if (n > 0) {
  const r = k % n;
  result = [...arr.slice(n - r), ...arr.slice(0, n - r)];
}

console.log(result);
💡 Hints

Stuck? Open one hint at a time

Hint 1

Rotating by the array length gives the same array, so use k % n to shrink a large k.

Hint 2

The last r elements move to the front, followed by the first n - r elements.

📌 Noted Points

Remember these

  • ⚡ Left vs right: Rotating right by k is the same as rotating left by n - k. Also, slice(-0) returns the whole array, so use slice(n - r) instead of slice(-r).
  • 💡 In-place trick: Reverse the whole array, then reverse the first r elements and the remaining elements separately. That uses O(1) extra space. The slice approach above runs in O(n) time and O(n) extra space.
