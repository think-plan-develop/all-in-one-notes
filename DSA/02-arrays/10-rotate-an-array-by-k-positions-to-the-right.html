Rotate Array Right by K — Reversal Algorithm

For right rotation, we move the last k elements to the beginning. Unlike left rotation, the order of the three reverses is: all → first K → remaining.

rotate-right-reverse.js
function rotateRight(arr, k) {
  let n = arr.length;
  if (n === 0) return arr;

  k = k % n;

  function reverse(left, right) {
    while (left < right) {
      let temp = arr[left];
      arr[left] = arr[right];
      arr[right] = temp;

      left++;
      right--;
    }
  }

  reverse(0, n - 1);
  reverse(0, k - 1);
  reverse(k, n - 1);

  return arr;
}

console.log(rotateRight([10, 20, 30, 40, 50, 60, 70, 80], 3));

// [60, 70, 80, 10, 20, 30, 40, 50]

Both left and right reversal approaches take O(n) time and O(1) extra space.

💡 Hints

Stuck? Open one hint at a time

Hint 1

Rotating by the array length gives the same array, so use k % n to shrink a large k.

Hint 2

Right rotation moves the last k elements to the front. Reversing the whole array first puts those elements at the front, but in the wrong order.

Hint 3

After reversing everything, reverse the first k elements, then reverse the remaining elements to restore their order.

  • 💡 Trick: Left: First K → Remaining → All. Right: All → First K → Remaining.
  • ⚡ Edge cases: Check for an empty array before using k % n, because k % 0 is NaN. If k % n is 0, reverse(0, -1) does nothing, so the array stays the same.
  • ⚠️ Input mutation: This approach modifies the original array. If the problem says not to modify the input, call it on a copy, for example rotateRight([...arr], k).
  • ⏱️ Complexity: Both left and right reversal approaches take O(n) time and O(1) extra space.
