const arr = [12, 5, 8, 21, 3, 17];

let max = arr[0];
let min = arr[0];

for (let i = 1; i < arr.length; i++) {
  if (arr[i] > max) max = arr[i];
  if (arr[i] < min) min = arr[i];
}

console.log("Largest =", max);
console.log("Smallest =", min);
💡 Hints

Stuck? Open one hint at a time

Hint 1

Start with max and min both equal to arr[0].

Hint 2

Loop from index 1 and update max or min whenever you see a bigger or smaller value.

📌 Noted Points

Remember these

  • ⚡ Start with arr[0]: Do not start max at 0. If every number is negative, the answer would be wrong.
  • 💡 Empty array: The question assumes a non-empty array. If empty input is allowed later, define a no-result output and check length before reading arr[0].
  • ⚠️ Single pass: One loop is enough: O(n) time and O(1) extra space.
