Find the Maximum Stock Profit (One Transaction)

🟢 Easy⭐ ImportantArraysGreedy
Given daily non-negative finite prices, find the maximum profit from at most one buy and one later sell. You may skip trading, so print 0 if no profit is possible or fewer than two prices exist. Track the lowest price seen so far.

const prices = [7, 1, 5, 3, 6, 4];

let minPrice = Infinity;
let maxProfit = 0;

for (const price of prices) {
  maxProfit = Math.max(maxProfit, price - minPrice);
  minPrice = Math.min(minPrice, price);
}

console.log(maxProfit);
💡 Hints

Stuck? Open one hint at a time

Hint 1

Keep minPrice, the lowest price seen so far.

Hint 2

First evaluate selling today using the minimum from earlier days, then update minPrice with today's price. On the first day, price - Infinity cannot improve the initial profit of 0.

📌 Noted Points

Remember these

  • ⚡ Buy before sell: Because minPrice only covers earlier days, you never sell before buying.
  • 💡 No profit: If prices only fall, the answer is 0, not a negative number, because trading is optional. Time: O(n); extra space: O(1).
