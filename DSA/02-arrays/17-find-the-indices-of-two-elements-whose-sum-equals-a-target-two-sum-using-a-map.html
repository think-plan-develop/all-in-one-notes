Two Sum Using a Map

two-sum-using-a-map.js
const arr = [2, 7, 11, 15];
const target = 9;

const seen = new Map();
let result = [];

for (let i = 0; i < arr.length; i++) {
  const need = target - arr[i];
  if (seen.has(need)) {
    result = [seen.get(need), i];
    break;
  }
  seen.set(arr[i], i);
}
console.log(result);

Store each visited number and its index in a Map, and check the Map before storing.

📌 Noted Points

Remember these

  • ⚡ Check first: Check the Map before storing the current number, so an element is not paired with itself.
  • 💡 O(n): Expected O(n) time and O(n) extra space with a hash map; the nested-loop baseline takes O(n²) time.
  • ⚠️ No pair: The result starts as [], so no match prints []. Check [3, 3], target 6 (answer [0, 1]), and [3], target 6 (answer []).
