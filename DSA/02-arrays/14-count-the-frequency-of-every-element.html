count-the-frequency-of-every-element.js
const arr = [2, 3, 2, 5, 3, 2];

const freq = new Map();

for (const x of arr) {
  freq.set(x, (freq.get(x) || 0) + 1);
}

for (const [value, count] of freq) {
  console.log(value, "->", count);
}

Hint 1

Use a Map where the key is the element and the value is its count.

Hint 2

For each element, read its current count (default 0) and add 1.

📌 Noted Points

Remember these

  • ⚡ Default to 0: freq.get(x) is undefined for a new key, so use (freq.get(x) || 0) + 1. Existing counts are positive, so || 0 works correctly here. Expected time: O(n); extra space: O(u), where u is the number of distinct values.
  • 💡 Map vs object: A Map keeps numeric keys as numbers and remembers insertion order.
