Find All Values That Appear More Than Once

find-all-values-that-appear-more-than-once.js
const arr = [4, 3, 2, 7, 3, 2, 4, 8];

const seen = new Set();
const dups = new Set();

for (const x of arr) {
  if (seen.has(x)) dups.add(x);
  else seen.add(x);
}

console.log([...dups]);

📌 Noted Points

Remember these

  • ⚡ Use a Set for dups: A Set for the duplicates keeps a value listed once, even if it appears three times.
  • 💡 Order: The result follows second-occurrence order, not first-occurrence order. For [4, 3, 3, 4], output [3, 4]. With expected O(1) set operations: O(n) expected time and O(n) extra space.
