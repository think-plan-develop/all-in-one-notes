check-whether-an-array-is-sorted.js
const arr = [2, 4, 4, 7, 9];

let sorted = true;

for (let i = 1; i < arr.length; i++) {
  if (arr[i] < arr[i - 1]) {
    sorted = false;
    break;
  }
}

console.log(sorted);
💡 Hints

Stuck? Open one hint at a time

Hint 1

Compare each element with the one before it.

Hint 2

If any arr[i] is smaller than arr[i - 1], the array is not sorted, so you can stop early.

📌 Noted Points

Remember these

  • ⚡ Equal neighbours: [2, 4, 4] is still sorted, so only a strictly smaller next value breaks the order.
  • 💡 Tiny arrays: An empty array or an array with one element is always sorted.
