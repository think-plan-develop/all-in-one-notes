Approach 1 — Using an Extra Array (Easy)
rotate-left-extra-array.js
function rotateLeft(arr, k) {
  let n = arr.length;
  if (n === 0) return [];

  k = k % n; // Important

  let result = [];

  for (let i = k; i < n; i++) {
    result.push(arr[i]);
  }

  for (let i = 0; i < k; i++) {
    result.push(arr[i]);
  }

  return result;
}

console.log(rotateLeft([1, 2, 3, 4, 5, 6, 7], 3));
// [4, 5, 6, 7, 1, 2, 3]

Without k = k % n, if k = 7 and n = 5, the second loop tries to read arr[5] and arr[6], which are undefined.

Approach 2 — Reverse Algorithm ⭐ (Best for DSA)

Uses two pointers and rearranges the array in place, without allocating another array.

rotate-left-reverse.js
function rotateLeft(arr, k) {
  const n = arr.length;
  if (n === 0) return arr;

  k = k % n;

  function reverse(left, right) {
    while (left < right) {
      [arr[left], arr[right]] = [arr[right], arr[left]];
      left++;
      right--;
    }
  }

  reverse(0, k - 1);
  reverse(k, n - 1);
  reverse(0, n - 1);

  return arr;
}

console.log(rotateLeft([10, 20, 30, 40, 50], 2));
// [30, 40, 50, 10, 20]
💡 Hints

Stuck? Open one hint at a time

Hint 1

Rotating by the array length gives the same array, so use k % n to shrink a large k.

Hint 2

Easy way: push the elements from index k to the end into a new array, then push the first k elements.

Hint 3

In-place way: reverse the first k elements, reverse the remaining elements, then reverse the whole array.

📌 Noted Points

Remember these

  • ⚡ Edge cases: Check for an empty array before using k % n, because k % 0 is NaN.
  • 💡 Complexity: Approach 1 runs in O(n) time and O(n) extra space. Approach 2 runs in O(n) time and O(1) extra space.
  • ⚠️ Input mutation: Approach 2 modifies the original array. If the problem says not to modify the input, call it on a copy, for example rotateLeft([...arr], k).
