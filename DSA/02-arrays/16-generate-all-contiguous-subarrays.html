Generate All Contiguous Subarrays

🟢 EasyArraysNested Loops
Print every non-empty contiguous subarray, ordered by increasing start index and then increasing end index. Equal-looking subarrays at different positions count separately. An empty array produces no subarrays.

generate-all-contiguous-subarrays.js
const arr = [1, 2, 3];

for (let i = 0; i < arr.length; i++) {
  for (let j = i; j < arr.length; j++) {
    console.log(arr.slice(i, j + 1));
  }
}

📌 Noted Points

Remember these

  • ⚡ Count: An array of length n has n * (n + 1) / 2 non-empty contiguous subarrays. There are O(n²) start/end pairs, but slicing and printing all their elements takes O(n³) total work. This code uses O(n) peak temporary slice space, excluding retained output.
  • 💡 Contiguous: Elements must be next to each other, so [1, 3] is not a subarray of [1, 2, 3].
