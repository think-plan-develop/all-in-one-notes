A Insertion

Insert at the end, the beginning, or any index

3 operations
1 Insert at the endThe next available index is arr.length. O(1) amortized▼
1let arr = [10, 20, 30];
2 
3arr[arr.length] = 40;
4 
5console.log(arr); // [10, 20, 30, 40]

Logic: The next available index is arr.length.

2 Insert at the beginning⭐Shift everything right from the last index, then write at index 0. O(n)▼
1let arr = [10, 20, 30];
2 
3for (let i = arr.length; i > 0; i--) {
4 arr[i] = arr[i - 1];
5}
6 
7arr[0] = 5;
8 
9console.log(arr); // [5, 10, 20, 30]

Logic:

  1. Start from the last index.
  2. Shift each element one position to the right.
  3. Insert the new element at index 0.
3 Insert at any index⭐Shift right from the end down to index, then place the value. O(n)▼
1let arr = [10, 20, 30, 40];
2let index = 2;
3let value = 25;
4 
5for (let i = arr.length; i > index; i--) {
6 arr[i] = arr[i - 1];
7}
8 
9arr[index] = value;
10 
11console.log(arr); // [10, 20, 25, 30, 40]

Logic: shift elements right, from the end down to index, then write the value at index.
