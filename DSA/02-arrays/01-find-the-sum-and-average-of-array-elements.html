sum-average.js
const arr = [10, 20, 30, 40, 50];
let sum = 0;

for (let i = 0; i < arr.length; i++) {
  sum += arr[i];
}

const average = sum / arr.length;

console.log("Sum =", sum);
console.log("Average =", average);
💡 Hints

Stuck? Open one hint at a time

Hint 1 — Where do I start?

Create a variable sum and set it to 0 before you look at any element.

Hint 2 — How do I visit every element?

Use a for loop from index 0 to arr.length - 1 and add each element to sum.

Hint 3 — How do I get the average?

After the loop ends, divide sum by the number of elements: sum / arr.length.

📌 Noted Points

Remember these

  • ⚡ Empty array: sum / arr.length divides by zero when the array is empty. Check arr.length first.
  • 💡 Start at 0: Initialize sum to 0, not to the first element, unless your loop starts at index 1.
  • ⚠️ Integer division: In C, C++ and Java, cast to float or double or the decimal part is lost.
  • ✅ Shortcut: arr.reduce((a, b) => a + b, 0) gives the sum in one line, but learn the loop first.
