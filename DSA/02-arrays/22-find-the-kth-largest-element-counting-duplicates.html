const arr = [3, 2, 1, 5, 6, 4];
const k = 2;

const sorted = [...arr].sort((a, b) => b - a);

console.log(sorted[k - 1]);

📌 Noted Points

Remember these

  • ⚡ Numeric sort: sort() compares as text by default. For descending numeric order, pass (a, b) => b - a. For ascending numeric order, use (a, b) => a - b. Sorting a copy is the baseline: typically O(n log n) time, with O(n) copy storage plus engine-dependent sorting workspace.
  • 💡 Duplicates count: In [5, 5, 4], the 2nd largest is 5, not 4.
  • ⚠️ Faster: A size-k min-heap gives O(n log k) time for k >= 2 and O(k) space; k = 1 is a linear scan. Quickselect offers expected O(n) time but O(n²) worst-case time with basic pivot selection. Study these after heaps and partitioning.
