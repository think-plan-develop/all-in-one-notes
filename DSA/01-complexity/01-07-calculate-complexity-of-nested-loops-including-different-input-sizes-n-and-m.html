01.07 - Calculate complexity of nested loops with input sizes n and m

For nested loops, multiply iteration counts when the inner loop runs fully for each outer-loop iteration.

for i = 0 to n - 1:
    for j = 0 to m - 1:
        work()

The inner body runs m times for each of n outer iterations: total work is n * m, or O(nm).

When both loops use n

If both bounds are n, this becomes O(n^2). Do not assume the two bounds are equal when the problem has separate inputs.

Dependent bounds

If the inner loop runs from 0 to i, total iterations are 0 + 1 + ... + (n - 1) = n(n - 1)/2, which is O(n^2).

Key idea: determine actual iteration counts and dependencies first; nesting alone does not determine the answer.
