01.01 - What are time complexity and space complexity?

Time complexity describes how the number of operations an algorithm performs grows with the input size. Space complexity describes how its memory use grows with the input size.

How to think about them

  • Use n to represent the size of the input.
  • Count how the work or memory changes as n grows, rather than measuring seconds or bytes on one machine.
  • State the assumptions that matter, such as whether an output array is counted as extra space.
Example: scanning every value in an array of length n takes linear time, O(n). If the scan only uses a fixed number of variables, its auxiliary space is O(1).
Key idea: complexity is a model of growth, not an exact runtime or memory measurement.
