01.12 - Understand time-space trade-offs

A time-space trade-off uses additional memory to reduce repeated work, or saves memory by doing more computation.

  • Caching: store results so repeated requests avoid recalculation.
  • Precomputation: build a lookup table once to answer later queries faster.
  • Recomputation: avoid storing intermediate values, accepting more work to reduce memory use.
A prefix-sum array takes O(n) extra space to build, then answers each range-sum query in O(1). Without it, a query may scan the range and take O(n) time.

Choose based on input limits, number of queries, memory constraints, and whether cached data remains valid.

Key idea: the right balance depends on the problem's constraints and workload, not a universal rule to minimize time or space alone.
