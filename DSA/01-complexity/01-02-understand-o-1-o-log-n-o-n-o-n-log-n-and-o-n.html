01.02 - Understand O(1), O(log n), O(n), O(n log n) and O(n2)

These common growth rates help estimate how an algorithm scales. The exact operation count may differ, but the growth category is useful for comparing approaches.

  • O(1), constant: work stays bounded as input grows, such as reading an array element by index.
  • O(log n), logarithmic: each step reduces the remaining search space by a constant factor, as in binary search.
  • O(n), linear: work grows proportionally to input size, as in one complete scan.
  • O(n log n), linearithmic: commonly produced by repeatedly dividing the input and processing all elements per level, as in merge sort.
  • O(n2), quadratic: often produced by two full nested loops over the same input.
For large inputs, the usual growth order is O(1), O(log n), O(n), O(n log n), then O(n^2).
Key idea: identify what changes with n; fixed work is constant, repeated passes are linear, and nested passes can be quadratic.
