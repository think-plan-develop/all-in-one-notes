01.11 - Compare in-place solutions with solutions using extra arrays or maps

An in-place algorithm modifies its input and uses only a small, bounded amount of additional working memory. An alternative may allocate a data structure to make the logic simpler or improve runtime.

  • In-place: often saves memory, but can require careful index updates or mutate data the caller expects to preserve.
  • Extra array: can make transformations straightforward, but may need O(n) additional or output space.
  • Hash map or set: can reduce repeated searches, often trading O(n) extra space for expected constant-time lookups.
To detect duplicates, compare each pair in O(n^2) time and O(1) extra space, or use a set for expected O(n) time and O(n) extra space.
Key idea: compare time, auxiliary space, mutation constraints, and input limits; in-place is not automatically the best choice.
