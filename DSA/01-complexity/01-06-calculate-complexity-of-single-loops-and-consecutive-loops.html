01.06 - Calculate complexity of single loops and consecutive loops

Count how many times the loop body runs, then simplify the total growth rate.

One loop

for i = 0 to n - 1:
    do constant work

The body runs n times, so time is O(n).

Two consecutive loops

for i = 0 to n - 1:  // n operations
    work()
for j = 0 to n - 1:  // n operations
    work()

The total is n + n = 2n, which simplifies to O(n). When loops run one after another, add their costs; do not multiply them.

Key idea: sequential loops add. Keep different input sizes explicit: loops of lengths n and m cost O(n + m).
