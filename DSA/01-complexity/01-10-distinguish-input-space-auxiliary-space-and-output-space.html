01.10 - Distinguish input space, auxiliary space and output space

  • Input space: memory occupied by the values supplied to the algorithm.
  • Auxiliary space: additional working memory, such as temporary arrays, maps, and recursion stack.
  • Output space: memory required for the result produced by the algorithm.
Reversing an array in place can use O(1) auxiliary space. Creating and returning a separate reversed array requires O(n) output space, even if the temporary working memory is constant.

State the convention used in an analysis. Some contexts report total space including output; others emphasize auxiliary space.

Key idea: make clear whether the input and result are counted when reporting space complexity.
