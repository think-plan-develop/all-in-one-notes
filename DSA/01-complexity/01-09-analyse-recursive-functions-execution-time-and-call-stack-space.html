01.09 - Analyse recursive functions: execution time and call-stack space

Analyze recursion by writing a recurrence: the work done in one call plus the work done by its recursive calls. Separately count the maximum number of calls active at once.

  • One call on n - 1: T(n) = T(n - 1) + O(1) gives O(n) time and O(n) stack space.
  • One call on n / 2: T(n) = T(n / 2) + O(1) gives O(log n) time and O(log n) stack space.
  • Two calls on n / 2 plus linear merging: T(n) = 2T(n / 2) + O(n) gives O(n log n) time; recursion depth is O(log n).

Stack space depends on recursion depth, not just the total number of calls. Branching recursion may make many total calls while keeping a smaller maximum depth.

Key idea: calculate total recursive work and maximum active call depth as separate quantities.
