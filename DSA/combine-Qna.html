🎯 25 Array & String Questions

Question, method used, and how to tackle it. ★ marks suggested interview priorities.

Arrays: In-Place Basics
Q1Reverse an array without reverse()
Method Two pointers + swapping
Approach Swap the first and last elements, then move inward.
Q2Remove duplicates from a sorted array in-place★ Priority
Method Read/write pointers
Approach Read every element; write only when a new value appears.
Q3Move all zeros to the end, preserving other elements’ order★ Priority
Method Read/write pointers
Approach Write non-zero values first, then fill the remaining positions with zeros.
Q4Remove every occurrence of a given value in-place
Method Read/write pointers
Approach Write only the values you want to keep; return the new length.
Q5Merge two sorted arrays into the first array’s available space★ Priority
Method Two pointers + backward writing
Approach Compare elements from both ends and place the larger one at the back.
Strings & Two Sum
Q6Check whether a string is a palindrome, ignoring punctuation and case★ Priority
Method Two pointers + character filtering
Approach Skip non-alphanumeric characters and compare both ends.
Q7Reverse the order of words in a sentence
Method Reversal + two pointers
Approach On a character array, reverse everything, then reverse each word; handle extra spaces.
Q8Check whether a string becomes a palindrome after deleting at most one character
Method Two pointers + checking two possibilities
Approach At the first mismatch, try skipping either the left or right character.
Q9Find two numbers whose sum equals a target in an unsorted array★ Priority
Method Hash map + complement lookup
Approach For each value, check whether target - value was seen earlier.
Q10Find two numbers whose sum equals a target in a sorted array
Method Two pointers
Approach Move the left pointer when the sum is too small; move the right when too large.
Hashing & Grouping
Q11Find all unique triplets whose sum is zero — 3Sum★ Priority
Method Sorting + two pointers
Approach Fix one number, find the remaining pair, and skip duplicates.
Q12Check whether two strings are anagrams
Method Frequency counting
Approach Count characters and check that their frequencies match.
Q13Group anagrams from an array of strings★ Priority
Method Sorting + hash map
Approach Sort each word’s characters to form a grouping key.
Q14Find the first non-repeating character
Method Frequency map + second traversal
Approach Count first, then scan the original string for the first count of 1.
Q15Find the longest consecutive sequence in an unsorted array
Method Hash set + sequence expansion
Approach Start counting only from numbers whose predecessor is absent.
Sliding Window & Prefix Sum
Q16Find the maximum sum of a subarray of size k★ Priority
Method Fixed sliding window + running sum
Approach Add the incoming value and subtract the outgoing value.
Q17Find the longest substring without repeating characters★ Priority
Method Sliding window + set/map
Approach Expand the window; move its start when a duplicate appears.
Q18Find every starting index of an anagram of a pattern inside a string
Method Fixed sliding window + frequency counting
Approach Maintain character counts for a window equal to the pattern’s length.
Q19Find the shortest subarray with sum at least a target, using positive numbers
Method Variable sliding window + running sum
Approach Expand until the target is reached, then shrink while the sum remains sufficient.
Q20Count subarrays whose sum equals k, including negative numbers★ Priority
Method Prefix sum + frequency map
Approach For each running sum, count previously seen sums equal to sum - k.
Classic Patterns
Q21Find the product of all elements except the current element, without division★ Priority
Method Prefix products + suffix products
Approach Combine the product before each index with the product after it.
Q22Sort an array containing only 0, 1, and 2
Method Dutch National Flag + three pointers
Approach Maintain separate regions for zeros, ones, unknown values, and twos.
Q23Merge overlapping intervals★ Priority
Method Sorting + linear scan
Approach Sort by start time, then extend the current interval whenever the next overlaps.
Q24Find the next lexicographically greater permutation
Method Pivot search + swapping + reversal
Approach Find the rightmost ascent, swap its smaller value with the rightmost larger value, then reverse the suffix.
Q25Rotate a square matrix by 90° clockwise in-place
Method Transpose + row reversal
Approach Swap rows with columns, then reverse every row.
