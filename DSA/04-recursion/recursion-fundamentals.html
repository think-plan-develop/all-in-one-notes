Recursion Fundamentals

A function that calls itself on a smaller problem until a stopping condition is reached. Covers base case, call stack, factorial, recursion vs iteration and DSA uses.

01What is recursion?self-call

Recursion is when a function calls itself to solve a problem in smaller or simpler steps until it reaches a condition that stops it.

Think of a mirror reflecting another mirror: a recursive function keeps calling itself until it reaches a stopping condition.

02Simple JavaScript examplecountDown
countDown.js
function countDown(n) {
  if (n === 0) {
    return; // Base case
  }

  console.log(n);
  countDown(n - 1); // Recursive case
}

countDown(3);
OUTPUT3 2 1
03How does recursion work?trace
  1. countDown(3) → prints 3 → calls countDown(2)
  2. countDown(2) → prints 2 → calls countDown(1)
  3. countDown(1) → prints 1 → calls countDown(0)
  4. countDown(0) → base case reached → returns
04Two important partsbase + recursive

Base case

The condition that stops further recursive calls. It returns a value or simply stops.

Recursive case

The function calls itself with a smaller or simpler problem.

No base case?Recursion may continue until JavaScript throws Maximum call stack size exceeded.
05What is the call stack?LIFO

The call stack keeps track of function calls that are currently executing. Each recursive call adds a new execution context to the stack. When a call returns, its context is removed.

countDown(3)waiting
countDown(2)waiting
countDown(1)waiting
countDown(0)base case · top

Deepest point for countDown(3): 4 active calls, including the base case. They return in reverse order.

Likewise, factorial(5) calls factorial(4), which calls factorial(3), and so on.

06Example: factorialn! = n × (n−1)!

Factorial of a non-negative integer n is the product of all positive integers from n down to 1.

5! = 5 × 4 × 3 × 2 × 1 = 120
factorial.js
function factorial(n) {
  if (n === 0 || n === 1) {
    return 1; // Base case
  }

  return n * factorial(n - 1); // Recursive case
}

console.log(factorial(5)); // 120
console.log(factorial(0)); // 1
  1. factorial(5)
  2. 5 * factorial(4)
  3. 5 * 4 * factorial(3)
  4. 5 * 4 * 3 * factorial(2)
  5. 5 * 4 * 3 * 2 * factorial(1)
  6. 5 * 4 * 3 * 2 * 1 = 120

The calls first build up; then the return values are calculated as the calls unwind.

Why handle 0?Mathematically 0! = 1, so 0 is a base case too. This example assumes n is a non-negative integer; in production code, validate the input.
07Recursion vs iterationinterview favourite
RecursionIteration
A function calls itself.Uses loops such as for and while.
Uses the call stack for recursive calls.Usually avoids extra function-call stack frames for the loop.
Can make tree and divide-and-conquer problems easier to express.Often simpler and more memory-efficient for straightforward repetition.
Can cause a stack overflow if recursion is too deep.Can avoid recursion-related stack overflow.

09Interview tips5 questions

Before writing a recursive function, ask:

  1. What is the base case?
  2. What is the recursive case?
  3. How does each call make the problem smaller or simpler?
  4. What should each call return?
  5. Could the recursion become too deep?
RememberBase case stops recursion; recursive case calls the same function again.
