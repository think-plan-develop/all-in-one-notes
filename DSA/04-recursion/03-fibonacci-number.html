Return the nth Fibonacci number, where F(0) = 0, F(1) = 1 and F(n) = F(n - 1) + F(n - 2).

fibonacci-number.js
const n = 6;

function fib(n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}

console.log(fib(n));

Hint 1

The two base cases are F(0) = 0 and F(1) = 1.

Hint 2

For any other n, return fib(n - 1) + fib(n - 2).

📌 Noted Points

Remember these

  • ⚡ Sequence: 0, 1, 1, 2, 3, 5, 8, 13, ...
  • 💡 Slow: This plain version is O(2^n), because the same values are computed again and again. Memoization (next topics) fixes that.
  • ⚠️ Base cases: Without both base cases, the recursion never stops.
