memoization-with-fibonacci.js
const n = 40;

const memo = new Map();

function fib(n) {
  if (n <= 1) return n;
  if (memo.has(n)) return memo.get(n);

  const result = fib(n - 1) + fib(n - 2);
  memo.set(n, result);
  return result;
}

console.log(fib(n));

📌 Noted Points

Remember these

  • ⚡ Overlapping subproblems: fib(5) needs fib(3) more than once. Memoization computes each value just once.
  • 💡 Complexity: Time drops from O(2^n) to O(n). Stack depth and the Map use O(n) space.
  • ⚠️ Top-down DP: Memoization is top-down dynamic programming. The bottom-up version fills a table with a loop.
