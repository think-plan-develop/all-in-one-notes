const x = 2;
const n = 10;

function power(x, n) {
  if (n === 0) return 1;
  if (n < 0) return 1 / power(x, -n);

  const half = power(x, Math.floor(n / 2));
  return n % 2 === 0 ? half * half : half * half * x;
}

console.log(power(x, n));
💡 Hints

Stuck? Open one hint at a time

Hint 1

Base case: x^0 = 1. For a negative n, compute 1 / x^(-n).

Hint 2

Compute half = power(x, floor(n / 2)) once and reuse it.

Hint 3

If n is even, the answer is half * half. If n is odd, it is half * half * x.

📌 Noted Points

Remember these

  • ⚡ Call once: Calling power twice for the same half brings you back to O(n). Store it in half.
  • 💡 Negative n: 2^-2 = 1 / 2^2 = 0.25.
  • ⚠️ Depth: n is halved each time, so the stack depth is O(log n).
