regular-expression-matching.js
const s = "aab";
const p = "c*a*b";

const memo = new Map();

function match(i, j) {
  const key = i + "," + j;
  if (memo.has(key)) return memo.get(key);

  let result;
  if (j === p.length) {
    result = i === s.length;
  } else {
    const first = i < s.length && (p[j] === s[i] || p[j] === ".");
    if (j + 1 < p.length && p[j + 1] === "*") {
      result = match(i, j + 2) || (first && match(i + 1, j));
    } else {
      result = first && match(i + 1, j + 1);
    }
  }

  memo.set(key, result);
  return result;
}

console.log(match(0, 0));
💡 Hints

Stuck? Open one hint at a time

Hint 1

Use match(i, j) to ask: does s from index i match p from index j? If j reaches the end of p, i must also be at the end of s.

Hint 2

Check if the current characters match: p[j] === s[i] or p[j] === ".".

Hint 3

If the next pattern character is *, either skip the x* part, or use it once and stay on the same j.

📌 Noted Points

Remember these

  • ⚡ Two choices for x*: Skip it with match(i, j + 2), or consume one character with match(i + 1, j).
  • 💡 Memoize on (i, j): There are only s.length * p.length states, which turns exponential work into O(n * m).
  • ⚠️ Whole string: aa does not match a, because the pattern must cover the entire string.
