function reverseString(str) {
  const result = [];
  for (let i = str.length - 1; i >= 0; i--) {
    result.push(str[i]);
  }
  return result.join("");
}

const str = "hello";
console.log(reverseString(str));

📌 Noted Points

Remember these

  • ⚡ Immutable strings: You cannot swap characters by assigning to str[i]. Build a new string.
  • 💡 Complexity: O(n) time and O(n) extra space. Collecting characters and joining once avoids relying on repeated string-prepending performance.
  • ⚠️ Check: "" → ""; "a" → "a"; "ab c" → "c ba".
  • ⚡ Character assumption: Use ASCII input for these exercises. JavaScript indexing works in UTF-16 code units; emoji and combined Unicode characters require a separate approach.
