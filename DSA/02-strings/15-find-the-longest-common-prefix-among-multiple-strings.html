Find the Longest Common Prefix Among Multiple Strings

🟢 Easy⭐ ImportantStringsScanning
Return the longest starting substring shared by every string. Compare characters exactly, including case. Return "" for an empty input array or when there is no common prefix. A single input string is its own common prefix.

function longestCommonPrefix(strings) {
  if (strings.length === 0) return "";
  const first = strings[0];
  for (let i = 0; i < first.length; i++) {
    for (let j = 1; j < strings.length; j++) {
      if (i >= strings[j].length || strings[j][i] !== first[i]) {
        return first.slice(0, i);
      }
    }
  }
  return first;
}

const strings = ["flower", "flow", "flight"];
console.log(longestCommonPrefix(strings));

📌 Noted Points

Remember these

  • ⚡ Prefix means start: A common piece in the middle of each string does not count.
  • 💡 Examples: ["dog", "racecar", "car"] → ""; ["", "abc"] → ""; ["solo"] → "solo".
  • ⚠️ Complexity: O(S) time as an upper bound, where S is the total input length; O(1) working space, excluding the returned prefix of length p.
  • ⚡ Character assumption: Use ASCII input for these exercises. JavaScript indexing works in UTF-16 code units; emoji and combined Unicode characters require a separate approach.
