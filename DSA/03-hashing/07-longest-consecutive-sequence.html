longest-consecutive-sequence.js
const nums = [100, 4, 200, 1, 3, 2];

const set = new Set(nums);
let best = 0;

for (const x of set) {
  if (!set.has(x - 1)) {
    let length = 1;
    while (set.has(x + length)) length++;
    best = Math.max(best, length);
  }
}

console.log(best);

Start counting only from numbers where x - 1 is not in the Set, because those begin a sequence.

📌 Noted Points

Remember these

  • ⚡ Key pattern: Set. Look up neighbours in O(1) instead of sorting.
  • 💡 Why O(n): The while loop runs only from the start of a sequence, so each number is visited once.
  • ⚠️ Duplicates: A Set ignores repeated values automatically.
