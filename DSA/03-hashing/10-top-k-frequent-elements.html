top-k-frequent-elements.js
const nums = [1, 1, 1, 2, 2, 3];
const k = 2;

const freq = new Map();
for (const x of nums) freq.set(x, (freq.get(x) || 0) + 1);

const buckets = Array.from({ length: nums.length + 1 }, () => []);
for (const [value, count] of freq) buckets[count].push(value);

const result = [];
for (let i = buckets.length - 1; i >= 0 && result.length < k; i--) {
  for (const value of buckets[i]) {
    if (result.length < k) result.push(value);
  }
}

console.log(result);

Stuck? Open one hint at a time

Hint 1

Count the frequency of every value in a Map.

Hint 2

Make buckets where the index is the count, then read the buckets from the highest count down until you have k values.

📌 Noted Points

Remember these

  • ⚡ Key pattern: Map + bucket sort (or a heap): no full sort of all values is needed.
  • 💡 Why buckets: A value can appear at most n times, so the count itself works as an array index. That gives O(n).
  • ⚠️ Heap option: A min-heap of size k gives O(n log k).
