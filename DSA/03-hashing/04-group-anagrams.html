group-anagrams.js
const words = ["eat", "tea", "tan", "ate", "nat", "bat"];

const groups = new Map();

for (const w of words) {
  const key = w.split("").sort().join("");
  if (!groups.has(key)) groups.set(key, []);
  groups.get(key).push(w);
}

console.log([...groups.values()]);
💡 Hints

Stuck? Open one hint at a time

Hint 1

Anagrams become identical when their letters are sorted. Use that sorted string as a key.

Hint 2

Store each key in a Map whose value is an array of words.

📌 Noted Points

Remember these

  • ⚡ Key pattern: A sorted-string key, or a letter-frequency key, identifies every anagram group.
  • 💡 Cost: Sorting each word costs O(k log k). A 26-letter frequency key brings it to O(k).
  • ⚠️ Order: Groups appear in the order their first word was seen.
