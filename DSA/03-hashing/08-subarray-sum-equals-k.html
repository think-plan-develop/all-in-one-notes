subarray-sum-equals-k.js
const nums = [1, 2, 3];
const k = 3;

const prefixCount = new Map([[0, 1]]);
let sum = 0;
let count = 0;

for (const x of nums) {
  sum += x;
  count += prefixCount.get(sum - k) || 0;
  prefixCount.set(sum, (prefixCount.get(sum) || 0) + 1);
}

console.log(count);

📌 Noted Points

Remember these

  • ⚡ Key pattern: Prefix sum + Map: count earlier prefixes equal to sum - k.
  • 💡 Start with 0: The Map must begin with {0: 1} so subarrays that start at index 0 are counted.
  • ⚠️ Why not sliding window: Negative numbers break a sliding window, but this method still works.
