contains-duplicate.js
const arr = [1, 2, 3, 1];

const seen = new Set();
let hasDuplicate = false;

for (const x of arr) {
  if (seen.has(x)) {
    hasDuplicate = true;
    break;
  }
  seen.add(x);
}

console.log(hasDuplicate);

📌 Noted Points

Remember these

  • ⚡ Key pattern: Set. Lookups with has() are O(1), so the whole check is O(n).
  • 💡 Shortcut: new Set(arr).size !== arr.length does the same in one line.
  • ⚠️ Stop early: break as soon as a repeat is found. There is no need to scan the rest.
