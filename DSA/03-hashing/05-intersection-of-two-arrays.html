intersection-of-two-arrays.js
const nums1 = [1, 2, 2, 1];
const nums2 = [2, 2];

const set1 = new Set(nums1);
const result = new Set();

for (const x of nums2) {
  if (set1.has(x)) result.add(x);
}

console.log([...result]);

📌 Noted Points

Remember these

  • ⚡ Key pattern: Set. A Set removes duplicates and gives O(1) has() checks.
  • 💡 Distinct: Using a Set for the result stops 2 from appearing twice.
  • ⚠️ Compare: The nested-loop version is O(n * m). The Set version is O(n + m).
