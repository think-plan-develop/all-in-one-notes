valid-anagram.js
const s = "listen";
const t = "silent";

let result = s.length === t.length;
const freq = new Map();

for (const ch of s) freq.set(ch, (freq.get(ch) || 0) + 1);

for (const ch of t) {
  if (!freq.get(ch)) {
    result = false;
    break;
  }
  freq.set(ch, freq.get(ch) - 1);
}

console.log(result);
💡 Hints

Stuck? Open one hint at a time

Hint 1

If the lengths are different, they cannot be anagrams.

Hint 2

Count each letter of s in a Map, then subtract one for each letter of t.

Hint 3

If a letter of t has no count left, return false.

📌 Noted Points

Remember these

  • ⚡ Key pattern: Map frequency counting: count one string up, count the other down.
  • 💡 Length check: With equal lengths, no leftover counts remain once every letter of t is matched.
  • ⚠️ Sorting: Sorting both strings and comparing also works, but costs O(n log n).
