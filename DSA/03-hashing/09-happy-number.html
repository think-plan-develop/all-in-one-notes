happy-number.js
const n = 19;

const seen = new Set();
let num = n;

while (num !== 1 && !seen.has(num)) {
  seen.add(num);
  let sum = 0;
  while (num > 0) {
    const digit = num % 10;
    sum += digit * digit;
    num = Math.floor(num / 10);
  }
  num = sum;
}

console.log(num === 1);

Hint 1

Compute the sum of the squares of the digits, then repeat with the new number.

Hint 2

Store each number in a Set. If you see one again, you are in a cycle.

📌 Noted Points

Remember these

  • ⚡ Key pattern: Set cycle detection: a repeated value means the process will never reach 1.
  • 💡 Example: 19 → 82 → 68 → 100 → 1, so 19 is happy.
  • ⚠️ Unhappy numbers: They always fall into a loop, for example 4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4.
