🧑‍💻 Coding — 2 Tasks 25 min
T1
Group and summarize orders — 10 minutes

Write a function that calculates the total paid order amount for each customer.

const orders = [
  { userId: "u1", amount: 100, status: "paid" },
  { userId: "u2", amount: 200, status: "paid" },
  { userId: "u1", amount: 50, status: "pending" },
  { userId: "u1", amount: 150, status: "paid" },
  { userId: "u3", amount: 500, status: "cancelled" },
];

console.log(summarizeOrders(orders));

// Expected output:
// [
//   { userId: "u1", total: 250 },
//   { userId: "u2", total: 200 }
// ]
REQUIREMENTS
  • Include only paid orders.
  • Group results by userId.
  • Sort results by total amount in descending order.
  • Do not mutate the original array.
  • Return an empty array for empty input.
🔁 Follow-up: Explain the time complexity of your solution.
T2
Build a React editable task list — 15 minutes

Create a component using this initial data:

const initialTasks = [
  { id: "t1", title: "Prepare React", completed: false },
  { id: "t2", title: "Practice Node.js", completed: true },
];
REQUIREMENTS
  • Add a task using an input and submit button.
  • Edit a task without changing its position in the list.
  • Preserve its completion status when editing its title.
  • Toggle completion and delete tasks.
  • Reject empty or whitespace-only titles.
  • Update state immutably and use stable keys.
🔁 Follow-up: If saving an edit to the backend fails, how would you handle the UI and preserve the user's input?
