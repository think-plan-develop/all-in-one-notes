INTERVIEW GUIDE

⚛️ React Developer — 60-Minute Interview

JavaScript-heavy format for candidates with 4–5 years of experience: theory, output prediction, two coding tasks, and four React questions.

⏱ Total: 60 minutes 🔠 JS Theory + Output 💻 2 Coding Tasks ⚛️ 4 React Qs
🟦 JavaScript Theory 15 min
1
Explain closures with a practical example. How can a closure retain access to variables after the outer function finishes?
2
Compare var, let, and const. Explain scope, hoisting, and the temporal dead zone.
3
How does this differ in regular and arrow functions? Explain when you would use call(), apply(), or bind().
4
Explain the JavaScript event loop. How do the call stack, microtasks, and timer callbacks interact?
5

6
What is the difference between shallow and deep copying? Why can updating a nested property in a copied object modify the original?
🔍 JavaScript Output Questions 10 min
7
Asynchronous execution — 5 minutes

Predict the output and explain the order.

console.log("A");

setTimeout(() => {
  console.log("B");
}, 0);

Promise.resolve().then(() => {
  console.log("C");
});

async function run() {
  console.log("D");
  await Promise.resolve();
  console.log("E");
}

run();

console.log("F");
🔁 Follow-up: If synchronous code blocks the thread for two seconds, when can the timer callback execute?
8
Scope and closures — 5 minutes

Predict the output of both loops.

for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log("var:", i), 0);
}

for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log("let:", j), 0);
}
EXPLAIN
  • Why do the loops produce different results?
  • How would you fix the first loop without replacing var with let?
🧑‍💻 JavaScript Coding — 2 Tasks 25 min
T1
Implement reduce() manually — 10 minutes

Write a standalone function:

reduceManually(array, callback, initialValue)

Examples:

reduceManually([1, 2, 3], (acc, value) => acc + value, 0);
// 6

reduceManually([1, 2, 3], (acc, value) => acc + value);
// 6

reduceManually(
  ["React", "Node", "React"],
  (acc, value) => {
    acc[value] = (acc[value] ?? 0) + 1;
    return acc;
  },
  {}
);
// { React: 2, Node: 1 }
REQUIREMENTS
  • Support calls with and without an initial value.
  • Pass accumulator, currentValue, index, and the original array to the callback.
  • Return the initial value for an empty array when one is supplied.
  • Throw an error for an empty array without an initial value.
  • Do not use built-in reduce().
📝 Assume a normal array without empty slots.
🔁 Follow-up: Why is checking if (!initialValue) incorrect?
T2
Implement asynchronous retry — 15 minutes

Write a function that retries a failed asynchronous operation.

retry(operation, maxAttempts, delayMs)

Example:

let attempts = 0;

async function fetchData() {
  attempts++;

  if (attempts < 3) {
    throw new Error("Temporary failure");
  }

  return { message: "Success" };
}

const result = await retry(fetchData, 3, 500);

console.log(result);
// { message: "Success" }
REQUIREMENTS
  • maxAttempts includes the first call.
  • Return immediately when an attempt succeeds.
  • Wait delayMs between failed attempts.
  • Do not wait after the final failure.
  • Throw the last error when all attempts fail.
  • Use async/await without blocking the JavaScript thread.
📝 Assume maxAttempts is a positive integer.
🔁 Follow-ups:
• Why should the function receive fetchData instead of fetchData()?
• What could go wrong when retrying a request that creates an order?
