Rules to Remember Normal Routes Nested — Prefix Nested — Outlet
🧩 At a Glance
🛣️
Normal routes: one <Route> per URL, each pointing straight at a component.
🔗
Nested — shared prefix: child routes inherit the parent's path segment.
🖼️
Nested — shared layout: <Outlet /> renders whichever child route matched.
⚠️
Common mistakes: path vs to, double <BrowserRouter>, missing <Outlet />.
⚠️ Common Points to Remember
Rules People Get Wrong
  • Import routing components from "react-router-dom".
  • Wrap <Routes> inside <BrowserRouter>. If your app is already wrapped in it in main.jsx, don't add another.
  • Use path on <Route>, not to.
  • Use to on navigation components such as <Link>.
  • Put the URL path on <Route>, not <Routes>.
⚠️ Easy mix-up: <Route path="/cart" /> defines where a route matches; <Link to="/cart"> defines where a click navigates. Swapping the props is a silent, common bug.
🛣️ 1. Normal Routes
One Route, One URL, One Component
The simplest form: each <Route> matches its own URL. path specifies the URL to match; element specifies the component to render.
import React from "react";
import { Route, Routes, BrowserRouter } from "react-router-dom";

import Products from "./route/Products";
import Cart from "./route/Cart";
import Wishlist from "./route/Wishlist";

const App = () => {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/product" element={<Products />} />
        <Route path="/cart" element={<Cart />} />
        <Route path="/wishlist" element={<Wishlist />} />
      </Routes>
    </BrowserRouter>
  );
};

export default App;

📋 Points to note

  • Each route matches its own URL.
  • path specifies the URL to match.
  • element specifies the component to render.

🔗 2. Nested Routes — Shared URL Prefix
Child Routes Inherit the Parent's Path
For nesting, place child <Route> elements inside a parent <Route>. Add the shared path to the parent (path="/ecommerce") and use relative paths for the children — no leading slash.
import React from "react";
import { Route, Routes, BrowserRouter } from "react-router-dom";

import Products from "./route/Products";
import Cart from "./route/Cart";
import Wishlist from "./route/Wishlist";

const App = () => {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/ecommerce">
          <Route path="product" element={<Products />} />
          <Route path="cart" element={<Cart />} />
          <Route path="wishlist" element={<Wishlist />} />
        </Route>
      </Routes>
    </BrowserRouter>
  );
};

export default App;

📋 Points to note

  • For nesting, place child <Route> elements inside a parent <Route>.
  • Add the shared path to the parent: path="/ecommerce".
  • Use relative paths for children: "product", "cart", and "wishlist" — without a leading /.
Parent PathChild PathComplete URL
/ecommerceproduct/ecommerce/product
/ecommercecart/ecommerce/cart
/ecommercewishlist/ecommerce/wishlist
📝 Note: here the parent <Route> has no element, so it renders nothing of its own — it exists purely to supply the shared path prefix.
🖼️ 3. Nested Routes — Shared Layout Using <Outlet />
A Layout Wrapper That Renders Whichever Child Matched
Import Outlet from "react-router-dom", pass the layout component through the parent route's element prop, and place <Outlet /> inside the layout wherever the matched child component should appear.
import React from "react";
import {
  Route,
  Routes,
  BrowserRouter,
  Outlet,
} from "react-router-dom";

import Products from "./route/Products";
import Cart from "./route/Cart";
import Wishlist from "./route/Wishlist";

const EcommerceLayout = () => {
  return (
    <div>
      <p>Welcome to ecommerce</p>
      <Outlet />
    </div>
  );
};

const App = () => {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<EcommerceLayout />}>
          <Route path="product" element={<Products />} />
          <Route path="cart" element={<Cart />} />
          <Route path="wishlist" element={<Wishlist />} />
        </Route>
      </Routes>
    </BrowserRouter>
  );
};

export default App;

📋 Points to note

  • Import Outlet from "react-router-dom".
  • Pass the layout component through the parent route's element prop.
  • Place <Outlet /> inside the layout where the matched child component should appear.
  • The shared layout content appears for every child route.
  • Without <Outlet />, the layout renders, but the child component does not appear.
URLRendered Content
/productWelcome message + Products
/cartWelcome message + Cart
/wishlistWelcome message + Wishlist
⚠️ At / itself: the welcome message appears, but <Outlet /> is empty because no default child (index route) is defined.
💡 Interview answer: <Outlet /> is the "slot" where React Router injects whichever nested route currently matches. Forgetting it is the most common reason a shared layout "works" but the page content never shows up.
