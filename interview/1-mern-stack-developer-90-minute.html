For candidates with 4–5 years of experience. Includes 2 coding tasks and 2 project scenarios. Ask candidates to support answers with examples from their own projects.

🧑‍💻 Coding — 2 Tasks 25 min
T1
Implement debounce(fn, delay) — 10 minutes

Write a reusable debounce(fn, delay) function.

const search = debounce((query) => {
  console.log("Searching:", query);
}, 300);

search("r");
search("re");
search("react");

// Only "Searching: react" should print,
// approximately 300 ms after the final call.
REQUIREMENTS
  • Reset the timer on every call.
  • Pass the latest arguments to the original function.
  • Preserve the calling context (this).
🔁 Follow-up: How would you add a cancel() method?
T2
Build a React user search — 15 minutes

Create a component with a search input that fetches users from:

GET /api/users?search=<query>

Response:
{
  "users": [
    { "id": "u1", "name": "Shivam" }
  ]
}
REQUIREMENTS
  • Debounce API calls by 300 milliseconds.
  • Display loading, error, empty, and success states.
  • Prevent an older response from replacing newer search results.
  • Clean up pending timers and requests.
  • Use stable keys when displaying users.

Assume the API already exists; focus on behavior rather than styling.
