📣 Node.js EventEmitter
Create and Handle Custom Events
EventEmitter is used in Node.js to create and handle custom events.

Basic idea

Listener registered
→
Event emitted
→
Listener runs

Example:

import { EventEmitter } from "events";const emitter = new EventEmitter();
🧰 Important Methods
on, emit, once, off
MethodPurpose
.on(event, fn)registers a listener. The listener runs every time the event is emitted.
.emit(event, data)Trigger an event and optionally pass data
.once(event, fn)registers a listener that runs only one time.
.off(event, fn) / .removeListener()Stop listening to an event
🧪 Combined Example
on, once, emit and off Together
import { EventEmitter } from "events";

const emitter = new EventEmitter();

const messageHandler = (text) => {
  console.log("Message:", text);
};

// Runs every time
emitter.on("message", messageHandler);

// Runs only once
emitter.once("login", (user) => {
  console.log(`${user} logged in`);
});

// Trigger message event
emitter.emit("message", "Hello");
emitter.emit("message", "Node.js");

// Trigger login multiple times
emitter.emit("login", "Shivam");
emitter.emit("login", "Shivam");

// Remove message listener
emitter.off("message", messageHandler);

// This will not run
emitter.emit("message", "After removing listener");

Output:

Message: HelloMessage: Node.jsShivam logged in

🛒 Real-World Example
orderPlaced Triggers Email + Inventory

Suppose an order is placed.

import { EventEmitter } from "events";

const emitter = new EventEmitter();

emitter.on("orderPlaced", (order) => {
  console.log("Send email for:", order.id);
});

emitter.on("orderPlaced", (order) => {
  console.log("Update inventory for:", order.id);
});

emitter.emit("orderPlaced", {
  id: 101,
  amount: 500
});

Output:

Send email for: 101Update inventory for: 101
One event → multiple listeners
emit("orderPlaced")
→
Send email
emit("orderPlaced")
→
Update inventory
One event can have multiple listeners.
🎯 Important Interview Point
Same Process Only

EventEmitter is mainly used for event-driven communication inside the same Node.js process.

Something happens
→
emit()
→
registered listeners react
For communication between different services, you usually use tools such as Kafka, RabbitMQ, SQS, or EventBridge instead of only EventEmitter.
🧱 Buffer
Raw Binary Data in Memory
A Buffer in Node.js is used to store and work with raw binary data in memory.

It is commonly used with files, streams, network data, images, and other binary content.

Buffer with streams

If you do not provide encoding:

const stream = fs.createReadStream("./file.txt");

stream.on("data", (chunk) => {
  console.log(chunk);
});

chunk is usually a Buffer.

If you use:

fs.createReadStream("./file.txt", { encoding: "utf8"});

then the chunks are returned as strings instead of Buffer objects.

No encoding
createReadStream("./file.txt")
→
chunk = Buffer
encoding: "utf8"
createReadStream("./file.txt", { encoding: "utf8" })
→
chunk = string
A Buffer is a memory area used by Node.js to handle raw binary data, especially during file, stream, and network operations.
🔍 util.inspect()
Human-Readable Object Debugging
util.inspect() is a Node.js utility used to convert objects into a human-readable debug representation.

It is especially useful for deeply nested objects, Maps, Sets, Errors, and complex Node.js objects.

const util = require("util");

const obj = {
  user: {
    name: "Shivam",
    address: {
      city: "Hyderabad",
      details: {
        pin: 500001
      }
    }
  }
};

console.log(util.inspect(obj));

Why use it?

Sometimes console.log() may not show deeply nested data clearly, especially for complex objects.

With util.inspect(), you can control how much detail is displayed.

console.log(
  util.inspect(obj, {
    depth: null,
    colors: true
  })
);

Important options

OptionPurpose
depthControls how deeply nested objects are displayed
colorsAdds terminal colors
showHiddenShows non-enumerable properties
compactControls compact formatting
sortedSorts object properties

Example:

console.log(
  util.inspect(obj, {
    depth: null,
    colors: true,
    compact: false
  })
);

depth

LIMITED LEVELSutil.inspect(obj, { depth: 1 });

Shows only limited nested levels.

FULL OBJECTutil.inspect(obj, { depth: null });

Shows the full nested object.

Common debugging use

const util = require("util");

console.log(
  util.inspect(data, {
    depth: null,
    colors: true
  })
);

Easy difference

console.log()util.inspect()
General loggingDetailed object inspection
Less controlHighly configurable
Good for simple valuesBetter for deeply nested/complex objects
util.inspect() returns a formatted, human-readable representation of a JavaScript object and is mainly used for debugging complex or deeply nested objects. Options such as depth, colors, and showHidden control how the object is displayed.
