🔗 1. ES Modules: import.meta.url and File Handling
Locating Files Relative to the Current Module
❌ NOT AVAILABLE IN ES MODULES
__dirname__filename

In ES Modules, __dirname and __filename are not available because they are CommonJS-specific globals.

→
✅ RECOMMENDED APPROACH

The recommended approach is to use:

import.meta.url with new URL()

to locate files relative to the current module.

Reading a file relative to the current module

import { readFile } from "fs/promises";

const filePath = new URL("./es1.html", import.meta.url);

try {
  const data = await readFile(filePath, "utf8");

  console.log(data);
} catch (err) {
  console.error("Error reading file:", err);
}

How it works

1
GET THE CURRENT MODULE import.meta.url

returns the URL of the current module.

For example:

file:///D:/node-app/src/index.js
2
RESOLVE RELATIVE TO IT

Then:

new URL("./es1.html", import.meta.url)

resolves es1.html relative to the current module.

3
SEE IT ON DISK

If the structure is:

src/
├── index.jscurrent module · import.meta.url
└── es1.htmltarget file

then:

const filePath = new URL("./es1.html", import.meta.url);

points to:

src/es1.html

Why it is useful

In ES Modules, you normally do not have:

__filename__dirname

So import.meta.url is commonly used to locate files relative to the current module.

Easy comparison

ThingMeaning
process.cwd()Folder where Node.js was started
import.meta.urlURL of the current module file
new URL("./file.txt", import.meta.url)File relative to the current module
⚠️ Important: import.meta.url is a URL, not a normal filesystem path.
⏳ 2. readFile() vs readFileSync()
Async by Default for Backend Applications
Use asynchronous readFile() by default in most Node.js backend applications.
MethodTypeBlocks event loop?Best use
readFile()AsynchronousNoAPIs, servers, backend applications
readFileSync()SynchronousYesStartup code, small scripts, CLI tools
✅ Recommended: readFile() from fs/promises 
import { readFile } from "fs/promises";

const filePath = new URL("./notes.md", import.meta.url);

try {
  const data = await readFile(filePath, "utf8");

  console.log(data);
} catch (err) {
  console.log("Error:", err);
}
📝 Because this uses fs/promises, no callback is required.
“readFileSync() blocks the JavaScript thread until the file operation completes, while readFile() works asynchronously and allows Node.js to continue handling other operations.”

For backend applications, prefer:

import { readFile } from "fs/promises";

with:

await readFile(...)
🗃️ 3. Important Functions from fs/promises
Promise-Based Filesystem Methods for async/await

fs/promises provides Promise-based filesystem methods that work cleanly with async/await.

FunctionPurpose
readFile()Read the complete contents of a file
writeFile()Create or overwrite a file
appendFile()Add data to the end of a file
readdir()Read files/folders inside a directory
mkdir()Create a directory
rm()Remove files or directories
unlink()Delete a file
rename()Rename or move a file
copyFile()Copy a file
stat()Get information about a file or directory
access()Check whether a path can be accessed
const data = await readFile("./notes.md", "utf8");

await writeFile("./output.txt", "Hello");

await appendFile("./output.txt", "\nNew line");

const files = await readdir("./src");

await mkdir("./uploads", { recursive: true });

await rename("./old.txt", "./new.txt");

await rm("./temp", { recursive: true, force: true });
🧾 4. JSON File Handling
Object ⇄ JSON String ⇄ File

When working with JSON files, remember:

Writing
Object
→
JSON.stringify()
→
writeFile()
Reading
readFile()
→
JSON.parse()
→
Object

Writing JSON

import { writeFile } from "fs/promises";

const filePath = new URL("./users.json", import.meta.url);

const user = {
  name: "shivam",
  email: "shivam@example.com",
  address: {
    city: "hyderabad",
    country: "india"
  }
};

try {
  await writeFile(
    filePath,
    JSON.stringify(user, null, 2),
    "utf8"
  );

  console.log("JSON written successfully");
} catch (err) {
  console.log("Error:", err);
}

Reading JSON

import { readFile } from "fs/promises";

const filePath = new URL("./users.json", import.meta.url);

try {
  const data = await readFile(filePath, "utf8");

  const user = JSON.parse(data);

  console.log(user);
} catch (err) {
  console.log("Error:", err);
}

Easy JSON rule

OperationMethod
JavaScript object → JSON stringJSON.stringify()
JSON string → JavaScript objectJSON.parse()
