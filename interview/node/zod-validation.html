✅ Zod Validation in Node.js (Express)

Zod is a schema validation library used to validate API request data (body, params, query) and return errors for invalid input. All examples here are plain JavaScript — no TypeScript.

📦 1. Install Zod
terminal
npm install zod
📐 2. Create Validation Schema
A schema describes the shape of valid data once, using plain JavaScript — no types or interfaces needed.
user.schema.js
import { z } from "zod";

const userSchema = z.object({
  name: z.string().min(3),
  email: z.email(),
  age: z.number().int().min(18),
  password: z.string().min(8),
});
🌐 3. Use in Express API
Call safeParse() on the incoming body. On failure, respond with 400 and a flattened field-error map; on success, use the validated result.data.
server.js
app.post("/users", (req, res) => {
  const result = userSchema.safeParse(req.body);

  if (!result.success) {
    return res.status(400).json({
      success: false,
      errors: z.flattenError(result.error).fieldErrors,
    });
  }

  // Validated data
  const user = result.data;

  res.status(201).json({
    message: "User created",
    user,
  });
});
💡 Best practice: create a reusable validation middleware so you don't repeat Zod validation in every Express controller.
🧰 4. Important Zod Methods
MethodPurpose
z.string()Validate string
z.number()Validate number
z.email()Validate email
.min(3)Minimum length/value
.max(20)Maximum length/value
.optional()Field is optional
.nullable()Allows null
z.enum(["ADMIN", "USER"])Restrict allowed values
.refine()Custom validation
.parse()Throws error if invalid
.safeParse()Returns result without throwing
⚖️ 5. parse() vs safeParse()
parse-vs-safeparse.js
// Throws ZodError for invalid data
userSchema.parse(req.body);

// Does not throw
const result = userSchema.safeParse(req.body);

if (result.success) {
  console.log(result.data);
} else {
  console.log(result.error.issues);
}
✅ Rule of thumb: use safeParse() in request-handling code — you control the response. Reach for parse() only where throwing and catching upstream is actually what you want.
