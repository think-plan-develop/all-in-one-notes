✏️ SQL UPDATE Statement

Modify existing records: one column, many columns, conditional values, and values from another table.

What is UPDATE?ExamplesDOs & DON'TsNotes & Revision
⚠️ Careful: Without WHERE, every row in the table is updated.
1. What is UPDATE?
Syntax

The UPDATE statement is used to modify existing records in a database table.

syntax.sql
UPDATE table_name
SET column_name = new_value
WHERE condition;
UPDATE→SET→WHERE
Always keep this order: which table → what to change → which rows.
2. Examples
Example 1: Update a single column
Task: Update stock quantity of product ID 16 to 75.
single-column.sql
UPDATE products
SET stock_quantity = 75
WHERE product_id = 16;
Example 2: Update multiple columns
Task: Update salary and city of employee ID 5.
multiple-columns.sql
UPDATE employees
SET salary = 55000,
    city = 'Hyderabad'
WHERE employee_id = 5;
Separate columns with commas. No comma after the last one.
Example 3: Conditional update using CASE
Task: Increase salary based on department.
case-update.sql
UPDATE employees
SET salary =
    CASE
        WHEN department = 'IT' THEN salary + 10000
        WHEN department = 'HR' THEN salary + 5000
        ELSE salary
    END;

Explanation

  • IT employees get a ₹10,000 increment.
  • HR employees get a ₹5,000 increment.
  • Employees from other departments retain their existing salary.
  • Without WHERE, all employees are considered for the update.
Example 4: Update using another table (JOIN update)
Task: Update employee department names using the departments table.
join-update.sql
UPDATE employees e
SET department_name = d.department_name
FROM departments d
WHERE e.department_id = d.id;

Explanation

  • employees e → Target table.
  • departments d → Source table.
  • FROM departments d → Uses another table to retrieve values.
  • WHERE → Matches employees with their departments.
3. DOs and DON'Ts
✅

DOs

Safe habits for every UPDATE

4 rules
  • ✓Always write UPDATE table_name before SET.
  • ✓Use WHERE after SET to target specific records.
  • ✓Use commas (,) to update multiple columns.
  • ✓Use RETURNING * to see updated records immediately (PostgreSQL).
🚫

DON'Ts

Mistakes that break or ruin data

4 traps
  • ✕Don't forget the UPDATE keyword.
  • ✕Don't write WHERE before SET. Correct order: UPDATE → SET → WHERE.
  • ✕Don't forget WHERE when updating specific records; otherwise, all rows get updated.
  • ✕Don't confuse the column being updated with the column used in the WHERE condition.
4. Important Notes
Keep in mind
  1. Without WHERE, all rows in the table will be updated.
  2. UPDATE modifies existing records; it does not insert new records.
  3. PostgreSQL supports RETURNING to display updated records.

Example:

returning.sql
UPDATE products
SET stock_quantity = 75
WHERE product_id = 16
RETURNING *;
