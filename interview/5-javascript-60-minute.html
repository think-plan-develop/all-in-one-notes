🔍 Output & Debugging Questions 10 min
7
Object references — 5 minutes

Predict the output and explain each result.

const first = {
  name: "Shivam",
  skills: ["React"],
};

const second = { ...first };
const third = first;

second.name = "Rahul";
second.skills.push("Node");
third.name = "Amit";

console.log(first.name);
console.log(second.name);
console.log(first.skills);
console.log(first === second);
console.log(first === third);
🔁 Follow-up: How would you copy this object so that updating the copied skills array does not affect the original?
8
Async array methods — 5 minutes

Explain what this function returns and why.

async function doubleNumbers(numbers) {
  const result = numbers.map(async (number) => {
    return number * 2;
  });

  return result;
}

doubleNumbers([1, 2, 3]).then(console.log);
EXPLAIN
  • Does result contain numbers or promises?
  • Does marking the outer function async automatically resolve the promises inside the array?
  • How would you change the function to return [2, 4, 6]?
  • What happens if one operation rejects after your change?
🧑‍💻 JavaScript Coding — 2 Tasks 25 min
T1
Flatten a nested array — 10 minutes

Write a function that flattens an array of numbers with arbitrary nesting.

flattenArray([1, [2, [3, 4], 5], 6]);
// [1, 2, 3, 4, 5, 6]

flattenArray([[], [1, []], 2]);
// [1, 2]

flattenArray([]);
// []
REQUIREMENTS
  • Do not use flat() or flatMap().
  • Preserve the original element order.
  • Do not mutate the input.
  • Handle empty nested arrays.
🔁 Follow-ups:
• Explain your solution's time and space complexity.
• What problem could occur with extremely deep nesting?
• How could you solve it without recursion?
T2
Implement throttle — 15 minutes

Write a reusable function:

throttle(fn, delay)

Example:

const logPosition = throttle((position) => {
  console.log(position);
}, 1000);

logPosition(10); // Runs immediately
logPosition(20); // Ignored
logPosition(30); // Ignored

// A call made after the 1000 ms window can run again.
REQUIREMENTS
  • Execute the first call immediately.
  • Ignore calls made within delay milliseconds of the last execution.
  • Pass arguments to the original function.
  • Preserve the calling context (this).
  • Do not schedule a trailing execution.
🔁 Follow-ups:
• How does this differ from debounce?
• How would you add a trailing execution using the latest arguments?
• Which would you choose for search input versus scroll handling?
