🐞 Code Debugging 10 min
19
Predict the state update — 4 minutes

Assume count is initially 0.

function Counter() {
  const [count, setCount] = useState(0);

  function handleClick() {
    setCount(count + 1);
    setCount(count + 1);
    setCount(count + 1);

    console.log(count);
  }

  return <button onClick={handleClick}>{count}</button>;
}
EXPLAIN
  • What does the console print on the first click?
  • What value appears on the button after the update?
  • How would you make one click increment the count by three?
20
Find and fix the timer problems — 6 minutes
function Timer() {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    setInterval(() => {
      setSeconds(seconds + 1);
    }, 1000);
  }, []);

  return <p>{seconds}</p>;
}
EXPLAIN
  • Why does the displayed value stop increasing?
  • What cleanup is missing?
  • How would you fix it without recreating the interval every second?
🧑‍💻 React Coding — 2 Tasks 30 min
T1
Build a nested file explorer — 20 minutesSwiggy
📌 Company basis: a candidate reported a file explorer task involving nested folders and adding files. Scope adapted here for a shorter exercise.

Use this initial data:

const initialTree = {
  id: "root",
  name: "project",
  type: "folder",
  children: [
    {
      id: "src",
      name: "src",
      type: "folder",
      children: [
        { id: "app", name: "App.jsx", type: "file" },
      ],
    },
    { id: "package", name: "package.json", type: "file" },
  ],
};
REQUIREMENTS
  • Display files and folders differently.
  • Expand or collapse folders.
  • Support arbitrary nesting using a recursive component.
  • Add a file inside a selected folder.
  • Update the tree without mutating existing state.
  • Use stable keys.
🔁 Discussion follow-up: How would you extend this to rename or delete a nested folder?
T2
Track the pointer and place a marker — 10 minutesSwiggy
📌 Company basis: same report describes a pointer-tracking exercise, later changed to display a marker on click and discuss optimization.

Create a rectangular area.

REQUIREMENTS
  • Track the pointer's position relative to the rectangle.
  • Clicking inside it displays a circle at the clicked position.
  • Each click moves the existing circle.
  • Avoid triggering a React render on every pointer movement when only tracking coordinates.
  • Keep the visible circle position in React state.
🔁 Discussion follow-up: Which values belong in useRef, and which belong in useState? Why?
