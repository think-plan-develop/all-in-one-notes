Notes — Docker Commands Full Reference

Cheat sheet with flag notes. Images · Containers · Logs · Networks · Volumes · Compose · Registry · Cleanup.

Images Containers Logs & Debug Networks Volumes Compose Registry Cleanup
Quick pattern: -d (detached/background) and -f (force / follow, depending on command) show up across almost every command group. Always check --help (e.g. docker run --help) when unsure — flag meaning can shift slightly by context (-f = "force" on rm/rmi, but "follow" on logs). In the code blocks below, each flag is listed directly under its own command with a └─ connector, so it's always clear which command a flag belongs to.
Images

Pull, build, list, tag, inspect

images

docker pull <image>  # download an image




docker build -t name:tag .  # build image from Dockerfile

└─-ttag the image with a name:tag


└─--no-cacherebuild ignoring cache


└─-f <file>use a different Dockerfile





docker images  # list local images




docker rmi <image>  # remove an image

└─-fforce remove even if in use





docker tag <image> new:tag  # add a tag to an image




docker history <image>  # show image layers




docker inspect <image>  # full image metadata
CommandWhat it does
docker pull <image>download an image
docker build -t name:tag .build image from Dockerfile
docker imageslist local images
docker rmi <image>remove an image
docker tag <image> new:tagadd a tag to an image
docker history <image>show image layers
docker inspect <image>full image metadata
Containers

Run, list, start, stop, kill, remove

containers

docker run <image>  # create + start a container

└─-ddetached (run in background, prints container ID)


└─-itinteractive + allocate a terminal (for shells)


└─--rmauto-remove container when it stops


└─-p 8080:80map host:container ports


└─-e KEY=valueset an environment variable


└─--env-file .envload env vars from a file


└─--name myappgive it a custom name


└─-v vol:/dataattach a volume or bind mount


└─--network mynetattach to a specific network


└─--restart=alwaysrestart policy





docker ps  # list running containers

└─-ashow all (including stopped)


└─-qonly show container IDs (useful in scripts)





docker start <id>  # start a stopped container

└─-aattach to its output


└─-iinteractive





docker stop <id>  # gracefully stop (SIGTERM, then SIGKILL after timeout)

└─-t <sec>custom timeout before force-kill





docker restart <id>  # stop then start again




docker kill <id>  # force stop immediately (SIGKILL)




docker rm <id>  # remove a stopped container

└─-fforce remove even if running


└─-valso remove associated anonymous volumes
CommandWhat it does
docker run <image>create + start a container
docker pslist running containers
docker start <id>start a stopped container
docker stop <id>gracefully stop (SIGTERM, then SIGKILL after timeout)
docker restart <id>stop then start again
docker kill <id>force stop immediately (SIGKILL)
docker rm <id>remove a stopped container
Logs & Debugging

Logs, exec, inspect, stats, top

logs & debug

docker logs <id>  # view logs

└─-ffollow logs live (like tail -f)


└─--tail 100show last 100 lines only


└─-tshow timestamps





docker exec <id> <cmd>  # run a command in a running container

└─-itinteractive shell (e.g. docker exec -it <id> sh)





docker inspect <id>  # full container config/state (JSON)




docker stats  # live CPU/memory/network usage

└─--no-streamshow one snapshot instead of live updates





docker top <id>  # processes running inside container
CommandWhat it does
docker logs <id>view logs
docker exec <id> <cmd>run a command in a running container
docker inspect <id>full container config/state (JSON)
docker statslive CPU/memory/network usage
docker top <id>processes running inside container

└─--driver bridge/host/overlaychoose network type





docker network inspect mynet  # see connected containers




docker network connect mynet <id>  # attach a running container to a network




docker network disconnect mynet <id>  # detach it




docker network rm mynet  # remove a network
CommandWhat it does

docker network create mynetcreate a custom network
docker network inspect mynetsee connected containers
docker network connect mynet <id>attach a running container to a network
docker network disconnect mynet <id>detach it
docker network rm mynetremove a network

Compose

up, down, restart, exec, logs, ps, build, config, pull

compose

docker compose up  # start all services

└─-ddetached (run in background)


└─--buildrebuild images before starting





docker compose down  # stop and remove containers/networks

└─-valso remove named volumes


└─--rmi allalso remove images





docker compose restart <service>  # restart a single service




docker compose stop / start <service>  # stop/start without removing




docker compose exec <service> sh  # shell into a running service

└─(no -it needed)exec is interactive by default in Compose





docker compose logs  # view logs for all services

└─-ffollow live


└─<service>logs for just one service





docker compose ps  # list services and their status




docker compose build  # rebuild images

└─--no-cacheignore build cache





docker compose config  # validate and print the resolved compose config




docker compose pull  # pull images for all services

docker compose upstart all services
docker compose downstop and remove containers/networks

docker compose exec <service> shshell into a running service
docker compose logsview logs for all services
docker compose pslist services and their status
docker compose buildrebuild images
docker compose configvalidate and print the resolved compose config
docker compose pullpull images for all services

Cleanup

Prune unused resources

cleanup

docker system prune  # remove unused containers/networks/dangling images

└─-aalso remove all unused images (not just dangling)


└─--volumesalso remove unused volumes


└─-fskip confirmation prompt





docker container prune  # remove all stopped containers




docker image prune  # remove dangling (untagged) images

└─-aremove all unused images





docker volume prune  # remove unused volumes




docker network prune  # remove unused networks
CommandWhat it does
docker system pruneremove unused containers/networks/dangling images
docker container pruneremove all stopped containers
docker image pruneremove dangling (untagged) images
docker volume pruneremove unused volumes
docker network pruneremove unused networks
Be careful with prune commands on machines containing important Docker resources — especially --volumes, which can delete persistent database data.
