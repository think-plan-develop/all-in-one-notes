🧮 JavaScript Arrays — Complete Guide

Creation, iteration, transformation methods, copying, and the interview questions that come up again and again

1–3. Basics 4. Iteration 5–10. Transform & Search 11–14. Mutate & Combine 15–17. Destructuring & Copying Interview Questions
📌 In short: Arrays are ordered, resizable collections. Some methods mutate in place (push, splice, sort), others return a brand-new array (map, filter, slice) — knowing which is which prevents subtle bugs.
🔑 Key Terms at a Glance
🧮
Array: An ordered, resizable collection of values, accessed by zero-based index.
🔄
Mutable methods: push/pop/shift/unshift/splice/sort/reverse — change the original array.
🆕
Immutable methods: map/filter/reduce/slice/concat — return a new array, original untouched.
🪞
Shallow copy: [...arr]/slice() only copy the top level — nested arrays stay shared by reference.
1–3. The Basics
1

Array Creation

Arrays can be created with an array literal (the recommended way) or with the Array constructor.

array-creation.js
const arr1 = [1, 2, 3];         // array literal — recommended
const arr2 = new Array(1, 2, 3); // constructor — works, but has a quirk

const weird = new Array(5);      // creates an array with length 5, NOT [5]!
console.log(weird.length); // 5
console.log(weird);        // [ <5 empty items> ]
A single numeric argument to new Array() sets the length instead of creating a one-element array — a classic gotcha. Stick to array literals to avoid it entirely.
2

Access & Update Elements

Elements are accessed by zero-based index. Assigning to an index updates that element directly, since arrays are mutable objects.

access-update.js
const fruits = ["apple", "banana", "cherry"];

console.log(fruits[0]); // "apple"
console.log(fruits[fruits.length - 1]); // "cherry" — last element

fruits[1] = "blueberry"; // update in place
console.log(fruits); // ["apple", "blueberry", "cherry"]

console.log(fruits[10]); // undefined — out-of-range access, no error
Even though const fruits can't be reassigned, its contents can still be mutated — const locks the binding, not the array itself.
3

push(), pop(), shift(), unshift()

These four methods add or remove elements from either end of an array — all of them mutate the original array in place.

push-pop-shift-unshift.js
const nums = [2, 3, 4];

nums.push(5);    // [2,3,4,5] — adds to the end, returns new length
nums.pop();     // [2,3,4]   — removes from the end, returns removed item
nums.unshift(1); // [1,2,3,4] — adds to the start, returns new length
nums.shift();   // [2,3,4]   — removes from the start, returns removed item
MethodAdds/RemovesPositionReturns
push()AddsEndNew length
pop()RemovesEndRemoved element
unshift()AddsStartNew length
shift()RemovesStartRemoved element
shift() and unshift() are slower than push()/pop() on large arrays — every remaining element has to be reindexed.
4. Iteration
4a

Classic for

classic-for.js
const colors = ["red", "green", "blue"];

for (let i = 0; i < colors.length; i++) {
  console.log(i, colors[i]);
}
Full control — supports break, continue, looping backwards, or skipping indices. The most verbose option, but never wrong.
4b

for...of

for-of.js
for (const color of colors) {
  console.log(color);
}
Cleaner syntax, still supports break/continue. Works on any iterable — arrays, strings, Maps, Sets — not just arrays.
4c

for...in (works, but not recommended for arrays)

for-in.js
for (const index in colors) {
  console.log(index, colors[index]); // index is a STRING: "0", "1", "2"
}
for...in iterates over enumerable property keys, including any custom properties added to the array — not just numeric indices. Prefer for...of or forEach() for arrays.
4d

forEach()

foreach.js
colors.forEach((color, index, array) => {
  console.log(index, color);
});
Functional style, gives you the element, index, and the full array in the callback. Cannot break or continue — always runs through every element. Returns undefined.
4e

while / do...while

while-loop.js
let i = 0;
while (i < colors.length) {
  console.log(colors[i]);
  i++;
}
Useful when the number of iterations isn't known upfront — for example, looping until a condition unrelated to the index becomes true.
4f

entries(), keys(), values()

entries-keys-values.js
for (const [index, color] of colors.entries()) {
  console.log(index, color); // 0 "red", 1 "green", 2 "blue"
}
MethodCan break/continue?Gives Index?Returns a Value?
Classic forYesYes, directlyNo — just runs code
for...ofYesOnly via .entries()No — just runs code
for...inYesYes, as a string keyNo — just runs code
forEach()NoYes, as 2nd callback paramundefined
whileYesManual (you track it)No — just runs code
entries() is the cleanest way to get both the index and value with for...of, without falling back to a classic for loop or forEach().
5–10. Transform & Search
5

map() — Transform Every Element

map() runs a function on every element and returns a brand-new array of the same length with the transformed values.

map.js
const nums = [1, 2, 3];
const doubled = nums.map(n => n * 2);

console.log(doubled); // [2, 4, 6]
console.log(nums);    // [1, 2, 3] — original untouched
Use map() whenever you need a new array of the same length with each value transformed — not for side effects like logging (use forEach() for that).
6

filter() — Keep Only What Matches

filter() returns a new array containing only the elements for which the callback returns true.

filter.js
const nums = [1, 2, 3, 4, 5];
const evens = nums.filter(n => n % 2 === 0);

console.log(evens); // [2, 4]
If no elements match, filter() returns an empty array — never undefined or null.
7

reduce() — Combine Into One Value

reduce() combines all array elements into a single value — a sum, an object, a string, even another array — by running an accumulator function across the array.

reduce.js
const sum = [1, 2, 3].reduce((acc, n) => acc + n, 0);
console.log(sum); // 6

const counts = ["a", "b", "a"].reduce((acc, letter) => {
  acc[letter] = (acc[letter] || 0) + 1;
  return acc;
}, {});
console.log(counts); // { a: 2, b: 1 }
Forgetting the initial value (the second argument) can cause bugs on empty arrays — [].reduce((a,b)=>a+b) throws a TypeError since there's no first element to seed the accumulator.
8

find() & findIndex()

find() returns the first matching element itself; findIndex() returns its position instead.

find-findindex.js
const users = [{ id: 1, name: "Sam" }, { id: 2, name: "Alex" }];

const user = users.find(u => u.id === 2);
const index = users.findIndex(u => u.id === 2);
MethodReturns on No Match
find()undefined
findIndex()-1
9

some() & every()

some() checks if at least one element passes a test; every() checks if all elements pass.

some-every.js
const nums = [2, 4, 6, 7];

nums.some(n => n % 2 !== 0);  // true — 7 is odd
nums.every(n => n % 2 === 0); // false — 7 breaks it
every() on an empty array always returns true (vacuous truth); some() on an empty array always returns false.
10

includes()

includes() returns a boolean for whether a value exists in the array — more readable than checking indexOf() !== -1.

includes.js
const nums = [1, 2, NaN];

nums.includes(2);   // true
nums.includes(NaN); // true — unlike indexOf, includes() detects NaN correctly
nums.indexOf(NaN);  // -1 — indexOf uses strict equality, and NaN !== NaN
includes() is the modern default for membership checks — reach for indexOf() only when you actually need the position.
11–14. Mutate & Combine
11

sort() — Ordering Elements, Carefully

By default, sort() converts elements to strings and compares them lexicographically — which produces wrong results for numbers.

sort.js
[1, 20, 3].sort();
// [1, 20, 3] — sorted as strings: "1" < "20" < "3"

[1, 20, 3].sort((a, b) => a - b);
// [1, 3, 20] — correct numeric sort
sort() mutates the original array in place and returns the same reference — if you need to preserve the original order, sort a copy: [...arr].sort().
12

splice() & slice()

These two are easy to mix up by name, but behave completely differently.

splice-slice.js
const arr = ["a", "b", "c", "d"];

// slice(start, end) — does NOT modify original, returns a copy
const copyPart = arr.slice(1, 3); // ["b", "c"]

// splice(start, deleteCount, ...items) — MUTATES original
const removed = arr.splice(1, 2, "X", "Y");
// removed = ["b", "c"], arr = ["a","X","Y","d"]
MethodModifies Original?Returns
slice()NoCopied portion (new array)
splice()YesRemoved elements (as an array)
13

concat(), join(), reverse()

concat-join-reverse.js
const a = [1, 2];
const b = [3, 4];

const combined = a.concat(b);   // [1,2,3,4] — new array, a & b unchanged
const str = ["a", "b", "c"].join("-"); // "a-b-c"

const nums = [1, 2, 3];
nums.reverse(); // [3,2,1] — mutates in place!
reverse() mutates the original array, unlike concat() and join(). Use [...nums].reverse() if you need to keep the original order intact.
14

flat() & flatMap()

flat() flattens nested arrays by a given depth; flatMap() maps each element and then flattens the result by one level.

flat-flatmap.js
const nested = [1, [2, 3], [4, [5, 6]]];

nested.flat();     // [1, 2, 3, 4, [5, 6]] — default depth 1
nested.flat(Infinity); // [1, 2, 3, 4, 5, 6] — fully flattened

["hello world", "foo bar"].flatMap(s => s.split(" "));
// ["hello", "world", "foo", "bar"]
arr.flatMap(fn) is equivalent to arr.map(fn).flat() but slightly more efficient since it avoids building an intermediate array.
15–17. Destructuring & Copying
15

Array Destructuring

destructuring.js
const [a, b] = [10, 20]; // 10 20

// skip elements
const [, second] = [1, 2, 3]; // 2

// default values + rest pattern
const [first = 0, ...rest] = []; // 0 []

// swapping variables
let x = 1, y = 2;
[x, y] = [y, x]; // 2 1
Destructuring matches by position, not by name — const [a, b] = arr always maps a to index 0 and b to index 1.
16

Spread Operator with Arrays

spread.js
const a = [1, 2];
const b = [3, 4];

const merged = [...a, ...b];      // [1, 2, 3, 4]
const copy = [...a];             // shallow copy of a

Math.max(...a);              // spreads array as individual arguments — 2
Spread is the modern, more readable alternative to concat() for combining arrays, and to slice() for making a quick shallow copy.
17

Shallow Copy vs Deep Copy

A shallow copy duplicates only the first level — nested arrays or objects inside still point to the same memory as the original.

shallow-vs-deep.js
const arr = [[1, 2]];
const shallow = [...arr];
shallow[0][0] = 100;
console.log(arr); // [[100, 2]] — original changed too!

const deep = structuredClone(arr);
deep[0][0] = 999;
console.log(arr); // [[100, 2]] — untouched this time
Copy TypeHow to Make OneNested Objects/Arrays
Shallow copy[...arr], arr.slice(), Array.from(arr)Shared reference
Deep copystructuredClone(arr), JSON.parse(JSON.stringify(arr))Fully independent copies
The JSON.parse(JSON.stringify()) trick is common but loses functions, undefined, Date objects, and Map/Set. Prefer structuredClone() in modern environments.

What is an array in JavaScript?

11

concat() vs the spread operator

Both combine arrays. The spread operator ([...a, ...b]) is the modern ES6 syntax; concat() is the older method-based approach.

12

Explain array destructuring

Array destructuring extracts elements into variables by position: const [a, b] = [10, 20].

13

Difference between shallow copy and deep copy

A shallow copy copies only the first level, while nested arrays or objects still share references. A deep copy (e.g. structuredClone()) duplicates every nested level too.

📕 Advanced

14

What does reduce() do?

reduce() combines all array elements into a single value such as a sum, object, or array.

reduce-example.js
const sum = [1,2,3].reduce((a,b)=>a+b,0);
15

Explain flat() and flatMap()

flat() flattens nested arrays. flatMap() performs map() followed by flat(1).

16

Why does sort() sometimes produce unexpected results?

By default, sort() converts elements to strings and sorts them lexicographically — [1, 20, 3].sort() gives [1, 20, 3] instead of numeric order. Fix with a compare function: .sort((a,b)=>a-b).

17

Mutable vs immutable array methods

Mutable (modify original)
  • push(), pop()
  • shift(), unshift()
  • splice()
  • sort(), reverse()
Immutable (return new array)
  • map(), filter()
  • reduce(), find()
  • slice(), concat()
  • flat(), flatMap()

19

Explain array references

Arrays are objects, so they are copied by reference.

array-references.js
const arr1 = [1,2];
const arr2 = arr1;
arr2.push(3);
console.log(arr1); // [1,2,3] — same array in memory
20

Why does [1,2] === [1,2] return false?

Arrays are compared by reference, not by value. Even though both arrays contain the same values, they are different objects stored at different memory locations.
