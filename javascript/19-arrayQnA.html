JavaScript Arrays Interview Q&A

8 core array-method comparisons every JS interview covers — map vs forEach, filter vs find, reduce, slice vs splice, sort, flat vs flatMap, and more.

1. map() vs forEach()

Both map() and forEach() iterate over an array, but they serve different purposes.

Featuremap()forEach()
Returns a new array✅ Yes❌ No (undefined)
Modifies original array❌ No❌ No (unless elements modified manually)
Chainable✅ Yes❌ No
Used forTransforming dataExecuting side effects
Return valueNew transformed arrayundefined

Syntax

syntax.js
array.map(callback);
array.forEach(callback);

Example

map.js
const numbers = [1, 2, 3];
const doubled = numbers.map(num => num * 2);

console.log(doubled);  // [2, 4, 6]
console.log(numbers);  // [1, 2, 3] — unchanged
foreach.js
const numbers = [1, 2, 3];
numbers.forEach(num => {
  console.log(num * 2);
});
// 2
// 4
// 6

Real-world Example

real-world.js
const users = [{ name: "John" }, { name: "Alice" }];

// map() — build a new array
const names = users.map(user => user.name);
console.log(names); // ["John", "Alice"]

// forEach() — just a side effect
users.forEach(user => console.log(user.name));
Interview point: use map() when you need a new array, and forEach() for logging, API calls, or DOM updates where no return value is needed.
2. filter() vs find()

Both search an array using a condition, but differ in how many results they return.

Featurefilter()find()
ReturnsArraySingle element
Number of matchesAllFirst
If no matchEmpty arrayundefined

Example

filter-find.js
const numbers = [10, 20, 30, 40];

const result1 = numbers.filter(num => num > 20);
console.log(result1); // [30, 40]

const result2 = numbers.find(num => num > 20);
console.log(result2); // 30

Real-world Example

real-world.js
const users = [{ id: 1 }, { id: 2 }, { id: 3 }];

const user = users.find(u => u.id === 2);
console.log(user); // { id: 2 }
Interview point: filter() gives you multiple results, find() gives you only the first result.
3. How does reduce() work?

reduce() reduces an array into a single value by executing a callback for every element while carrying forward an accumulator.

Syntax

syntax.js
array.reduce((accumulator, currentValue) => {
  return accumulator;
}, initialValue);

Example

reduce.js
const numbers = [1, 2, 3, 4];

const sum = numbers.reduce((acc, num) => acc + num, 0);
console.log(sum); // 10

Execution Flow

acc = 0 → 0 + 1 = 1 → 1 + 2 = 3 → 3 + 3 = 6 → 6 + 4 = 10

Finding Maximum

max.js
const nums = [10, 50, 20];

const max = nums.reduce((acc, value) => value > acc ? value : acc);
console.log(max); // 50
Common uses: sum, average, maximum, minimum, grouping, counting, and flattening arrays.
4. slice() vs splice()
Featureslice()splice()
Changes original array❌ No✅ Yes
ReturnsNew arrayRemoved elements
PurposeCopy portionAdd/Remove/Replace elements

slice()

slice.js
const arr = [1, 2, 3, 4, 5];

const result = arr.slice(1, 4);
console.log(result); // [2, 3, 4]
console.log(arr);    // original unchanged

splice() — remove

splice-remove.js
const arr = [1, 2, 3, 4];

arr.splice(1, 2);
console.log(arr); // [1, 4]

splice() — insert

splice-insert.js
const arr = [1, 4];

arr.splice(1, 0, 2, 3);
console.log(arr); // [1, 2, 3, 4]

splice() — replace

splice-replace.js
const arr = [1, 2, 3];

arr.splice(1, 1, 100);
console.log(arr); // [1, 100, 3]
Interview point: slice() is non-destructive, splice() is destructive (it mutates the original array).
5. find() vs findIndex()
Featurefind()findIndex()
ReturnsElementIndex
If not foundundefined-1

Example

find-findindex.js
const users = [{ id: 1 }, { id: 2 }];

console.log(users.find(user => user.id === 2));
// { id: 2 }

console.log(users.findIndex(user => user.id === 2));
// 1
Interview point: use find() when you need the object itself, and findIndex() when you need its position in the array.
6. some() vs every()

Both return a Boolean.

Featuresome()every()
Returns true ifAt least one element matchesAll elements match
Stops earlyYesYes

some()

some.js
const nums = [2, 4, 5, 8];

const result = nums.some(num => num % 2 !== 0);
console.log(result); // true

every()

every.js
const nums = [2, 4, 6];

const result = nums.every(num => num % 2 === 0);
console.log(result); // true
Interview point: some() behaves like OR logic, every() behaves like AND logic.
7. How does sort() work?

sort() sorts array elements in place.

Default Behavior

default-sort.js
const arr = [10, 2, 30];

arr.sort();
console.log(arr); // [10, 2, 30]

Why? Because the default sort converts elements to strings and compares them lexicographically — "10", "2", "30" sort as 10, 2, 30, not numerically.

Numeric Sort — Ascending / Descending

numeric-sort.js
const arr = [10, 2, 30];

arr.sort((a, b) => a - b);
console.log(arr); // [2, 10, 30] — ascending

arr.sort((a, b) => b - a); // descending

Sorting Objects

sort-objects.js
const users = [
  { name: "John", age: 30 },
  { name: "Alice", age: 20 }
];

users.sort((a, b) => a.age - b.age);
Interview point: always provide a comparator function for numeric sorting — the default sort treats every value as a string.
8. flat() vs flatMap()
Featureflat()flatMap()
Flattens nested arrays✅ Yes✅ Yes
Maps elements❌ No✅ Yes
Equivalent toflat()map().flat()

flat()

flat.js
const arr = [1, [2, 3], [4, [5]]];

console.log(arr.flat());   // [1, 2, 3, 4, [5]]
console.log(arr.flat(2));  // [1, 2, 3, 4, 5] — deeper flatten

flatMap()

flatmap.js
const numbers = [1, 2, 3];

const result = numbers.flatMap(num => [num, num * 2]);
console.log(result); // [1, 2, 2, 4, 3, 6]

// equivalent to:
numbers.map(num => [num, num * 2]).flat();

Real-world Example

real-world.js
const users = [
  { name: "John", skills: ["JS", "React"] },
  { name: "Alice", skills: ["Node"] }
];

const skills = users.flatMap(user => user.skills);
console.log(skills); // ["JS", "React", "Node"]
Interview point: flat() just flattens nested arrays; flatMap() transforms each element first, then flattens one level.
