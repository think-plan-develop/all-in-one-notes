🗂️ Map, WeakMap, Set & WeakSet

ES6's dedicated collection types — key-value storage, uniqueness, and memory-friendly variants — with real project examples for each

Map WeakMap Set WeakSet Quick Comparison
📌 In short: Map stores key-value pairs with keys of any type; Set stores unique values. Their Weak variants only accept object keys/values, aren't iterable, and have no size — trading that away so entries can be garbage collected automatically once nothing else references the object.
🔑 Key Terms at a Glance
🗺️
Map: Key-value collection where keys can be any type — strings, numbers, objects, even functions.
🕸️
WeakMap: Like Map, but keys must be objects, held weakly so they can be garbage collected.
🔷
Set: A collection of unique values — duplicates are silently ignored.
👻
WeakSet: Like Set, but only objects, held weakly for automatic cleanup.
1. Map

Definition & Features

ES6
A Map is a built-in ES6 collection that stores key-value pairs. Unlike plain objects, Map keys can be of any data type — string, number, object, function, boolean, and more.
  • Stores key-value pairs.
  • Keys can be any data type.
  • Preserves insertion order.
  • Duplicate keys are not allowed — setting an existing key updates its value instead.
  • Fast lookup using keys.

Common Methods

MethodDescription
set(key, value)Add or update a key-value pair
get(key)Get value by key
has(key)Check if key exists
delete(key)Remove an entry
clear()Remove all entries
sizeNumber of entries

Iterating

map-iterate.js
for (const [key, value] of map) {}

map.forEach((value, key) => {});

Object ⇄ Map

object-map-convert.js
const map = new Map(Object.entries(obj));

const obj = Object.fromEntries(map);

Real Project Example — API Cache

Use Case
api-cache.js
const cache = new Map();

function getUser(id) {
    if (cache.has(id)) {
        return cache.get(id);
    }

    const user = { id, name: "Rahul" };

    cache.set(id, user);

    return user;
}
💡 Use case: Avoid repeated API calls by caching results keyed by ID.

Real Project Example — Product Lookup

Use Case
product-lookup.js
const products = new Map();

products.set(101, {
    name: "Laptop",
    price: 65000
});

console.log(products.get(101));
💡 Use case: E-commerce product lookup, keyed by product ID rather than a string.
2. WeakMap

Definition & Notes

ES6
A WeakMap is similar to a Map, but only objects can be used as keys. If an object key has no other references left, it can be garbage collected automatically — its WeakMap entry disappears with it.

Methods

  • set()
  • get()
  • has()
  • delete()
⚠️ Note
  • Object keys only
  • Not iterable
  • No size property

Real Project Example — Store Private Data

Use Case
private-data.js
const privateData = new WeakMap();

class User {
    constructor(name) {
        privateData.set(this, {
            password: "123456"
        });

        this.name = name;
    }

    getPassword() {
        return privateData.get(this).password;
    }
}
💡 Use case: Truly private instance data that can't be accessed from outside the class, without needing private class fields.

Real Project Example — Store DOM Metadata

Use Case
dom-metadata.js
const meta = new WeakMap();

const button = document.querySelector("button");

meta.set(button, {
    clicks: 0
});
💡 Use case: Frameworks store metadata on DOM elements without causing memory leaks — if the element is removed from the page, its metadata is cleaned up too.
3. Set

Definition & Features

ES6
A Set is a built-in ES6 collection that stores unique values. Duplicate values are automatically ignored.
  • Stores unique values only.
  • Values can be any data type.
  • Preserves insertion order.
  • Fast lookup using has().

Common Methods

MethodDescription
add(value)Add a value
has(value)Check value
delete(value)Remove value
clear()Remove all values
sizeNumber of values

Check Duplicates

check-duplicates.js
const hasDuplicates = arr =>
    new Set(arr).size !== arr.length;

Set Operations

set-operations.js
// Union
new Set([...a, ...b]);

// Intersection
new Set([...a].filter(x => b.has(x)));

// Difference
new Set([...a].filter(x => !b.has(x)));

Real Project Example — Remove Duplicate Values

Use Case
remove-duplicates.js
const numbers = [1, 2, 3, 2, 1];

const uniqueNumbers = [...new Set(numbers)];

console.log(uniqueNumbers);
// Output: [1, 2, 3]

Real Project Example — User Permissions

Use Case
user-permissions.js
const permissions = new Set([
    "READ",
    "WRITE"
]);

if (permissions.has("WRITE")) {
    console.log("Permission Granted");
}
💡 Use case: Role-based access control (RBAC) — checking a user's permission set is a fast has() lookup.
4. WeakSet

Definition & Notes

ES6
A WeakSet stores objects only. Objects are held weakly, so they can be garbage collected once nothing else references them.

Methods

  • add()
  • has()
  • delete()
⚠️ Note
  • Objects only
  • Not iterable
  • No size property

Real Project Example — Track Processed Objects

Use Case
track-processed.js
const processed = new WeakSet();

const user = {
    id: 1
};

processed.add(user);

console.log(processed.has(user));

Real Project Example — Prevent Duplicate Processing

Use Case
prevent-duplicate-processing.js
const visited = new WeakSet();

function process(node) {
    if (visited.has(node)) return;

    visited.add(node);

    console.log("Processing...");
}
💡 Use case: Guard against re-processing the same object/DOM node (e.g. tree traversal, observer callbacks) without leaking memory for objects that later disappear.
