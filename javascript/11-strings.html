Definition

What is a String?

Start Here
A string is a sequence of characters used to represent text. In JavaScript, strings are primitive values and are immutable — every method that "changes" a string actually returns a brand-new string.
📝 Interview Definition: A string is an immutable primitive data type that represents a sequence of UTF-16 encoded characters, and every string operation returns a new string rather than modifying the original.
Template Literals

Backtick Strings

ES6

Template literals use backticks (` `) instead of quotes, and support embedded expressions and multi-line text without extra characters.

template-literals.js
const name = "Maya";
const age = 28;

// Old way — string concatenation
const old = "Hi, I'm " + name + " and I'm " + age + " years old.";

// Template literal — cleaner interpolation
const greeting = `Hi, I'm ${name} and I'm ${age} years old.`;

// Multi-line, no \n needed
const multi = `Line one
Line two
Line three`;

// Expressions work too
const total = `Total: ${10 * 3}`; // "Total: 30"
💡 Tip: Template literals also support "tagged templates" — a function placed right before the backticks that can process the string and interpolated values before they're combined.
String Methods

Common Built-in Methods

Strings come with a large set of built-in methods for reading, searching, and transforming text.

string-methods.js
const str = "Hello World";

str.length;             // 11
str.toUpperCase();      // "HELLO WORLD"
str.slice(-5);          // "World" — negative index counts from the end
str.includes("World"); // true
str.charAt(0);         // "H"
⚠️ Remember: All string methods return a new string — the original is never modified, since strings are immutable.
Split & Join

String → Array with split()

split(separator) breaks a string into an array of substrings, using the given separator.

split.js
"a,b,c".split(",");       // ["a", "b", "c"]
"Hello World".split(" "); // ["Hello", "World"]
"hello".split("");      // ["h","e","l","l","o"]
"a,b,c".split(",", 2);    // ["a", "b"] — limit param
"one".split();            // ["one"] — no separator = whole string in one element
📝 Note: split() also accepts a regular expression as the separator, letting you split on complex patterns like multiple spaces: "a b".split(/\s+/).

Array → String with join()

join() is the reverse of split() — it's an array method that combines elements into a single string, using a given separator.

join.js
const parts = ["a", "b", "c"];

parts.join();      // "a,b,c" — default separator is a comma
parts.join("");    // "abc" — no separator
parts.join(" - "); // "a - b - c"

// Common pattern: split, transform, join
const sentence = "the quick brown fox";
sentence.split(" ").join("-"); // "the-quick-brown-fox"
💡 Tip: split() + join() together are a quick way to do a global find-and-replace of a fixed string, before regex-based replaceAll() was widely available.
Replace & Trim

replace() and replaceAll()

replace() swaps the first match of a substring or pattern; replaceAll() swaps every match.

replace.js
const text = "cat sat on the cat mat";

text.replace("cat", "dog");
// "dog sat on the cat mat" — only the FIRST match

text.replaceAll("cat", "dog");
// "dog sat on the dog mat" — ALL matches

// With regex + global flag (works like replaceAll)
text.replace(/cat/g, "dog");
// "dog sat on the dog mat"

// Using a function as the replacement
"5 + 3".replace(/\d+/g, n => Number(n) * 2);
// "10 + 6"
⚠️ Gotcha: replace("cat", "dog") only replaces the first occurrence unless you pass a /g regex or use replaceAll(). This trips up a lot of beginners.

trim(), trimStart(), trimEnd()

These methods remove whitespace from a string — useful for cleaning up user input from forms.

trim.js
const input = "   hello world   ";

input.trim();       // "hello world" — removes both sides
input.trimStart();  // "hello world   " — removes leading only
input.trimEnd();    // "   hello world" — removes trailing only
💡 Common use case: Always trim() user input (like emails or usernames) before validating or storing it, so " a@b.com " and "a@b.com" are treated the same.
Regex Basics

Regular Expressions

Pattern Matching

A regular expression (regex) describes a pattern for matching text — used with methods like test(), match(), and replace().

regex-create.js
// Two ways to create a regex
const pattern1 = /hello/i;             // literal syntax, i = case-insensitive
const pattern2 = new RegExp("hello", "i"); // constructor syntax
SymbolMeaning
.Any single character
\dAny digit (0-9)
\wAny word character (letters, digits, underscore)
\sAny whitespace character
*0 or more of the previous token
+1 or more of the previous token
?0 or 1 of the previous token (optional)
^Start of string
$End of string
[abc]Any one of a, b, or c
g flagGlobal — match all occurrences, not just the first
i flagCase-insensitive matching
regex-usage.js
const emailPattern = /^\w+@\w+\.\w+$/;

emailPattern.test("a@b.com");  // true
emailPattern.test("not-an-email"); // false

"Order #123, Order #456".match(/\d+/g);
// ["123", "456"]

"2026-07-05".replace(/(\d{4})-(\d{2})-(\d{2})/, "$3/$2/$1");
// "05/07/2026" — capture groups reordered
📝 Note: test() returns a boolean (does it match?), while match() returns the actual matched text (or null if nothing matches).
Most Asked Output Questions

Question 1

⭐⭐⭐⭐
output-q1.js
let str = "hello";
str[0] = "H";
console.log(str);
Output: "hello" (unchanged)

Why? Strings are immutable — you cannot change a character by index assignment. The assignment silently fails (or throws in strict mode) instead of mutating the string.

Question 2

⭐⭐⭐⭐
output-q2.js
console.log("5" + 3);
console.log("5".replace("5", 3));
console.log(typeof "5".replace("5", 3));
Output: "53", then "3", then "string"

Why? + triggers string concatenation. replace() always returns a string, even when the replacement value is a number — it gets coerced to a string in the result.

Interview Summary

Key Points to Remember

  • Strings are immutable primitives — every method returns a new string.
  • Template literals use backticks, support ${expr} interpolation, and native multi-line text.
  • slice() supports negative indices; substring() does not.
  • split() turns a string into an array; join() does the reverse.
  • replace() only changes the first match unless you use /g or replaceAll().
  • trim(), trimStart(), and trimEnd() clean up whitespace from user input.
  • Regex test() returns a boolean; match() returns the matched text or null.
  • Index assignment on a string (str[0] = "H") silently fails — it does not mutate the string.
💡 Common misconception: Beginners often assume replace() replaces every occurrence like a find-and-replace in a text editor. By default it only replaces the first match — the global flag or replaceAll() is required for the rest.
Interview Q&A — Strings
💡 Interview Q&A
Why are strings immutable in JavaScript?
Strings are a primitive type, and primitives in JavaScript are immutable by design. This makes them safe to pass around and compare by value, and lets the engine optimize memory since a string's contents can never change after creation — any "modification" always produces a new string.
What's the difference between slice() and substring()?
Both extract a section of a string given a start and end index, but slice() accepts negative indices to count from the end, while substring() treats negative values as 0 and also swaps the arguments if start is greater than end.
How would you check if a string is a valid email using regex?
Use the test() method on a pattern like /^\w+@\w+\.\w+$/, which anchors the match with ^ and $ so the whole string must fit the word-at-word-dot-word shape. Real-world validation usually needs a more permissive pattern, since email rules allow more characters than \w covers.
How do you replace all occurrences of a substring?
Use replaceAll() for a plain string, or replace() with a regex that has the global /g flag. Without one of these, replace() only swaps the first match it finds.
