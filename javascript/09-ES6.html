ES6+ Features

JavaScript has evolved fast since ES6 (2015) — one new spec every year. Here's every feature that shows up in real code and interviews, from ES6 through the latest yearly updates.

Definition Start Here

ES6 (ECMAScript 2015) was the biggest single update to JavaScript ever, introducing classes, modules, arrow functions, and more. Since then, ECMAScript ships a new yearly version (ES2016, ES2017 ... ES2024, ES2025), each adding smaller, focused features.

Interview Definition: ES6+ refers to all JavaScript language features introduced from ECMAScript 2015 onward, including syntax additions (arrow functions, classes, destructuring) and built-in API additions (Promises, Map/Set, optional chaining).
1. let & const
Block-Scoped Declarations ES6

let and const replaced var as the standard way to declare variables, adding real block scope and a Temporal Dead Zone that catches use-before-declare bugs.

let-const.js
let count = 0;   // reassignable, block-scoped
count = 1;         // ✅ works

const PI = 3.14; // cannot be reassigned
// PI = 3.15;   ❌ TypeError

if (true) {
  let scoped = "inside";
}
// console.log(scoped); ❌ ReferenceError — stays inside the block
Best practice: Default to const, use let only when reassignment is needed, and avoid var entirely in new code.
2. Arrow Functions
Concise Function Syntax ES6

Arrow functions offer shorter syntax and — unlike regular functions — don't have their own this, arguments, or super; they inherit these from the enclosing scope.

arrow-functions.js
// Regular function
function add(a, b) { return a + b; }

// Arrow function — equivalent
const add2 = (a, b) => a + b;

// Single param doesn't need parens
const square = x => x * x;

// Multi-line body needs explicit return
const greet = name => {
  const msg = `Hello, ${name}`;
  return msg;
};
Watch out: Because arrow functions don't bind their own this, avoid them for object methods, constructors, and prototype methods.
3. Destructuring
Unpacking Arrays & Objects ES6

Destructuring extracts values from arrays or properties from objects into individual variables in one line.

destructuring.js
// Array destructuring
const [first, second] = [10, 20];
// first = 10, second = 20

const [, , third] = [1, 2, 3]; // skip elements

// Object destructuring
const user = { name: "Sam", age: 28 };
const { name, age } = user;

// Renaming while destructuring
const { name: userName } = user; // userName = "Sam"

// Default values
const { role = "guest" } = user; // role = "guest" (not on user)

// Nested destructuring
const { address: { city } } = { address: { city: "Delhi" } };

// In function parameters
function printUser({ name, age }) {
  console.log(`${name} is ${age}`);
}
Common use case: Destructuring props in React components, or pulling named exports out of a module in a single line.
4. Spread Operator
Expanding Values with ... ES6 / ES2018

The spread operator (...) expands an array or object into individual elements/properties — used for copying, merging, and passing arguments.

spread.js
// Copying an array
const nums = [1, 2, 3];
const copy = [...nums]; // [1, 2, 3] — independent copy

// Merging arrays
const merged = [...nums, 4, 5]; // [1,2,3,4,5]

// Copying / merging objects (ES2018)
const user = { name: "Sam" };
const updated = { ...user, age: 28 }; // { name: "Sam", age: 28 }

// Spreading into function arguments
Math.max(...nums); // 3
Note: Spread creates a shallow copy — nested objects/arrays inside are still shared references, not deeply cloned.
5. Rest Operator
Collecting Values with ... ES6

The rest operator looks identical to spread (...) but does the opposite — it collects remaining items into an array or object, instead of expanding them.

rest.js
// Rest in function parameters — collect all remaining args
function sum(...nums) {
  return nums.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3); // 6

// Rest in array destructuring
const [first, ...rest] = [1, 2, 3, 4];
// first = 1, rest = [2, 3, 4]

// Rest in object destructuring
const { id, ...otherFields } = { id: 1, name: "Sam", age: 28 };
// otherFields = { name: "Sam", age: 28 }
How to tell spread and rest apart: Same symbol, opposite job. On the right side of an assignment (or in a function call) it spreads. On the left side (parameters/destructuring) it collects (rest).
6. Template Literals
Backtick Strings ES6

Template literals use backticks and support embedded expressions and native multi-line strings.

template-literals.js
const name = "Maya";
const greeting = `Hello, ${name}! Today is ${new Date().toDateString()}.`;

const multiLine = `Line one
Line two`;
Note: Tagged templates — a function placed right before the backticks — let you intercept and process the literal and its interpolated values, used by libraries like styled-components.
7. Default Parameters
Fallback Values for Arguments ES6

Function parameters can specify a default value used when the argument is undefined or omitted.

default-params.js
function greet(name = "Guest", greeting = "Hello") {
  console.log(`${greeting}, ${name}!`);
}

greet();               // "Hello, Guest!"
greet("Sam");         // "Hello, Sam!"
greet(undefined, "Hi"); // "Hi, Guest!" — undefined triggers the default

// Defaults can reference earlier parameters
function createBox(width, height = width) {
  return { width, height };
}
createBox(5); // { width: 5, height: 5 }
Gotcha: Passing null does NOT trigger the default — only undefined does. greet(null) logs "Hello, null!".
8. Optional Chaining
Safe Property Access with ?. ES2020

Optional chaining stops evaluation and returns undefined instead of throwing, when accessing a property on null or undefined.

optional-chaining.js
const user = { profile: { name: "Sam" } };

user?.profile?.name;      // "Sam"
user?.address?.city;      // undefined — no error, even though address doesn't exist
user.address.city;        // ❌ TypeError without optional chaining

// Works with function calls too
user.greet?.();  // undefined if greet doesn't exist, instead of throwing

// Works with array access
const arr = null;
arr?.[0]; // undefined
Common use case: Safely reading deeply nested API response data where some fields might be missing.
9. Nullish Coalescing
Fallback with ?? ES2020

?? returns the right-hand value only when the left side is null or undefined — unlike ||, it doesn't trigger on other falsy values like 0 or "".

nullish-coalescing.js
const count = 0;

count ?? 10; // 0 — 0 is not null/undefined, so it's kept
count || 10; // 10 — 0 is falsy, so || replaces it (often a bug)

const settings = { theme: null };
settings.theme ?? "light"; // "light"
Note: ES2021 added logical assignment operators built on this same idea: ??=, ||=, and &&= — see "More Modern Features" below.
10. Modules
import / export ES6

ES Modules let you split code across files, with explicit imports and exports, replacing older patterns like CommonJS's require().

math.js
// Named exports
export const PI = 3.14;
export function add(a, b) { return a + b; }

// Default export — one per file
export default function multiply(a, b) { return a * b; }
app.js
import multiply, { PI, add } from "./math.js";
import * as MathUtils from "./math.js"; // namespace import

// Dynamic import (ES2020) — loads on demand, returns a Promise
const module = await import("./math.js");
Benefit: Modules are strict mode by default, each module has its own scope (no global leaks), and dynamic import() enables code-splitting for faster page loads.
11. Classes
class Syntax ES6 / ES2022

Classes are syntactic sugar over JavaScript's existing prototype-based inheritance — cleaner syntax for the same underlying mechanism.

classes.js
class Animal {
  // Private field (ES2022) — only accessible inside the class
  #energy = 100;

  // Static field (ES2022) — belongs to the class, not instances
  static kingdom = "Animalia";

  constructor(name) {
    this.name = name;
  }

  speak() {
    console.log(`${this.name} makes a sound. Energy: ${this.#energy}`);
  }

  static describe() {
    return `Kingdom: ${Animal.kingdom}`;
  }
}

class Dog extends Animal {
  speak() {
    super.speak();
    console.log(`${this.name} barks.`);
  }
}

const dog = new Dog("Rex");
dog.speak();
// dog.#energy;  ❌ SyntaxError — private field, inaccessible outside the class
Note: Private fields (#field) and static fields/methods were both standardized in ES2022, making classes far more capable than the ES6 original.
12. More Modern ES Features (ES2016 – ES2024)
Async Programming ES2015 / ES2017

Promises and async/await are the standard way to handle asynchronous operations, replacing deeply nested callbacks.

async-await.js
async function getUser(id) {
  try {
    const res = await fetch(`/api/users/${id}`);
    const data = await res.json();
    return data;
  } catch (err) {
    console.error(err);
  }
}

// Run promises in parallel
const [a, b] = await Promise.all([fetch("/a"), fetch("/b")]);

// ES2020/2021: settle all regardless of failures, or get first success
await Promise.allSettled([p1, p2]);
await Promise.any([p1, p2]);

// ES2022: top-level await — no wrapping async function needed in modules
const config = await fetch("/config.json").then(r => r.json());
Logical Assignment Operators ES2021

Shorthand combinations of logical operators with assignment.

logical-assignment.js
let config = { theme: null };

config.theme ??= "dark";   // assigns only if null/undefined
config.count ||= 10;      // assigns only if falsy
config.active &&= false;    // assigns only if currently truthy

14. Generators & Iterators
Pausable Functions & the Iterator Protocol ES6

An iterator is any object with a next() method that returns { value, done }. A generator is a special function (function*) that automatically builds an iterator for you, and can pause mid-execution with yield.

generator-basics.js
function* idGenerator() {
  let id = 1;
  while (true) {
    yield id++;   // pauses here, returns id, resumes on next next()
  }
}

const gen = idGenerator();  // calling it doesn't run the body yet
gen.next();  // { value: 1, done: false }
gen.next();  // { value: 2, done: false }
gen.next();  // { value: 3, done: false }

Generator Object Methods

MethodWhat it doesExample
next(value)Resumes execution, optionally sending value in as the result of the last yieldgen.next() → {value, done}
return(value)Stops the generator early, as if a return happened theregen.return(99) → {value:99, done:true}
throw(error)Throws an error inside the generator at the paused point (catchable with try/catch inside)gen.throw(new Error("stop"))
yield-two-way.js
// yield can also receive values passed into next()
function* chat() {
  const name = yield "What's your name?";
  console.log(`Hello, ${name}!`);
}

const g = chat();
g.next();          // { value: "What's your name?", done: false }
g.next("Sam");   // logs "Hello, Sam!", then { value: undefined, done: true }

// yield* delegates to another generator or iterable
function* inner() { yield 1; yield 2; }
function* outer() { yield* inner(); yield 3; }
[...outer()]; // [1, 2, 3]

Custom Iterables with Symbol.iterator

Any object becomes usable in for...of and spread [...obj] if it implements Symbol.iterator — generators make this trivial.

custom-iterable.js
const range = {
  from: 1,
  to: 3,
  [Symbol.iterator]: function* () {
    for (let i = this.from; i <= this.to; i++) {
      yield i;
    }
  }
};

for (const num of range) {
  console.log(num); // 1, 2, 3
}
[...range]; // [1, 2, 3] — spread works too
Why it matters: Generators power lazy sequences (infinite data without infinite memory), custom iteration logic, and were the foundation async/await was built on top of.
15. Map, Set & Their Weak Variants
Modern Collection Types ES6

Map and Set are dedicated collection types that improve on plain objects and arrays for key-value storage and uniqueness — with WeakMap/WeakSet as memory-friendly variants for object keys.

Map — key/value pairs, any key type

map.js
const map = new Map();
const objKey = { id: 1 };

map.set("name", "Sam"); // string key
map.set(objKey, "metadata"); // object as a key — impossible with plain objects

map.get("name");   // "Sam"
map.has("name");   // true
map.size;             // 2
map.delete("name");
map.clear();          // removes everything
Map Method / PropertyPurpose
set(key, value)Adds or updates an entry, returns the map (chainable)
get(key)Returns the value, or undefined if not found
has(key)Checks if the key exists
delete(key)Removes one entry, returns true/false
clear()Removes all entries
sizeNumber of entries (property, not a method)
keys() / values() / entries()Returns iterators over keys, values, or [key, value] pairs
forEach((value, key) => {})Loops over every entry

Set — a collection of unique values

set.js
const set = new Set([1, 2, 2, 3]);
// duplicates are dropped automatically → Set(3) {1, 2, 3}

set.add(4);
set.has(2);    // true
set.size;         // 4
set.delete(1);
[...set];         // [2, 3, 4] — convert back to an array
Set Method / PropertyPurpose
add(value)Adds a value (ignored if already present), chainable
has(value)Checks if the value exists
delete(value)Removes the value, returns true/false
clear()Removes all values
sizeNumber of values
keys() / values()Both return an iterator over the values (identical for Set)
forEach(value => {})Loops over every value
Common use case: [...new Set(array)] is the shortest way to remove duplicates from an array.

WeakMap & WeakSet — memory-friendly variants

weak-map-set.js
const wm = new WeakMap();
let user = { name: "Sam" };
wm.set(user, "private data");

user = null; // user object is now garbage-collected, and its WeakMap entry disappears too

const ws = new WeakSet();
ws.add(document.body); // only objects allowed, no primitives
FeatureWeakMap / WeakSet
Available methodsset/get/has/delete (WeakMap), add/has/delete (WeakSet) — same names as their non-weak versions
Keys must beObjects only — no strings, numbers, or other primitives
size propertyNot available
Iterable / forEachNot available — entries can vanish at any time via garbage collection
Why use itPrevents memory leaks when attaching extra data to objects you don't fully control the lifecycle of
Note: The lack of iteration/size on Weak variants isn't a missing feature — it's intentional, since entries can disappear unpredictably as soon as the object key is garbage-collected.
