📦 Variables & Data Types
1

Variable Declarations

What are the different ways to declare variables (var, let, const)?
var is function-scoped, can be redeclared and updated, and is hoisted with undefined. let is block-scoped, can be updated but not redeclared. const is block-scoped and cannot be reassigned after initialization.
2

Hoisting

What is Hoisting? How does it work for variables and functions?
Hoisting is JavaScript's behavior of moving declarations to the top of their scope during the compilation phase. Function declarations are fully hoisted, var is hoisted with undefined, while let/const are hoisted but remain inaccessible until initialized (TDZ).
3

Temporal Dead Zone

What is the Temporal Dead Zone (TDZ)?
TDZ is the period between entering a scope and the initialization of a let or const variable. Accessing the variable during this period throws a ReferenceError.
4

Data Types

What are Primitive and Non-Primitive data types?
Primitive types (string, number, boolean, null, undefined, symbol, bigint) are immutable and stored by value. Non-primitive types (Objects, Arrays, Functions) are mutable and stored by reference.
Primitive
  • string, number, boolean
  • null, undefined
  • symbol, bigint
Non-Primitive
  • Objects
  • Arrays
  • Functions
5

Comparisons & Nullish Values

What is the difference between == and ===?
== performs type coercion before comparison, while === compares both value and type without conversion. Using === is recommended to avoid unexpected results.
What is the difference between null and undefined?
undefined means a variable has been declared but not assigned a value. null is an intentional assignment representing the absence of a value.
🔒 Scope & Closures
6

Closures

What are Closures? Explain with a real-world example.
A closure is a function that remembers and can access variables from its outer scope even after the outer function has finished executing. Common use cases include data privacy, counters, and event handlers.
closure.js 
function counter() {
  let count = 0;

  return function () {
    return ++count;
  };
}

const increment = counter();

increment(); // 1
increment(); // 2
increment(); // 3
7

Lexical Scope & this

What is Lexical Scope?
Lexical scope means a function can access variables defined in its own scope and its outer scopes based on where it is written, not where it is called.
What is the this keyword? How does its value change in different contexts?
this refers to the object that invokes the function. Its value depends on how the function is called: global object (or undefined in strict mode), the object itself, a constructor instance, or explicitly set using call, apply, or bind.
⏱️ Event Loop & Async
8

Event Loop

What is the Event Loop? Explain the Call Stack, Web APIs, Callback Queue, and Microtask Queue.
The Event Loop continuously checks if the Call Stack is empty. It executes all Microtasks (Promises, queueMicrotask) before processing Macrotasks (e.g., setTimeout, setInterval) from the Callback Queue.
9

Async Patterns & Task Queues

What are Callbacks, Promises, and Async/Await?
Callbacks are functions passed to another function for asynchronous execution. Promises provide a cleaner way to handle asynchronous operations, while async/await offers synchronous-looking code built on top of Promises.
What are Microtasks and Macrotasks?
Microtasks include Promise callbacks and queueMicrotask(), executing immediately after the current task. Macrotasks include setTimeout, setInterval, and DOM events, which run after all Microtasks complete.

🧩 Functions
10

Arrow Functions

What are Arrow Functions? How are they different from regular functions?
Arrow functions provide a shorter syntax and do not have their own this, arguments, or prototype. They inherit this from the surrounding lexical scope, making them useful for callbacks.
11

Higher-Order Functions

What are Higher-Order Functions? Give examples.
Higher-Order Functions are functions that accept other functions as arguments or return functions. Examples include map(), filter(), reduce(), forEach(), and setTimeout().
hof.js 
const numbers = [1, 2, 3, 4];

const doubled = numbers.map(num => num * 2);

console.log(doubled); // [2, 4, 6, 8]
12

call(), apply(), bind()

What are call(), apply(), and bind()? When should you use each?
All three methods are used to explicitly set the value of this. call() invokes the function immediately with arguments listed individually. apply() invokes immediately with arguments as an array. bind() returns a new function with this permanently bound, without executing it.
this-binding.js 
const person = {
  name: "Shivam"
};

function greet(city) {
  console.log(this.name + " from " + city);
}

greet.call(person, "Delhi");
greet.apply(person, ["Mumbai"]);

const fn = greet.bind(person);
fn("Pune");
🧬 Objects & Prototypes

Prototypal Inheritance

What is Prototypal Inheritance? Explain the Prototype Chain.
Every JavaScript object can inherit properties and methods from another object through its prototype. If a property isn't found on the object, JavaScript searches its prototype chain until it finds the property or reaches null.
prototype.js 
const person = {
  greet() {
    console.log("Hello");
  }
};

const user = Object.create(person);

user.greet(); // Hello
Prototype Chain: user → person → Object.prototype → null
14

Shallow vs Deep Copy

What is the difference between Shallow Copy and Deep Copy?
Shallow Copy copies only the first level — nested objects are still referenced, so changes affect the original object. Deep Copy creates completely independent copies, including all nested objects.
copy.js 
// Shallow Copy
const obj1 = { user: { name: "John" } };
const obj2 = { ...obj1 };
obj2.user.name = "Mike";
console.log(obj1.user.name); // "Mike" ❌

// Deep Copy
const obj3 = structuredClone(obj1);
obj3.user.name = "Mike";
console.log(obj1.user.name); // "John" ✅
15

Modules

What are Modules in JavaScript? Explain CommonJS vs ES Modules.
Modules allow code to be split into reusable files. CommonJS (require, module.exports) is primarily used in Node.js, while ES Modules (import, export) are the standard module system for modern JavaScript and browsers.
🧠 Advanced Patterns

Event Bubbling, Capturing & Delegation

What is Event Bubbling, Event Capturing, and Event Delegation?
Event Bubbling: the event propagates from the target element up to its parent elements (child → parent) — the default behavior. Event Capturing: the event propagates from the outermost parent down to the target (parent → child). Event Delegation: a single listener on a parent handles events from multiple children using bubbling.
events.js 
// Capturing: document → parent → button
// Target: button
// Bubbling: button → parent → document

// Delegation Example
parent.addEventListener("click", (e) => {
  if (e.target.tagName === "BUTTON") {
    console.log("Button clicked");
  }
});

Memoization

What is Memoization? What are its advantages and use cases?
Memoization is an optimization technique that stores the results of expensive function calls and returns the cached result for the same inputs instead of recalculating, improving performance by avoiding repeated computations.
memoize.js 
const memo = {};

function square(n) {
  if (memo[n]) return memo[n];

  console.log("Calculating...");
  memo[n] = n * n;
  return memo[n];
}

square(5); // Calculating...
square(5); // Returns cached result
Advantages
  • Improves performance
  • Avoids repeated calculations
  • Reduces execution time
Common Use Cases
  • Recursive algorithms (Fibonacci)
  • Dynamic Programming
  • API response caching
