🌐 What is JavaScript?

JavaScript is a high-level, dynamic language used to add behavior to web pages. It can respond to events, validate input, fetch data, and run on browsers, servers, and mobile apps.

It is used with HTML and CSS to build interactive web applications.
2

🏷️ What are the different data types in JavaScript?

JavaScript has primitive types like string, number, boolean, undefined, null, symbol, and bigint, plus object types such as arrays, functions, and plain objects.

data-types.js
let name = "Aisha";
let age = 28;
let isActive = true;
let user = { name, age };
3

🔗 What is the difference between primitive and reference types?

Primitive values are copied by value, while objects and arrays are copied by reference. Changing one reference affects all variables pointing to the same object.

primitive-vs-reference.js
let a = 5;
let b = a;
b = 10;

let obj1 = { name: "John" };
let obj2 = obj1;
obj2.name = "Mike";
4

🔒 What is strict mode?

Strict mode helps catch common mistakes by making JavaScript behave more securely. It prevents accidental globals and throws errors for unsafe actions.

strict-mode.js
"use strict";
let value = 10;

⚖️ Difference between == and ===

== performs type coercion before comparing values; === compares both value and type without any conversion.

equality.js
5 == "5"       // true
5 === "5"      // false

null == undefined    // true
null === undefined   // false
Best practice: always prefer === to avoid unexpected coercion bugs.

✅ Truthy and Falsy values

There are only 8 falsy values in JavaScript — everything else is truthy.

false, 0, -0, 0n, "", null, undefined, NaN
truthy.js
if ("Hello") {
  console.log("Truthy");
}

if ([]) {
  console.log("Array is Truthy"); // even an empty array!
}

🔄 What is Type Coercion?

JavaScript automatically converts one data type into another during operations.

coercion.js
"5" + 2       // "52" (string concatenation)
"5" - 2       // 3   (numeric conversion)
true + 1      // 2
false + false  // 0
Implicit Coercion
  • Happens automatically
  • e.g. "5" + 2
Explicit Coercion
  • Developer-triggered
  • Number(), String(), Boolean()

🚫 What is NaN?

NaN stands for "Not-a-Number" and represents an invalid numeric result.

nan.js
Number("Hello")   // NaN
0 / 0            // NaN

Number.isNaN(NaN)  // true — correct way to check

NaN === NaN       // false — NaN is never equal to itself

This is a legacy bug from the very first JavaScript implementation. It can't be fixed today because millions of existing websites depend on this behavior.

Functions & Scope
1

⚙️ What is a function in JavaScript?

A function is a reusable block of code that performs a task and can return a result. Functions help organize logic and avoid repetition.

function.js
function greet(name) {
  return `Hello, ${name}`;
}
2

🔭 What is scope and lexical scope?

Scope defines where a variable can be accessed. Lexical scope means a function can access variables from the place where it is written in the code.

scope.js
function outer() {
  let value = 1;
  function inner() {
    console.log(value);
  }
  return inner;
}
3

🪢 What is the scope chain?

The scope chain is the lookup path JavaScript follows to find variables. If it cannot find a variable in the current scope, it moves outward step by step.

This is why inner functions can access outer variables.
4

📤 What is hoisting?

Hoisting means declarations are moved to the top of their scope during execution. However, only the declaration is hoisted, not the initialization.

hoisting.js
console.log(x); // undefined
var x = 5;
5

🎁 What is a closure?

A closure is created when a function remembers variables from its outer scope even after that scope has finished executing.

closure.js
function counter() {
  let count = 0;
  return function () {
    count++;
    return count;
  };
}
Closures are commonly used in callbacks, private state, and memoization.
6

🪜 What is currying?

Currying transforms a function that takes multiple arguments into a series of functions that each take one argument.

curry.js
const multiply = a => b => a * b;
console.log(multiply(3)(4));
7

🔧 What is function composition?

Function composition combines multiple functions so the output of one becomes the input of the next.

compose.js
const addOne = x => x + 1;
const double = x => x * 2;
const result = double(addOne(3));
8

📝 Function Declaration vs Function Expression

Function Declaration

Hoisted completely, including its body, so it can be called before its definition.

declaration.js
sayHello(); // works fine

function sayHello() {
  console.log("Hello");
}
Function Expression

Stored inside a variable; only the variable is hoisted, not the function body.

expression.js
const sayHello = function () {
  console.log("Hello");
};

// sayHello(); before declaration → ReferenceError

💥 What is an IIFE?

An Immediately Invoked Function Expression runs right after it's created, and is commonly used to create a private, isolated scope.

iife.js
(function () {
  console.log("Executed");
})();
11

📞 What are Callback Functions?

A callback is a function passed as an argument to another function, to be invoked later.

callback.js
function greet(callback) {
  console.log("Hello");
  callback();
}

greet(() => console.log("Welcome"));
Used in: event listeners, timers, async operations, and array methods like map/filter/reduce.
12

🏔️ What are Higher-Order Functions?

A function that either accepts another function as an argument, returns a function, or both.

hof.js
function calculate(operation, a, b) {
  return operation(a, b);
}

calculate((x, y) => x + y, 2, 3); // 5
Examples: map(), filter(), reduce(), forEach().
13

🥇 What are First-Class Functions?

In JavaScript, functions are treated like any other value — they can be assigned to variables, passed as arguments, returned from functions, and stored in objects or arrays.

first-class.js
const greet = function () {
  console.log("Hi");
};

const obj = { greet };
obj.greet();
14

🧼 What are Pure Functions?

A pure function always returns the same output for the same input, has no side effects, and never modifies external data.

pure.js
// Pure
function add(a, b) {
  return a + b;
}

// Not pure — depends on & mutates external state
let total = 0;
function add2(value) {
  total += value;
}
Objects
1

🧺 What is Object Destructuring?

Destructuring extracts object properties directly into variables in a single statement.

destructure.js
const user = { name: "John", age: 25 };

const { name, age } = user;
console.log(name); // "John"
console.log(age);  // 25

// renaming a variable
const { name: fullName } = user;
2

🔀 What is Object.assign()?

Copies properties from one or more source objects into a target object — also commonly used for shallow cloning.

object-assign.js
const a = { x: 1 };
const b = { y: 2 };

const result = Object.assign({}, a, b);
console.log(result); // { x: 1, y: 2 }

// shallow clone
const clone = Object.assign({}, obj);
3

🧊 What is Object.freeze()?

Makes an object completely immutable — you cannot add, delete, or modify its properties.

object-freeze.js
const user = { name: "John" };

Object.freeze(user);
user.name = "Mike"; // silently ignored (or throws in strict mode)

console.log(user.name); // "John"
4

🗝️ What is Object.seal()?

Allows updating existing properties, but prevents adding new ones or deleting existing ones.

object-seal.js
const user = { name: "John" };

Object.seal(user);

user.name = "Mike"; // allowed
user.age = 25;      // not allowed
delete user.name;   // not allowed
5

🔑 Dot Notation vs Bracket Notation

Dot Notation

Used when the property name is a valid identifier.

dot-notation.js
const user = { name: "John" };
console.log(user.name);
Bracket Notation

Used when the property name has spaces/special characters, is stored in a variable, or is computed dynamically.

bracket-notation.js
const user = { "first name": "John" };
console.log(user["first name"]);

const key = "name";
console.log(user[key]);
