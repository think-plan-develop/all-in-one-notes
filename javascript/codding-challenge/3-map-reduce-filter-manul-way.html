Manual Implementation vs Built-in

map, filter, reduce, and forEach — how each works, written by hand, then compared to the real thing.

map() filter() reduce() forEach() some() / every() Faithful Versions Common Mistakes Chaining Quick Comparison
💡 How these notes work: each method below covers three things in order — what it does, a manual (polyfill-style) implementation, and the real built-in usage.
🔑 Key Terms at a Glance
🔁
map(): Returns a new array of the same length — one transformed value per input element.
🧹
filter(): Returns a new array containing only elements where the callback is truthy — length ≤ input.
📦
reduce(): Walks the array carrying an accumulator, and returns one final combined value.
🎬
forEach(): Runs a callback for its side effects and returns undefined — can't be chained.
⚠️
Arrow + braces: (e) => { e * 2 } returns nothing — braces need an explicit return.
🔗
Chaining: filter().map().reduce() works because each returns an array except the last; forEach breaks any chain.
sample-data.js
let a = [1, 2, 3, 4];
let arr = [1, 2, 3, 4, 5];

These two arrays are reused throughout every example below.

1. map()

What It Does

Runs a callback on every element and returns a new array of the returned values. Output length always equals input length.

Manual Implementation

mapManually.js
function mapManually(arr, callBackFn) {
    let result = [];

    for (let i = 0; i < arr.length; i++) {
        result.push(callBackFn(arr[i], i));
    }

    return result;
}

let res = mapManually(a, (e, i) => {
    return e * 2;
});

console.log("result of map", res); // [2, 4, 6, 8]

Built-in

built-in.js
let res = a.map((e, i) => e * 2);
console.log("result of map", res); // [2, 4, 6, 8]
2. filter()

What It Does

Runs a callback on every element and keeps only those where the callback returns a truthy value. Output length is less than or equal to input length.

Manual Implementation

filterManually.js
function filterManually(arr, callbackFn) {
    let result = [];

    for (let i = 0; i < arr.length; i++) {
        if (callbackFn(arr[i])) {
            result.push(arr[i]);
        }
    }

    return result;
}

let res1 = filterManually(a, (e) => e != 2);
console.log("result of filter", res1); // [1, 3, 4]

Built-in

built-in.js
let res1 = a.filter((e) => e != 2);
console.log("result of filter", res1); // [1, 3, 4]
3. reduce()

What It Does

Walks through the array carrying an accumulator. On each step the callback combines the accumulator with the current element and returns the new accumulator. The final accumulator is the result.

Manual Implementation

reduceManually.js
function reduceManually(arr, callbackFn, accumulator) {
    for (let i = 0; i < arr.length; i++) {
        accumulator = callbackFn(accumulator, arr[i]);
    }

    return accumulator;
}

const res = reduceManually(arr, (acc, curr) => curr * acc, 1);
console.log("result of reduce", res); // 120 (1*2*3*4*5)

Built-in

built-in.js
const res = arr.reduce((acc, curr) => acc * curr, 1);
console.log("result of reduce", res); // 120

4. forEach()

What It Does

Runs a callback on every element for its side effects. It returns undefined, so it cannot be chained.

Manual Implementation

forEachManually.js
function forEachManually(arr, callbackFn) {
    for (let i = 0; i < arr.length; i++) {
        callbackFn(arr[i], i, arr);
    }
}

forEachManually(a, (e, i) => {
    console.log(`index ${i} -> ${e}`);
});
// index 0 -> 1
// index 1 -> 2
// index 2 -> 3
// index 3 -> 4

Built-in

built-in.js
a.forEach((e, i) => {
    console.log(`index ${i} -> ${e}`);
});
some() & every()

some() — Manual Implementation

someManually.js
// SOME
function someManually(arr, cb) {
    for (let i = 0; i < arr.length; i++) {
        if (cb(arr[i], i, arr)) return true;
    }
    return false;
}

some() — Built-in

built-in.js
const hasEven = arr.some((n) => n % 2 === 0);
console.log(hasEven); // true

every() — Manual Implementation

everyManually.js
// EVERY
function everyManually(arr, cb) {
    for (let i = 0; i < arr.length; i++) {
        if (!cb(arr[i], i, arr)) return false;
    }
    return true;
}

every() — Built-in

built-in.js
const allPositive = arr.every((n) => n > 0);
console.log(allPositive); // true
Improvement Notes — More Faithful Manual Versions

The manual versions above are good for learning. The built-ins also pass extra arguments and handle edge cases. A more faithful version looks like this:

map & filter — Pass (element, index, array)

faithful-map-filter.js
// Pass (element, index, array), like the real thing
function mapManually(arr, callbackFn) {
    let result = [];
    for (let i = 0; i < arr.length; i++) {
        result.push(callbackFn(arr[i], i, arr));
    }
    return result;
}

function filterManually(arr, callbackFn) {
    let result = [];
    for (let i = 0; i < arr.length; i++) {
        if (callbackFn(arr[i], i, arr)) {
            result.push(arr[i]);
        }
    }
    return result;
}

reduce — Support an Optional Initial Value

faithful-reduce.js
// Support optional initial value like the real reduce
function reduceManually(arr, callbackFn, initialValue) {
    let start = 0;
    let accumulator = initialValue;

    if (arguments.length < 3) {
        if (arr.length === 0) {
            throw new TypeError("Reduce of empty array with no initial value");
        }
        accumulator = arr[0];
        start = 1;
    }

    for (let i = start; i < arr.length; i++) {
        accumulator = callbackFn(accumulator, arr[i], i, arr);
    }
    return accumulator;
}
💡 When no initial value is passed, real reduce uses the array's first element as the starting accumulator and begins looping from index 1 — and throws if the array is empty with no initial value at all.
Common Mistakes

Watch Out For These

MistakeWhy it bites you
Forgetting return inside { }Arrow functions with braces need an explicit return — (e) => { e * 2 } returns undefined for every element
Using map when the result is unusedWastes a new array allocation — use forEach for pure side effects instead
reduce with no initial value on a possibly-empty arrayThrows TypeError: Reduce of empty array with no initial value
Expecting forEach to return a value or support breakIt always returns undefined and has no way to exit early — use a plain for loop or some/every if you need early exit
Chaining Example

filter → map → reduce

chain.js
const total = [1, 2, 3, 4, 5]
    .filter((n) => n % 2 === 1)   // [1, 3, 5]
    .map((n) => n * 10)           // [10, 30, 50]
    .reduce((acc, n) => acc + n, 0); // 90

console.log(total); // 90
⚠️ forEach cannot be part of a chain, since it returns undefined — there's nothing for the next method in the chain to call .map() or .filter() on.
Quick Comparison

1. some() — Manual

someManual.js
function someManual(arr, callback) {
  for (let i = 0; i < arr.length; i++) {
    if (callback(arr[i], i, arr)) {
      return true;
    }
  }

  return false;
}

console.log(someManual([1, 3, 4], x => x % 2 === 0));
// true

1. some() — Built-in

built-in.js
console.log([1, 3, 4].some(x => x % 2 === 0));
// true

2. every() — Manual

everyManual.js
function everyManual(arr, callback) {
  for (let i = 0; i < arr.length; i++) {
    if (!callback(arr[i], i, arr)) {
      return false;
    }
  }

  return true;
}

console.log(everyManual([2, 4, 6], x => x % 2 === 0));
// true

2. every() — Built-in

built-in.js
console.log([2, 4, 6].every(x => x % 2 === 0));
// true
