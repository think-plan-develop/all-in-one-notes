1. Scope
What is Scope?
Scope defines where a variable can be accessed in your program. JavaScript has three kinds: Global, Function, and Block scope.
📝 Interview Definition: Scope defines the visibility and accessibility of variables in different parts of a program.
1.1 Global Scope

Variables declared outside any function or block belong to the global scope and can be accessed from anywhere in the program.

global-scope.js 
let name = "Shivam";

function show() {
    console.log(name); // Accessible
}

show();
console.log(name); // Accessible
1.2 Function Scope

Variables declared with var inside a function are accessible only within that function.

function-scope.js 
function demo() {
    var age = 25;
    console.log(age); // ✅
}

demo();
console.log(age); // ❌ ReferenceError
1.3 Block Scope

Variables declared with let and const are accessible only inside the block ({}) where they are declared.

block-scope.js 
{
    let city = "Delhi";
    const country = "India";

    console.log(city);     // ✅
    console.log(country);  // ✅
}

console.log(city);     // ❌
console.log(country);  // ❌
Combined Example — All Three Scopes Together
combined-scope.js 
let global = "I am Global";

function demo() {
    var functionVar = "Function Scope";

    if (true) {
        let blockVar = "Block Scope";

        console.log(global);      // ✅
        console.log(functionVar); // ✅
        console.log(blockVar);    // ✅
    }

    console.log(global);      // ✅
    console.log(functionVar); // ✅
    console.log(blockVar);    // ❌
}

demo();

console.log(global);      // ✅
console.log(functionVar); // ❌

2. Lexical Scope (Static Scope)
What is Lexical Scope?
Lexical Scope means a function's scope is determined by where it is written (defined) in the source code — not where it is called. JavaScript decides this during code creation.
lexical-scope.js 
let a = 10;

function outer() {
    let b = 20;

    function inner() {
        console.log(a); // 10
        console.log(b); // 20
    }

    inner();
}

outer();

Here, inner() is defined inside outer(), so it can access:

  • Its own variables
  • Variables of outer()
  • Global variables
The Classic Gotcha Example
gotcha.js 
let a = 10;

function first() {
    console.log(a);
}

function second() {
    let a = 20;
    first();
}

second();
// Output: 10
⚠️ Why? Although first() is called inside second(), it was defined in the global scope. So it only has access to the global lexical scope, not second()'s local variables.
📝 Interview Definition: Lexical Scope means JavaScript determines variable accessibility based on where functions are defined, not where they are called.
3. Lexical Environment
What is a Lexical Environment?
A Lexical Environment is an internal memory structure created whenever JavaScript enters the Global Execution Context, a function, or a block (let/const).

It contains two parts:

  • Environment Record — stores variables and functions
  • Outer Reference — points to the parent lexical environment
lexical-env.js 
let a = 10;

function outer() {
    let b = 20;
}

Global Lexical Environment

Global Lexical Environment │ ├── a = 10 ├── outer = function └── Outer Reference = null

When outer() executes

Outer Lexical Environment │ ├── b = 20 └── Outer Reference │ ▼ Global Lexical Environment
📝 Interview Definition: Lexical Environment is the internal memory structure where JavaScript stores variables and maintains a reference to its parent scope.
4. Scope Chain
What is the Scope Chain?
The Scope Chain is the mechanism JavaScript uses to resolve variables. It searches the current Lexical Environment, then the parent, then the grandparent, and so on — until it reaches the Global Lexical Environment or finds the variable.
scope-chain.js 
let a = 10;

function outer() {
    let b = 20;

    function inner() {
        let c = 30;

        console.log(a);
        console.log(b);
        console.log(c);
    }

    inner();
}

outer();

Variable Lookup — Searching for 'a'

Inner Scope │ ▼ Outer Scope │ ▼ Global Scope │ ▼ Found (a = 10)

JavaScript checks:

  1. Is a in inner()? ❌
  2. Is a in outer()? ❌
  3. Is a in Global? ✅
💡 Interview Definition: Scope Chain is the mechanism JavaScript uses to resolve variables by searching the current scope and then moving through parent scopes until the variable is found or the global scope is reached.
